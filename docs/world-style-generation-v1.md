# 世界生成、地表与编辑边界

导航：[文档索引](README.md#foundation)

本文定义生成确定性、生效地表、编辑和版本职责。噪声公式、采样参数、接口字段与 shader 实现直接查代码；渲染驻留归[渲染流送](render-streaming.md)，作者编辑存储归[世界增量](foundation-infrastructure.md#世界增量)。

## 分层与修改入口

| 层 | 代码入口 | 职责 |
|---|---|---|
| 连续地貌 | [LandformSampler](../src/world/LandformSampler.ts) | 与区块切分无关的地貌采样 |
| 生成地表 | [WorldSurfaceResolver](../src/world/WorldSurfaceResolver.ts) | 地格分类、宏观地表及水体合成 |
| 世界源 | [world 目录](../src/world/) | 拓扑、生成区块、Worker 和权威编辑 |
| 生效地表 | [WorldSurfaceView](../src/world/WorldSurfaceView.ts) | 将当前作者结果与生成基底合成给消费者 |
| 总览 | [generateWorldOverview](../src/world/generateWorldOverview.ts) | 同源采样与有界栅格生成 |
| 绘制与编辑 | [rendering 目录](../src/rendering/)、[HexMap](../src/HexMap.ts) | LOD 几何、局部刷新、贴地和公开入口 |

依赖方向是连续生成 → 地格解析 → 世界源/生效地表 → 渲染与导航消费者。生成算法不依赖 Three.js、摄像机或已加载显示网格；表现层不能反过来成为生成或通行权威。

## 确定性与世界身份

同一完整 descriptor 和规范坐标，无论 eager、分块、Worker、缓存命中、请求顺序或总览采样，都必须产生一致结果。随机量由坐标和独立用途的盐值派生，不能依赖全局随机流或区块加载顺序。

世界 descriptor 在输入阶段校验并冻结，含嵌套水体配置；坐标使用安全整数，环绕在采样前规范化。风格基线由生成器版本约束，公开参数必须整体规范化并实际影响对应生成算法，不能只有 UI 滑块变化。

唯一指纹覆盖种子、拓扑、尺寸、生成器版本与水体参数；缓存、增量、导航和默认 worldId 共用这一身份规则。显式 worldId 可区分同地貌的多个存档。内部短哈希用于采样，不承诺无碰撞的内容身份。

修改风格参数先查生成入口、Worker 消息、缓存键和存档校验；数字范围由代码维护。UI 步长不应改变 API 的合法性，也不以额外 epsilon 掩盖无效输入。

## 拓扑

- 无限世界按全局坐标生成，没有人为边缘。
- 环绕世界使用有限周期域，尺寸满足六边形接缝约束，周期两端采样一致。
- 有界世界使用边缘规则，不等同于从无限世界裁下一块。

尺寸与容量在分配前验证。样本图库中的尺寸只用于验证，不是所有产品的世界大小；修改某种拓扑必须同时检查区块、总览、编辑、路径和环绕显示副本。

## 生成地表与作者编辑

生成基底可重建，作者覆盖是权威状态；WorldSurfaceView 是读取视图，不是第二份可变网格或存档。重复生成和缓存命中不能覆盖已编辑地格。

保留原分类的地格延续连续起伏；作者改为丘陵/山地时遵守对应有效高度范围，改为平地后不残留原山崖。水面遵守水位语义。静态地图无生成上下文时使用中性地表，不猜测种子。

作者可以给 `Land.land` 添加 `soil` 修饰，表示裸土地表：渲染要求图集存在 soil 格，缺失或用于其他地类时报错；混合优先级位于草地与沙地之间，full/fast 共用材质层，主线程与 Worker 草丛生成都排除该格，总览显示土色。它不改变高度、通行性或森林标记；当前消费者为游戏副本路线，不加入程序化地貌基底，因此不改变生成器版本或既有种子的分类。

`external-surface` 修饰将该格的地面/水面绘制交给应用 `WorldRenderLayer`：`TerrainMesh` 初始构建、增量挂载和刷新都跳过其几何，移除修饰时恢复对应地面/水面区块。逻辑分类、总览、植被和库地表查询不被改写；自定义图层负责与应用玩法高度对齐、投影、光照及资源所有权。当前消费者仅为有限副本的连续岸坡，荒野生成不使用该修饰，也不改变生成版本。

植被删除使对应密度归零，手工添加使用明确的中性布局/树型覆盖，不能被下一次生成撤销。任意连续高度雕刻尚无持久协议，不能临时把显示网格顶点当成权威编辑；有真实消费者时再设计版本化增量。

## 高度、共享边界与贴地

共享顶角由相邻地格对称求值，不由某一块的遍历顺序决定。所有 LOD 共享边缘高度与法线约束，CPU 高度查询和渲染中心扇面一致；近远景切换不能改变角色实际海拔。

shader 细节只在声明范围内增加视觉起伏，保持共享位置并进入 CPU 裁剪边界；不能暗中改变地格分类、通行或存档。full/fast 路径必须保持同一宏观地表和属性语义。

单位、城市、标记、草木、相机与拾取统一读取生效地表。迷雾隐藏外观但不能压平权威高度；向场景添加任意对象不会自动获得贴地规则，调用者需使用地表锚点入口。

显示山高属于地表显示 revision，不改变生成身份；改变后必须刷新几何、包围盒、植被和地表锚点，不能只调材质。新增顶点属性先核对硬件属性限制与资源字节记账。

## 海域与排水河网

自动河流已实现；门禁登记与触发输入分别见[决策登记](optimization-gates.json)和[需求记录](evidence/automatic-river-generation/2026-09-04.json)。实现入口是 [WorldWaterSampler](../src/world/WorldWaterSampler.ts)，范围/default/步长以 [WorldStyleProfile](../src/world/WorldStyleProfile.ts)为准，不在文档复制公式和参数表。

### 决策与需求依据

2026-09-04 用户审阅 2048×2048 世界总览，指出最终高度阈值产生散乱水洼、后续采样方案出现单格伪河且总览明显变慢，明确要求算法改进而非继续调参。因此门禁以 explicitUserHydrologyRequirement 触发；该观察不是物理 GPU 测量，也没有证明已具备可航行/可编辑河网。

当前选择独立低频海域场加有界粗网格排水：LandformSampler.ocean 拥有海陆分类，WorldWaterSampler 在稳定扰动的粗六边形格点上生成支流、汇流和入海路径。有界世界保留边缘语义，环绕世界周期采样。目标是可识别且跨区块一致的视觉水文，不是完整物理水循环。

不再从包含高频山脊/谷地细节的最终高度直接裁海岸；独立随机水洼没有排水身份，逐总览像素追踪流域重复成本过高，全局水文图或完整侵蚀会扩大无限世界状态和启动工作。人工湖河仍可编辑，自动生成不保留未入海的任意内陆死路。

### 河网不变量与预算

- 排水选择按规范坐标稳定，势能严格下降且路径有长度上限；仅保留达到宏观海域的有效路径。相遇分支共用下游，流量代理决定连续宽度，河口扩宽沿真实入海弧长而非离海岸的直线距离。
- 每条成功源路径是 riverLength 的锚点，倍率相对锚点到海洋的曲线距离解释。向上游只探索真实入边，受分水岭、气候、地类与总节点预算限制；提高倍率不改变搜索域或整图潜在流量，不保证成比例增加河长/面积。
- 各倍率使用同一完整有界图，汇流预算取最大并只栅格化一次共享河段；增大长度保留已有水格、弯道和河口，不能随机重生成已存在部分。
- 曲线在原路径凸包内平滑、汇流切线对齐，真实源头和入海端点不漂移。连续扫掠半径与地格中心几何距离决定整格归属，不能随机接受边缘格；细于地格的宽度仍保留连通脊线。
- 生成河格沿用 sea/coastal 分类，逻辑上整格为水或陆，材质过渡不是部分通行。无需因为视觉河网另造一份区块编码/通行事实。
- 无限/有界域使用有界页面 LRU，搜索 halo 覆盖可能源路径、扰动、曲线及河口宽度；邻页、重叠窗口和不同请求大小结果一致。环绕域只枚举规范源并规范化读取。
- 源身份、扰动与流量来自种子/坐标/独立盐值，不依赖 Worker 数或请求顺序；临时节点/上游探索缓存随采样范围释放。
- 总览先采宏观地表，再按范围枚举河格；不逐像素追踪流域或物化全部世界地格。放大时覆盖采样对应的完整像素足迹，缩小时按有界规则合成，支持矩形和分数缩放。

水体参数包含在 descriptor 指纹、序列化、缓存与导航身份中；改变语义同步版本，缺字段/旧含义不自动迁移。海域场宽广，局部窗口全陆或全海都可能合理，质量检查应看宏观连通结构，不强制每窗固定水占比。持久湖盆、编辑传播及物理汇水尚未实现。


## 有界采样与流送

每个 resolver 的缓存有上限；临时采样窗口归一次构建，结束后释放。不得为改善命中率保留整片无限世界。生成请求的取消、迟到结果与资源释放归渲染会话合同。

总览成本随输出像素和受控枚举工作增长，不随逻辑世界面积无界物化。长任务可分批让出，但批次大小、线程数与请求次序不能改变生成结果。

源区块与渲染区块只改变调度和存储切分；共享边界不依赖邻块已驻留，卸载后重建仍一致。通行只读取生成与作者语义，不从视觉 LOD 或微表面反推。

## 编辑刷新与版本

编辑按实际语义刷新必要邻域：地形、修饰、河流影响地表及相关通行；单位变化不触发地貌重建，城市等消费者只刷新受影响资源。发布同时校验世界世代和地表 revision，旧任务不能覆盖新编辑。

| 变化 | 必须审查的版本/合同 |
|---|---|
| 同 descriptor 下地格或宏观地貌结果改变 | 生成器版本、指纹、样本与基线 |
| PackedWorldChunk 编码改变 | 区块格式、读写校验和缓存 |
| Worker 请求/响应改变 | 协议、构建入口、所有收发方 |
| 总览载荷或像素解释改变 | 总览格式与缓存 |
| 完整 WorldDescriptor 字段/含义改变 | 描述符格式、精确身份与恢复校验 |
| 作者增量或检查点参与者字段/含义改变 | 增量/参与者版本、保存与恢复 |
| 纯显示参数或视觉细节改变 | 地表 revision、资源失效与像素验证 |

Worker 两端校验协议、生成身份、请求坐标、尺寸与 packed 格式；已接收请求的取消语义归[基础设施](foundation-infrastructure.md#生命周期与故障恢复)。确定性 golden 更新必须对应明确的生成协议变更，不能作为普通快照维护。

当前版本常量和编码以源码为准，不在文档复制版本数字。一次改动只调整受影响的版本，不能一律提升全部版本；不提供旧格式迁移或静默降级。

## 验证与维护

修改生成算法先跑确定性、拓扑边界、生成/Worker/缓存等价及总览测试；修改地表还检查共享顶角、各 LOD、编辑后高度、远坐标、贴地与裁剪。期望值应独立于被测实现，不能调用同一算法生成预期。

世界风格验收使用固定样本的指标和图库，两者都看；阈值或样本更新应说明生成语义变化及视觉理由，不能只为让基线变绿。样本归[采样定义](../tests/helpers/worldStyleGallery.ts)，独立阈值归[风格检查](../tests/world/worldStyleGallery.review.ts)，命令与组合见[测试策略](testing.md)。

自然河网是有预算的程序化近似，局部渲染合理不证明整个流域真实；当前算法限制与后续触发条件见本页河网决策及门禁登记。显示微细节不等于物理地形，缓存有界也不代表必要可见工作集永不超预算。
