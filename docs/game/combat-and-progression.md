# 战斗、成长与装备合同

本文对应 `apps/survivor/src/core` 的当前实现。数值变更必须同时修改代码、本文和相关测试。

## 固定战斗

- 步长：20ms，50 tick/秒。
- 玩家碰撞半径：0.3 逻辑单位；基础攻击范围：6.4。
- 武器自动选择范围内距离平方最小的怪物。基础弹速 10.5，伤害有 92%–108% 浮动，暴击为 1.8 倍。
- 弹道对本 tick 起终点执行线段扫掠；命中第一只怪物后消失。
- 玩家受击后获得 0.55 秒全局无敌时间。实际伤害为
  `max(1, rawDamage × 100 / (100 + armor × 7))`。
- 页面隐藏和暂停不推进 tick；单帧最多接收 250ms 墙钟时间。

## 玩家派生值

初始等级 1，力量、体魄、敏捷、寻宝各 5，起始武器提供 4 点伤害。装备加成先按三个槽位求和，
再按下列公式生成派生值：

```text
damage        = 7 + level×1.15 + might×1.35 + gear.damage
maxHealth     = round(88 + level×4 + vitality×8 + gear.maxHealth)
armor         = vitality×0.32 + gear.armor
moveSpeed     = 2.7 × (1 + agility×0.008 + gear.moveSpeed)
attackRate    = 1.38 × (1 + agility×0.012 + gear.attackSpeed)
criticalChance= min(0.75, 0.045 + agility×0.0035 + gear.criticalChance)
pickupRadius  = 1.65 + fortune×0.035 + gear.pickupRadius
healthRegen   = 0.12 + vitality×0.018 + gear.healthRegen
```

下一级经验为 `round(24 + level×13 + level²×1.8)`。每级提供 2 点属性；连续跨级按实际级数累计。
一次经验结算发生升级时额外恢复新最大生命的 12%，即使连续跨级也只执行一次。加点与装备切换
只应用真实的最大生命差额，不提供额外恢复。

## 怪物生成

生成速率为 `min(13, 1.45 + elapsedSeconds×0.048)`；活怪限制为
`min(640, 96 + floor(elapsedSeconds×2.4))`。新怪生成在玩家 8.5–12 逻辑单位外环。

基础强度倍率为 `1 + elapsedSeconds/115 + (level-1)×0.045`。生命完整乘倍率，速度只吸收倍率增量的
8% 且最大 1.35 倍，接触伤害乘倍率平方根。精英从 35 秒后出现，概率上限 11%；精英生命 4 倍、
半径 1.28 倍、伤害 1.55 倍、经验 3 倍。

| 类型索引 | 基础生命 | 速度 | 伤害 | 半径 | 经验 | 解锁 |

| 0 | 22 | 1.18 | 7 | 0.30 | 6 | 开局 |
| 1 | 17 | 1.72 | 6 | 0.25 | 7 | 20 秒 |
| 2 | 70 | 0.72 | 15 | 0.46 | 16 | 45 秒 |
| 3 | 44 | 1.34 | 11 | 0.34 | 12 | 90 秒 |

## 掉落与装备

普通怪基础掉率 7.5%，精英 62%，再乘 `1 + fortune×0.025` 并封顶 72%。只有地面装备池有空位时
才执行品质与词缀随机。物品等级为
`max(1, playerLevel + floor(elapsedSeconds/55) + random[-1, 1])`。

品质基础区间为传奇 2.5%、稀有累计 15%、魔法累计 43%、其余普通；寻宝按受限质量加成分别调整
三个阈值。普通、魔法、稀有、传奇的数值倍率为 1、1.18、1.42、1.82，附加词缀数为 1、2、3、4。

武器隐式提供伤害；护甲隐式提供生命和护甲；指环隐式提供拾取范围。词缀从槽位白名单无放回抽取。
装备战力只用于 UI 比较，不进入实际结算；实际效果始终来自逐项 bonus 聚合。

背包容量 20。拾取半径 0.75；背包满时地面装备保留。穿戴只接受背包内 ID，旧装备回到背包；
丢弃也只接受背包内 ID。不存在装备复制、自动分解或隐式覆盖。

## 容量与验证

怪物、弹道、经验球、地面装备容量分别是 640、128、768、64。经验球满时新经验累加到索引 0，
保证经验总值；其他池满时相应生产者停止创建新实体。所有池只迭代 `[0,count)` 活跃前缀并以末项
交换删除。

`npm run test:app` 验证同种子复现、装备引用/数值、固定时钟、持续生成与自动击杀。
`npm run test:app:e2e` 验证真实 Worker/WebGL 世界加载和主要玩家操作。
