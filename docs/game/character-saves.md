# 开始界面与角色存档

导航：[总导航 · 游戏设计](../README.md#game) · [按任务阅读](../README.md#routes)

`bootstrap` 先显示 `StartScreen`，点击开始/读档后才创建 HexMap、角色资源与战斗 Worker；返回主界面销毁这组资源。
开始界面提供 1–128 字世界种子、随机种子、继续最近一次有效存档以及四个固定存档槽。
世界预览使用同一生成器、水体参数和总览栅格算法，展示中心 512×512 地格，192×192 像素；输入停顿 300 ms 后交给独立 Worker。
修改种子或离开主界面立即终止旧预览任务，完成后也终止 Worker；主界面不运行 3D 世界或战斗循环。

## 保存边界

- 一个自动槽，三个手动槽。开始/主界面读档完成、每 60 秒、切出页面和返回主界面时保存自动槽；手动槽只由用户操作覆盖。
- `O` 打开游戏与存档界面，暂停战斗；关闭只恢复由该界面暂停的战斗，保留玩家主动暂停。
- Worker 在前序命令和 tick 完成后导出 `CharacterCheckpoint`，不直接把 10 Hz HUD 快照当成存档。
- 主线程将小型角色记录写入 IndexedDB `survivor-characters/characters`，严格持久化事务完成后才显示已保存时间。
- 保存失败显示原因，旧记录保留，战斗继续；死亡不会覆盖最后一次存活存档。保存期间拒绝第二次保存，菜单禁用重复操作。
- 返回主界面先等待自动保存成功再销毁会话；保存失败留在游戏内。浏览器关闭事件不能保证异步写入完成，最近完成的自动/手动存档才是持久化边界。

## 存档内容与读档

保存种子、原始出生原点、角色位置/朝向、tick/击杀/宝箱计数、角色等级/经验/属性/剩余点数、金币、粉尘、全部背包类型、穿戴与嵌珠、物品 ID 分配器、自动回收设置与计数。
技能等级、装配、点数、冷却与持续状态、生命/法力、药剂/攻击/免伤盾冷却和战斗随机数也保存。
运行时所有权见[战斗架构](combat-architecture.md)：经济字段恢复到 `CombatRewards`，受击保护和被动盾冷却恢复到 `CombatResolution`；结界仍以原检查点的剩余值与期限保存，读取时由 `SkillSystem` 按存档 tick 重建 `StatusSystem` 的有效 Barrier。空结界或已到期结界不重建。不保存临时战斗事件或怪物 Buff；本次职责调整未改变角色格式。
衍生属性由已保存的装备与角色成长重算，不从存档信任最终战力缓存。

这是角色存档，附近怪物、宝箱、弹道和未拾取掉落不存，读档按原始出生原点重建附近遭遇；不能用于逐 tick 战场回放。
读档确认窗明确这个范围；读档完成后保持暂停，玩家查看状态后继续。
灵境沿用独立持久化档案；角色存档中的历史灵境加点先从基础属性扣除，再加上当前永久灵境成长，避免旧档回退或重复叠加。

手动覆盖已有槽、游戏内读档各使用一个预览/提示合一的确认窗。空手动槽直接保存；开始界面明确提示新游戏会更新自动槽。
记录保存角色格式版本与地图生成器版本；不支持的版本显示不可读取，不做迁移或降级。单个损坏槽不阻挡其他槽读取。
读取时检查有限数值、物品类型/品质/堆叠、唯一 ID、装备部位、分类容量、技能装配等；生产 Worker 还检查种子/原点及角色位置净空。

`CharacterSave.test.ts` 覆盖角色往返、永久灵境、非法数据、IndexedDB 重开和槽隔离、命令保存屏障。
`menu-saves.spec.ts` 通过真实 Worker 验证世界预览、手动保存、读档、刷新读取、自动保存返回主界面与窄屏布局。
