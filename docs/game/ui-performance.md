# 背包、打造与地图 UI 开销

导航：[总导航 · 游戏设计](../README.md#game) · [按任务阅读](../README.md#routes)

当前 HUD 是 React DOM、SVG 图标与 CSS 品质样式，由浏览器执行布局、绘制和合成，不是 WebGL 中统一材质的 UI 实例批次。
游戏实体已有独立实例批次；减少 UI 开销的边界是减少 DOM、重复组件计算和持续动画，不能用游戏 draw call 数代表 UI 成本。

`ShareSnapshot` 在 Worker 的结构化克隆之后复用等值只读分支，未变化的背包、装备、属性、衍生属性、宝珠、回收设置与技能构筑保持引用身份。
装备比较缓存同时依赖物品、穿戴、属性、战力和角色等级，避免复用引用后漏掉等级变化。
`VirtualItemGrid` 依据实际容器宽高与滚动位置，只挂载可见行以及缓冲行，保留总滚动高度与稳定 ID；改变分类/过滤重置滚动窗口，响应式列数改变保留原来的首行物品锚点。
格子常驻品质底色、描边、星级与锁纹，只有悬停/键盘聚焦的格子播放流光，离屏格子不产生 DOM 或合成动画。
浮窗仍在 Portal 中，拖拽仍使用共享的捕获指针机制；虚拟化不会将浮窗裁在滚动容器内。
背包卡片仅保留选择和详情入口，装备/打造/售出共用底部操作区；较紧凑的 112px 行高和更宽的单窗会增加可见物品数，仍按可见行挂载。统一标题和折叠说明不引入逐帧更新，航图拖动继续只修改一个 transform。

## 本机对比

用 `node scripts/benchmark-survivor-ui.mjs <生产预览地址>` 运行；真实战斗 Worker 注入 80 件彩装，1280×720，Chromium/ANGLE D3D11，世界暂停，每场景采样 2.5 秒。
测量夹具通过角色检查点一起设置背包和物品 ID 分配器，保持物品与存档校验有效。
初轮虚拟化改造的基线为 `b141f09`；下表是该轮相同场景、脚本和显卡的单次观察，不作为当前窗口尺寸的固定挂载数或跨硬件 FPS 承诺。

| 指标 | 改动前 | 改动后 |
|---|---:|---:|
| 背包实际挂载格子 | 80 | 15 |
| 打造实际挂载格子（含穿戴） | 81 | 20 |
| 背包打开时主线程 TaskDuration | 479.5 ms | 231.3 ms |
| 背包打开时 RecalcStyleDuration | 96.2 ms | 0.4 ms |
| 打造打开时主线程 TaskDuration | 406.3 ms | 232.2 ms |
| 打造打开时 RecalcStyleDuration | 79.8 ms | 0.4 ms |
| 背包 RAF 帧间隔 P95 | 16.7 ms | 16.8 ms |

采样受 60 Hz 限制；开销明显减少，未测出更高的显示帧率。该基准隔离窗口挂载/样式动画，不能替代持续移动战斗场景的性能门槛。
`CharacterSave.test.ts` 检查克隆快照的分支复用与单件锁定失效；`menu-saves.spec.ts` 验证 80 格虚拟滚动仍能到达末件物品。

统一窗口布局后的复测（2026-09-19，同脚本与 1280×720）：80 件彩装背包挂载 24 格，打造挂载 16 格；两者 2.5 秒采样的 RAF P95 分别为 16.8 / 16.7 ms，样式重算累计 0.384 / 0.674 ms，布局累计均为 0 ms。主线程 TaskDuration 为 291.3 / 286.9 ms，关闭窗口基准为 303.8 ms；包含后台场景工作，不作为纯 UI 耗时差或 FPS 提升结论。

## 技能星图

冰霜、火焰、雷电页各固定 34 个节点和一张 SVG 连线图，只挂载当前页；其余页只挂载实际已有术式。`SkillGraph` 用 memo，节点等级/选择/构筑不变时，10Hz 冷却/法力发布不会重新遍历连线。参数修正在权威构筑提交时编译，UI 草稿只在编辑时重编译，不在固定 tick 处理整棵树。
星图平移直接更新滚动位置，原生边界限制位移，指针移动不触发 React 整树重渲染；悬浮说明复用单实例 Portal 浮窗协议。`RepeatButton.tsx` 共用于属性和技能加点，仅按住期间有一个延时任务，取消/失焦/卸载清除；权威端仍验证每次点数和上限。
2026-09-20 的[交互调整样本](measurements/skill-interaction-refinement.json)在 1280×720、Chromium/ANGLE D3D11、暂停权威并保留背景渲染下，各采样 2.5 秒：星图 34 节点，RAF P95 16.8ms，期间 Layout 0ms；背包 24 格和打造 16 格同样保持有界挂载。这不是持续战斗帧率或拖动全程采样。浏览器行为检查另覆盖实际拖动、连线与名称/等级/图标几何避让、悬浮、长按释放/关闭取消和一键洗点；1440×900、390×844、1366×520 检查导航不被遮挡，树可操作高度大于 100px。
纹样、光晕与图标使用本地 CSS/SVG；沒有新增纹理或常驻循环动画，减弱动效偏好关闭过渡。现有 UI 基准新增 K 窗口采样及节点数，记录在[星图浏览器样本](measurements/skill-tree-ui.json)；它包含背景场景，不能单独视为纯 UI 耗时或持续战斗帧率。

完整火树接入后的[测量记录](measurements/fire-skill-tree.json)沿用上述环境，新增火焰页采样：冰/火各挂载 34 节点，RAF P95 分别为 16.8 / 16.7ms，Layout 均为 0ms，样式重算累计 0.335 / 0.441ms。两个页面只挂载当前学派，新增另一棵树不将节点数翻倍；这些暂停世界的样本不包含满人口灼烧的 GPU 成本。

2026-09-21 的[雷树记录](measurements/lightning-skill-tree.json)在同环境新增雷电页：冰/火/雷各挂载 34 节点，RAF P95 分别为 16.8 / 16.7 / 16.8ms，Layout 均为 0ms，雷电页样式重算累计 .488ms。背包仍挂载 24 格、打造 16 格。另通过真实 Worker/WebGL 检查 2K 居中、七个雷电主动、导电与静电防护的暂停/到期；这些交互截图与暂停 UI 样本不代替持续战斗 GPU 帧时测量。

## 地图迷雾

`node scripts/benchmark-survivor-map.mjs <运行地址>` 默认检查实际开发服务 `http://127.0.0.1:5173`，也支持生产预览。在 1920×1080 浏览器中用真实鼠标输入，分别记录静止、默认比例拖动和最远比例拖动；每次拖动场景含 6 段 × 60 个移动事件，远景通过多次滚轮输入到达 384 地格跨度。保留真实地图帧调度、地形 Worker 与战斗更新，不直接修改视口、不冻结快照。记录地图请求/重绘计数、迷雾/覆盖层/整图同步绘制耗时、主线程任务时间、长任务与 RAF 帧间隔。同步绘制耗时不是 GPU 完成时间，后台战斗与机器负载会影响整帧结果。

旧实现用精确浮点视口作为采样缓存键，平滑跟随和缩放几乎每次都重新扫描 128×128 点；云团渐变即使缓存命中也重新提交。当前采用带余量的离屏图，重建按探索行段和地域多边形绘制。缓存失效与资源归属以[探索与家园](exploration-and-homestead.md)为准。

第一轮历史测量（2026-09-19，Chromium/ANGLE D3D11、1280×720）见[原始数据](measurements/minimap-fog-browser.json)：在同一构建内注入 `ea7d7c5` 的原始 `drawFog` 方法作为基线。该轮直接修改视口并冻结快照，只证明迷雾函数开销下降，没有覆盖真实指针、地形请求和重复重绘，不能作为拖动流畅度的验收。当前脚本已替换为上面的真实输入回放。

| 迷雾同步提交耗时 | 改动前 | 改动后 |
|---|---:|---:|
| 跟随移动 P95 | 1.5 ms | 0.1 ms |
| 持续开雾 P95 | 1.4 ms | 0.7 ms |
| 展开拖动 P95 | 1.4 ms | 0.1 ms |
| 远景拖动 P95 | 2.4 ms | 0.1 ms |
| 远景拖动最大值（含首次重建） | 4.3 ms | 1.7 ms |

计时精度约 0.1 ms，缓存命中的实际耗时低于或接近该精度，不能将比值当作整体帧率提升。已有浏览器回归还检查未知像素保持不透明、负坐标探索范围正确、同等级不解锁，以及缓存命中不重建。

第二轮针对 `9f69890` 的实际开发页面修复：雾下地形页停止请求、不可见地域不绘制渐变，鼠标/采样完成/覆盖层更新合并到既有地图帧。相同 360 次远景移动的[浏览器数据](measurements/minimap-drag-browser.json)：新增地形请求 **54 → 0**，地图绘制 **415 → 360**，整图绘制 P95 **1.0 → 0.2 ms**，该场景绘制累计 **318.0 → 45.1 ms**。两次 RAF P95 均约 16.7 ms，未在本机复现用户的持续低帧率，因此不把减少的工作量写成整体 FPS 提升。100 事件同帧突发由浏览器回归另行验证为一次绘制。
