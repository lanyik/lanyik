# 荒原进度与开发重点

导航：[文档索引](../README.md#game)

状态复核：2026-09-28。本文只记录当前进度、尚未实现的能力和建议顺序；运行规则归各领域设计，参数与完成细节查代码，不在这里复写。

## 当前进度

已具备探索、战斗、掉落、配装、打造、角色存档和永久成长闭环。地图库已有流送、资源预算、恢复与诊断，游戏已有有界 ECS、权威 Worker、四系及通用构筑、常驻被动和批量表现。当前阶段适合继续完善可玩内容和代表场景验证。

| 领域 | 已有能力 | 仍需完成 |
|---|---|---|
| 战斗 | 普通怪/领主、四系技能与状态、攻击遮挡、自动战斗、受阻寻路与近身占位、主角动作与基础音效 | 真实地貌与密集围攻体验验证、动作节奏与音色实玩校准 |
| 成长 | 游侠职业与装备归属基座、词条打造、技能构筑、被动装配、宝珠、灵境 | 职业玩法、定向套装与饰品来源、中后期构筑和经济节奏校准 |
| 世界 | 连续地貌、遭遇连通布局、探索迷雾、家园与卷轴副本 | 聚落实体、据点目标、区域差异及相应持久进度 |
| 产品 | 自动/手动存档、失败恢复、诊断导出、窄屏布局 | 新手引导、画质/输入设置、角色与灵境备份 |
| 表现与性能 | 主角上下身骨骼分层、地形材质、树木 LOD、天空雾、实例化和 UI 虚拟化 | 写实暗黑世界样板、游戏 UI 重设计、桌面独显 1440p / 60 FPS 验收 |

## 优先：写实暗黑视觉改造

[视觉改造项目](visual-overhaul.md)统一世界、角色、技能与游戏界面的标准、工作包及验收。方向与目标为写实暗黑、桌面独显 1440p / 60 FPS，正式目标硬件仍待确定。主角移动/攻击分层、B1 统一颜色输出/天空环境照明及 B2 近景动态阴影已完成；首领副本已接入营地→石路→河岸→首领的连续路线、首批扫描石材和原生 1440p 对照入口。荒野与副本树木已共用风动及同步阴影，副本连续岸坡、湿土、营火和倒木已接入。地形环境反射的粗糙度积分已修正；下一步优先建立山地结构和体积雾样板，补充低视角验收，再扩充废墟并评估向荒野推广；具体缺口归[山地与大气验收](visual-overhaul.md#山地与大气验收缺口)。HUD、背包与角色换装闭环及怪物/四系效果仍待后续。专业武器动作、完整世界样板与界面重设计尚未完成，不能用当前试装代表最终品质。

## 优先：战斗可信度

攻击与移动已读取同源地表及树干遮挡，前景透视不会移除碰撞。遭遇布局在驻留窗口内证明入口连通，只有实际创建后消费出生槽；保证范围见[地形通行](terrain-navigation.md)。

怪物已有[有总预算的受阻寻路与近身占位](simulation-and-ai.md#受阻寻路与群体占位)，覆盖长墙、凹墙、脱战归位及外圈补位。接下来在真实山口、密林、河岸及混合体型围攻中检查到达率、受阻时间、重叠和战斗压力；局部搜索与软分离不承诺所有窄口和极端密度可解。

主角已接入[上下身分层、移动瞄准、受击和倒地动作及基础声音](actor-assets.md#主角动作与声音)，可移动施法保留步态，实际锁步施法才使用全身动作；权威死亡立即停止玩法，常驻模型独立完成倒地。音频按范围、频率和重要性限声部，O 菜单可关闭和调音量。当前复用通用动画及原创合成音效，专业侧移/后退和武器动作、配音及配乐尚未实现。

## 优先：成长选择与完整校准

四系和通用构筑已经接入，不再以“增加技能点用途”为独立待办。先验证开局到首领及中后期、混系构筑的真实选择；每阶段同步 UI、存档、规则和验证。未来沉默、元素与触发被动协议仅随实际消费者推进，接入约束见[战斗架构](combat-architecture.md#后续接入边界)。

现有角色已登记为游侠，[职业与装备基座](items.md#职业装备归属与产出)覆盖身份、武器归属、标准防具的通用/专属限制及通用饰品规则。后续按角色职业设计技能、武器行为与整套装备，再接副本的职业定向套装产出；本期没有新职业、套装效果或饰品产出。饰品需独立设计稀缺来源，不放回常规随机池；不提前搭建没有实际内容的效果框架。

[数值报告](combat-and-progression.md#数值校准)只覆盖参考装备的离线期望。需用固定种子的开局到首领样本，覆盖缺装、同级完整装、越级和高品质专精，记录死亡原因、击杀时间、回复占比、净收入、换装间隔和空跑时间。金币、粉尘已有支出，待评估的是节奏和收益感。

## 随后：探索片段与世界状态

家园和副本已有可玩入口及续战记录；家园经营、仓库、可建造设施和 NPC 尚未实现。荒野营地目前主要是怪物编组，尚缺依地貌布置的建筑、目标与专属产出。

先完成一个可重复的探索片段：发现地标、沿可通行路线接近、处理有配合的敌人、完成据点目标、挑战领主并获得改变下一次选择的奖励。用这个片段锁定节奏和美术样板，再扩充区域与大型任务。

荒野卸载/读档重建人口是当前规则，副本另有持久进度。增加据点或首杀奖励时，明确持续范围、重置时机和稳定地点身份，不能只在 HUD 留标记，也不能把地图库增量能力当作已经实现的游戏事件存档。

## 产品与性能验收

画质目标与样板标准归[视觉改造项目](visual-overhaul.md)，当前资源边界归[环境资产](environment-assets.md)与[角色资产](actor-assets.md)。视觉品质和 CPU/GPU 成本在同一可玩场景中评审。

先补画质/分辨率比例、文字尺寸和控制说明；音频已有会话内开关与音量，设置持久化待补。物品支持触屏拖拽不代表整款游戏已有移动端操控；手柄与触屏移动由目标平台决定。

长期游玩需要同时覆盖角色和永久灵境的备份入口，校验版本、部分损坏、中断和重复导入。当前诊断导出不能代替角色备份。

在明确设备与分辨率上测平原赶路、密林战斗、领主特效、满包开窗和跨区加载，记录 CPU/GPU 帧时分位、峰值资源与挂载长任务。[UI 测量](ui-performance.md)和历史 CPU 基准只证明各自场景；Windows 原生图形路径及目标设备仍需发布验收。

已补齐[CPU 尾延迟与阶段观测](measurements/performance-tail-latency.json)，并完成[首轮等价计算优化](measurements/performance-tail-optimization.json)。玩法区块现已采用提前准备与异步分块，[本轮记录](measurements/regional-streaming.json)中赶路/自动战斗最大 tick 明显下降，旧版回放和异步回放保持玩法、随机状态及布局一致；P99 和均值增加，不能将分摊工作描述为总计算量下降。

后续关注冷启动、远距传送中仍较重的单块/构造切片，以及灼烧周期结算和躲避首批决策。分块已经避免普通跨区一次生成整列，但不保证所有切片达标。平均门禁不证明峰值达标，阶段探针含额外开销，仍需目标设备完整场景确认输入延迟影响；尚未调整玩法或加入新的尾延迟硬门槛。

建议顺序：写实暗黑可玩样板与游戏界面闭环 → 战斗可信度与构筑校准 → 探索片段及世界状态 → 内容扩充和产品设置。更多 Worker、全面改写 ECS 或切换 WebGPU 均不是当前开发的前置条件，优化仍按[门禁](../optimization-gates.md)推进。
