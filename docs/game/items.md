# 通用物品与图标规范

导航：[总导航 · 游戏设计](../README.md#game) · [按任务阅读](../README.md#routes)

本页维护装备生成与比较、背包事务、回收和通用物品表现。地域与奖励来源见[战斗与成长](combat-and-progression.md)，窗口布局与快捷键见[界面设计](interface-design.md)。固定参数由 `apps/survivor/src/core/GameConfig.ts` 定义，
`ItemDefinition.ts` 约束公共字段，`InventoryItem.ts` 提供可辨别联合类型，`Inventory.ts` 执行分类容量和堆叠事务。

## 装备生成与比较

装备基础值、显式词条与聚合值分别存储且冻结，`sumEquipment()` 是装备聚合入口。

11 部位：武器、头盔、胸甲、腿甲、鞋靴、臂甲、手套、指环、项链、手镯、饰品。
每部位四种基础名称（共 44 种），配合随机前缀、词条与三轴属性生成装备。

- 等级只控制部位基础值，星级和品质不改变基础值。
- 1/2/3 星生成时分别有 2/3/4 条不重复词条，基础概率 58%/30%/12%，可被星级宝珠改变；继承后完整保留来源条数。
- 白/蓝/紫/金/钻/彩控制词条颜色与倍率 1/1.3/1.7/2.2/2.9/3.8。
- 全部 38 种 `BONUS_INFO` 属性都能成为词条。数值为基准值×品质倍率×`[.86,1.14)`，保留三位小数。
- 品质、星级使用独立随机抽样；宝箱/Boss 保底只提升品质，不改变星级、基础值或词条选择。

|---|---|
| 武器 | 攻击 `3.5+1.35L` |
| 头盔 | 生命 `6+2L`，防御 `.5+.25L` |

| 臂甲 | 防御 `.5+.25L`，格挡 `1+.35L` |
| 手套 | 攻击 `.5+.35L` |

起始为 1 级白色 1 星守夜短弩，基础攻击 4.85，词条攻击+1、命中率+2%。

### 战力与比较

`EquipmentEvaluation.ts` 是换装、清理和推荐的统一入口。当前装备与候选都带相同的常驻被动属性上下文，避免把被动收益误记为换装收益；自动嵌珠组合评分同样把被动寻宝与宝珠评分一起带入递减公式。战力是最终战斗属性的综合加权分，不是伤害预测。
先 `sumEquipment` 聚合，再 `deriveStats` 结算等级、加点、百分比加成、属性上限与溢出转换。
最终 `BONUS_IDS` 数值乘目录权重求和；排除已折算到结果的 maxHealthBonus、damageBonus、armorBonus、blockBonus、regenBonus，
以及非战斗的 experienceBonus、goldBonus、pickupRadius。免伤盾单独计 `(12 - shieldRecovery) × 25`，
另加 `maxMana × .35 + manaRegen × 22`，最后四舍五入。装备原始评分仍包含探索收益，保留其独立参考价值。
命中、防暴和爆伤减免也先按当前敌方规则的有效上限截断；没有实际收益的溢出不增加换装战力。
例如两套装备都已能完全抵消 Boss 闪避时，换掉额外命中换取伤害会提高战力，不会因原始命中词缀分更高而被自动清理。
主 HUD 与角色面板显示总战力；装备贡献是当前总战力减去相同等级/加点裸装战力。
换装比较只替换对应部位后重算全部属性，显示的战力必须等于实际穿戴结果。

### 挂机自动装配

Z 自动战斗同时启用装备与宝珠自动装配，关闭、死亡、传送和读档后停止；家园不运行。`AutomaticLoadout.ts` 在开启挂机、拾取/开箱、升级解锁宝珠槽及调整回收设置时计算方案，不逐 tick 扫描背包。手动穿戴、卸下和嵌珠立即生效，不在下个空闲 tick 改回；下一次上述边界才重新评估，长期固定搭配可关闭 Z。

万象牵引允许不受距离限制地收取当前世界已生成的地面物品与经验，失败仍保留物品；不自动开箱或使用物品。低频扫描、尝试预算和装配条件统一见[通用被动合同](skills-and-effects.md#通用主动与常驻被动)。

装备按固定的十一部位顺序各评估一次，从背包与本次奖励中选择总战力提升最大的候选；只有严格提升才替换，持平保留当前装备，同增益候选按较小物品 ID 决定。每个部位最多替换一次，本轮后续部位基于已选择的前序装备比较，不搜索十一部位的笛卡尔积。资源比例按普通换装结算，不通过换装回血或回蓝。

宝珠目标是普通怪装备的词条期望产出：`普通掉率 × 品质词条倍率期望 × 词条条数期望`，复用实际 `lootProfile`、装备品质倍率及配对共鸣；不以宝珠颜色简单替换，也不单独优化额外金币和打造折扣。同类型宝珠数值由品质单调决定，先取各类型最强的至多六颗，再枚举四类在已解锁槽中的数量组合，六槽最多 84 种组合。已嵌同分宝珠优先，其余同分按 ID；整套收益未严格提高则保持现状，换装保留仍被选中的宝珠槽位。可以同时替换两颗以形成新配对，不受逐槽贪心限制；不会自动精炼、花粉尘或使用未解锁槽。

装备只有一层 `locked`：锁定就受保护，Shift＋点击/空格和角色详情按钮一次切换。自动穿戴保留候选已有的锁，不新增锁；`autoEquipped` 仅记录自动穿戴经历，供旧装淘汰判断，不是第二层保护。已有手动锁定的候选不新增自动经历。手动穿戴、手动锁定/解锁、打造清除自动经历，初始武器也属于保留装备；标记随角色存档保存。

自动淘汰独立于品质回收阈值，但只处理未锁定且 `autoEquipped=true` 的背包旧装备，并要求同时满足：白/蓝/紫品质；原始评分不高于当前同部位的 60%；落后至少 10 级或两个品质档；换回后总战力严格降低。符合时同一事务售出，收益与累计售出件数复用普通回收。小幅升级旧装不触发这条淘汰规则，但未锁定装备仍参与玩家主动设置的品质清理；锁定和金色以上装备不受自动淘汰规则影响。

装配先于品质回收：选中的装备和宝珠不会先被分解，剩余物品再应用已有品质阈值。`planAutomaticLoadout` 只生成方案，装备、宝珠、旧物回包、自动淘汰、金币/粉尘一起提交；满包只有在最终分类容量足够时才可换装。宝箱整批奖励有任一类放不下便整批不领取，不提前穿戴、出售、消耗随机数或物品 ID。Boss 保底三星彩装本次领取必须保留在背包或穿戴栏，不因自动回收阈值被出售。

纯药剂/精粹/卷轴拾取不启动装配评估。失败的地面物品或宝箱领取以稳定来源对象缓存；背包、派生属性、已嵌组合或回收规则改变后才重试，药剂原地消耗也使缓存失效。跨驻留区块、恢复与销毁清理失败记录；容量受当前地面池与驻留宝箱数量约束，满包原地等待不会每 tick 重算整套装备。

地面拾取与宝箱领取共用每固定 tick 一次自动装配计算预算，失败方案也计入；已缓存的失败不消耗预算。超额来源原样留在地面/宝箱，下一 tick 按原拾取顺序继续，不伪报满包、不提前消耗奖励或随机数。开启挂机、升级和手动调整设置仍立即评估。该上限避免一批物品同时吸附到身边时在单 tick 连续重算整套背包；每秒仍可处理最多 120 次领取。

`npm run benchmark:app` 的 `autoLoadout` 场景固定 80 件装备、48 颗库存宝珠、六个已嵌槽和新奖励，每轮必须实际换装/嵌珠，报告每次方案计算耗时、P95 和最大值。一次预热、五次采样，每次 120 个方案，平均耗时样本的中位数门槛为 3ms/decision；这是 Node CPU 预算，不代表浏览器帧率。

## 数据与容量

| 字段 | 含义 |
|---|---|
| id | 局内唯一物品/堆叠 ID；排序、选择、命令和浮窗身份使用它 |
| type | 大类，也是所属背包：equipment、orb、consumable、affix、scroll |
| value | 大类下的子类；装备部位、宝珠类型、药剂配方或词条属性 ID |
| size | 当前格的数量；装备和宝珠固定 1，药剂、词条与副本卷轴为 1–99 |
| rarity / name | 品质与显示名；具体属性保留在各自类型中 |
| itemLevel | 仅装备拥有等级；药剂与宝珠不存在该字段 |

| type | value | 独立容量 | 堆叠上限 |
|---|---|---:|---:|
| equipment | weapon/head/chest/legs/boots/arms/hands/ring/necklace/bracelet/charm | 80 格 | 1 |
| orb | fortune/bounty/constellation/harmony | 48 格 | 1 |
| consumable | health/mana/health-percent/mana-percent | 32 格 | 99 |
| affix | BONUS_INFO 中的属性 ID | 80 格 | 99 |
| scroll | rift-lord / stone-sovereign / storm-oracle / ember-champion | 20 格 | 99 |

`value` 只表达子类，不复用为属性数值；`size` 表达数量，不表达图标像素大小或物品占用格形状。
`TypedValue<T,V>` 是物品与技能共用的大类/子类身份。技能定义为 `type: "skill"`、`value: pulse/frost/chain/dash/ward`，
另有解锁条件和独立技能等级；技能不堆叠、不占背包，不虚设 size、物品 ID 或背包容量。
背包内存仍是有界联合数组，分类容量分别计算，穿戴装备和已嵌宝珠不占背包格。不存在共享的总格数限制。

药剂由固定配方和品质唯一决定药效，只有 value、品质相同才可合并。拾取先补已有同规格堆叠，再为余量占一格；
空间不足时整个拾取不提交，原有堆叠和地面物品数量不变。已有堆叠保留原 ID，新格保留新物品 ID。
地面五类物品与经验共用[派生拾取范围](combat-and-progression.md#基础属性法力与升级)，范围属性同时作用于两者。进入范围后以 `5+(拾取范围−距离)×2.2` 单位/秒吸向玩家，到身边 .25 单位内再执行上述入包或自动清理事务。
吸附按固定 tick 推进、移动后更新空间索引，表现帧插值前后位置；离开范围后清除上一帧位移，物品不会重复播放旧移动。满包物品保留在身边，吸附不要求玩家走到树干或陡坡中的掉落点。
显式“合并药剂”和整理先按当前背包顺序紧凑合并兼容堆叠，先出现的 ID 保留，数量和药效守恒；已合并消失的 ID 不再可操作。
整理对完整背包按品质降序、装备等级降序（非装备按 0）、类型升序、同类非装备 value 升序、稳定 ID 升序排序；装备不按部位额外排序。当前分类只是结果的过滤视图，排序不改变金币、穿戴或选择 ID。每次打开背包整理一次，之后新物品追加，不逐帧排序。
词条精粹另有 `amount` 数值，只有属性、数值、品质完全相同才堆叠；提取时自动补满同规格堆叠。

## 副本传送卷轴

四种 Boss 卷轴固定彩色品质，无装备等级；同副本、同品质可堆叠，独立 20 格、每格 99 张。每次怪物击杀独立抽一次，概率等于当前 `lootProfile.qualities[5]`（基础 .2%，随品质寻宝提升），成功后四种等概率选一种；不要求同时掉彩装，也不乘普通/精英装备掉率。`seed:scroll:累计击杀数` 的独立随机流不消耗原有战斗/装备随机序列。地面池满时不额外创建卷轴。

背包“卷轴”页与数量角标显示真实库存，点击“前往”或双击打开 H 并选择对应副本；查看地图不消耗，首次开启或通关后开新轮才在旅行事务中扣 1 张。未完成副本继续进入不扣，详见[副本规则](exploration-and-homestead.md#boss-挑战副本)。卷轴有独立回收设置、默认关闭，不进入打造。图标采用现有 SVG 图标系统中的封印卷轴，地面复用宝石物品池和彩色光柱，无新增外部资产。
通用紧凑合并同时处理可堆叠的精粹，装备与宝珠保持独立格。精粹不设等级，不生成随机额外属性。
使用药剂只减少一瓶，数量为零才移除格；HUD 显示所有相应子类堆叠的总瓶数。
暂停、药剂冷却中或该药能恢复的全部资源已满时禁用使用按钮，图标仍可显示详情。死亡后禁止物品修改；暂停期间的其他命令边界见[应用设计](../app-development.md#权威状态与时钟)。

### 固定药剂配方

`InventoryItem.ts` 的 `POTIONS` 和 `POTION_RARITIES` 是配方与数值的唯一来源，不随地域或角色等级增加规格。

| value / 名称 | 恢复方式 | 白 | 蓝 | 紫 | 金 |
|---|---|---:|---:|---:|---:|
| health / 生命药剂 | 定值生命 | 60 | 140 | 300 | 600 |
| mana / 法力药剂 | 定值法力 | 40 | 90 | 180 | 360 |
| health-percent / 生命精华 | 生命上限比例 | 20% | 30% | 45% | 60% |
| mana-percent / 法力精华 | 法力上限比例 | 20% | 30% | 45% | 60% |

四种配方等概率，只有 16 种可堆叠规格；金药额外恢复另一资源上限的 15%，不抽随机附加词条。
主副生命恢复都乘 `1+regenBonus`，法力直接恢复，按使用时的上限计算并封顶，共用 4 秒冷却。
品质按基础掉落分布抽取；精英药剂保底蓝、领主保底金，宝箱采用该箱保底且药剂最高金。
宝珠寻宝不影响药剂品质。快捷键 Q/E 按主恢复资源选药：优先最小足量，否则选恢复最多的一瓶；
恢复量相同时优先低品质，再按 ID 升序。HUD 图标、详情和实际使用共用 `selectConsumable`，不依赖背包排序。

## 穿戴与奖励入包

穿戴/嵌珠先验证真实背包 ID、类型及槽位解锁条件，再移出新物品并返回旧物品；同分类满包仍可一换一。穿戴动作使装备上锁，换下后保留锁定；显式解锁的返包装备以新穿戴状态判断自动回收。直接卸下装备需要该类空格并完整保留物品，宝珠取下规则见[宝珠拖拽](#宝珠拖拽)。

宝箱在克隆的随机状态上生成实际奖励，并在库存副本上安排保留件和可合并堆叠。符合[自动回收](#分类回收与自动处理)的奖励不占背包格；全部保留奖励能容纳后，才一次提交库存、随机数、物品 ID、金币/粉尘和箱子消费。
容量不足不改变原堆叠、随机序列、ID 或奖励，清出空间后可重新尝试；不能只按箱子品质假定装备可丢弃。开箱受阻仍刷新地域宝箱表现缓存，避免显示过期列表。

## 通用图标

`IconFrame` 提供底图、主体、边框与角标，`ItemIcon` 和 `SkillIcon` 共用它。
`ItemIcon` 被背包、装备栏、宝珠槽、药剂快捷栏和拾取推荐共用。SVG 采用 48×48 坐标系，标准显示 44px，
装备槽缩放至 38px、宝珠与药剂快捷栏至 30px；缩放不改变四层结构。图标不依赖外部位图或字体符号资源。

1. 底图：固定圆角方形暗底，少量品质色渐变；空槽保留同一结构。
2. 主体：按 type/value 选图形。装备按部位，宝珠按四种子类；生命/法力用红色十字/蓝色液滴区分，定值用细口瓶，百分比用棱形瓶和 % 标记。功能色不替代品质边框。
3. 边框：同一品质色描边和内嵌线；焦点轮廓独立，不用改变品质来表达选择。
4. 角标：右下角统一位置；装备显示星数，药剂与精粹显示当前堆叠数量，宝珠不添加无意义数量 1。精粹主体为卷轴。

技能使用本地 64×64 彩色 SVG，图鉴 62px、桌面装配槽 48px、HUD 38px；窄屏分别缩为 62/42/34px。
技能角标显示等级，边框为中性颜色，主体和底图表达虚空/冰霜/雷霆/疾风/星辉。技能目前没有物品品质，不能将功能色当成品质或等级。

物品名称、边框、品质标签和地面战利品颜色都从 `GAME_CONFIG.quality` 读取：

| 品质 | 名称 | 颜色 |
|---|---|---|
| common | 白 | #c1cbc8 |
| magic | 蓝 | #83baff |
| rare | 紫 | #bc91f3 |
| legendary | 金 | #efc572 |
| diamond | 钻 | #80e6e0 |
| rainbow | 彩 | #f498d5 |

装备品质不取代装备等级或星级；药剂和宝珠不显示等级。显示名和详情中的品质文字保留，不能只靠颜色理解物品。
生命条、法力条、Boss 标识和地区难度色是各自语义色，不表达物品品质。

## 详情浮窗

`ItemTooltip` 与 `SkillTooltip` 共用 `IconTooltip`，只包裹通用图标按钮。卡片留白、名称、评分、操作按钮及装备槽标签都不触发浮窗。
悬停或键盘聚焦图标显示详情，未固定时离开图标立即关闭；鼠标经过浮窗本身不会续显，浮窗不拦截点击。

底部显示“Alt 固定浮窗 · 移开图标关闭”。按 Alt 固定后，可以移开图标并进入浮窗滚动、查看词条说明。
再次按 Alt、Esc、点击关闭按钮或浮窗外部会关闭；原图标卸载和浏览器失焦也会关闭。
触屏在触碰图标时固定，提供可见关闭按钮，不依赖硬件键盘。

`ItemTooltipProvider` 协调全局一个活动浮窗；固定期间悬停其他图标不替换当前内容。
技能与宝珠拖拽共用 `useSlotDrag`，达到 6px 门槛时关闭浮窗，拖拽期间不再显示；触屏轻触保留固定详情，拖动则装配。
Esc 优先关闭详情，下一次才关闭界面窗口。Portal 避免面板裁切，定位以图标边界和实际浮窗尺寸计算。

## 分类回收与自动处理

每个背包页签有独立品质上限，默认关闭，包含所选品质。装备/药剂/词条/卷轴自动售出换金币，宝珠自动分解换粉尘。
药剂只显示白/蓝/紫/金四档，其余分类显示白/蓝/紫/金/钻/彩。切页同时切换设置、说明和本类累计处理件数。
设置后立即处理库存，之后在加点、升级、换装、打造、解锁和入包边界应用同一规则；堆叠按整格回收。
各类物品均要求品质不高于本类阈值。装备额外要求未锁定、同部位已有装备且换装后的总战力严格降低；物品评分和等级不阻止清理。
品质未达阈值、已锁定或同部位为空的装备直接保留，不为这些必定保留的物品重复计算换装战力。
宝珠、药剂和精粹按各自品质阈值处理；已穿戴装备和已嵌宝珠不在背包清理范围。符合条件的地面物品即使满包也能自动回收。
战力提升、持平、空部位可用装备始终保留。手动穿戴装备设置 `locked=true`，换下后仍保持锁定；自动穿戴不增加锁，旧装淘汰见[挂机自动装配](#挂机自动装配)。
解锁立即应用自动售出规则；锁定的界面操作与显示见[界面设计](interface-design.md)。
锁定同时阻止售出、提取和作为继承来源。打造后的目标自动锁定；作为保留的目标可接受打入和继承，每次单窗确认。锁定不阻止穿戴。
换装战力与原始物品评分的区别见[战力与比较](#战力与比较)。
计数按物品件数累计，关闭停止之后的自动处理。权威模拟决定结果，界面使用同一换装评估解释保留原因。
回收收益由 `Recycling.ts` 定义：品质序号 `q` 从白 1 到彩 6，装备获得 `8*q*(星数+1)+2*等级` 金币，
药剂每瓶 `3*q` 金币，词条每份 `20*q` 金币；宝珠每颗 `3^(q-1)` 粉尘。回收不叠加寻宝金币加成。
无无偿丢弃命令。手动售出/分解只接受背包物品，单窗预览收益与整格销毁，再验证 ID/品质/数量/装备 revision 后原子提交。
清理只在状态变化边界执行，不增加每 tick 的背包全量扫描；关闭设置停止后续自动处理，新游戏恢复关闭和零计数。

手动“一键分解”按装备等级严格小于输入值筛选背包未锁定装备，跳过已穿戴装备；与自动回收不同，手动选择不按战力过滤。
一次确认窗列出实际装备、等级、总金币收益及不可撤销提示；提交捕获 ID+revision，任一装备变化/上锁/消失则整批拒绝，不把确认后新拾取的装备追加进去。
其收益与单件装备回收一致，均为金币。保留锁定保护，不提供隐式批量解锁。
打造费用、精粹事务、宝珠分解和继承详见[打造与灵境](crafting-and-spirit.md)。

## 宝珠拖拽

角色和背包宝珠页显示同一组槽；槽数、解锁等级与评分由[宝珠合同](combat-and-progression.md#六槽宝珠与寻宝算法)维护，共鸣由[打造合同](crafting-and-spirit.md#寻宝共鸣)维护。
背包宝珠可分解获得粉尘或用粉尘精炼到更高品质，规则见[打造与灵境](crafting-and-spirit.md)。背包图标拖到槽位嵌入或替换，已嵌宝珠互拖交换槽位；
双击槽位取下。满宝珠背包仍支持替换和槽间交换，直接取下需要空格，或满足自动分解品质条件。
被替换/取下的宝珠立即应用自动分解规则；设置命中的已嵌宝珠在槽下明确标记“取下分解”，留在槽内不会被分解。
删除目标槽下拉框及全局选槽状态。键盘聚焦宝珠图标按空格拿起，再按 1–6 指定槽，Esc 取消。
捕获指针支持鼠标、笔和触屏；无效落点、锁定槽、失焦、pointercancel、来源移除均取消，模拟层重复校验身份与解锁条件。

## 地面物品和品质表现

地面物品与经验的清理范围服从[玩法区块驻留](combat-and-progression.md#区块驻留与人口)：由 `WorldView.residentRadius` 定义保留窗口，`reconcileRegions` 在当前位置属于 `unloaded` 时删除实体、空间索引和对应 `groundItems` 引用。
返回不恢复旧掉落；重新生成的人口或宝箱可能产生新掉落。地面物品池容量及满载行为见[实体存储](simulation-and-ai.md#实体存储)，不设额外时间回收。

宝箱、武器、护甲标记和药瓶采用 [Kenney Mini Dungeon 2.0](https://kenney.nl/assets/mini-dungeon) 的 CC0 模型。
`assets/loot/sources.json` 记录原文件、来源和 SHA-256，构建用 `survivor-loot.mjs` 校验并将调色板烘焙为顶点颜色、合并与去重顶点。
运行时 `LootModels` 一次读取四模型，武器/护甲/饰品分别用剑/盾/环表示，宝珠用多面宝石，药瓶按资源着色、精华瓶放大。
装备部位的完整差异由 UI 图标表达；世界模型是大类标记。八类掉落池和一个宝箱池复用几何/材质，不逐物品克隆模型和纹理。
宝箱模型在构建时以底部归零并居中；`ChestGrounding` 按实际模型底部包围范围进行 5×5 高度采样，拟合坡面朝向，
再对旋转后的底面采样确定接触高度，避免只按中心高度摆放导致上坡侧下沉。箱体保持刚性，跨山脊时允许底面局部留缝。
地形高度沿用角色使用的微地形高度上界和间隙。放置矩阵缓存上限为 81，地形变化、区块挂载/卸载、重开时清空；
每帧仅换算相对玩家的坐标，不重复采样静止宝箱的底面。

| 品质 | 地面光效（`LootEffects`） | UI 图标 |
|---|---|---|
| 白 | 清晰单环、柔和辉光 | 静态描边 |
| 蓝 | 更亮单环、缓慢脉动 | 内发光 |
| 紫 | 流动外环、细光柱 | 低频扫光 |
| 金 | 更高光柱、环绕光点、上升光点 | 更快扫光、金色内光 |
| 钻 | 内外多环、更多光点 | 双流光、钻色内光 |
| 彩 | 连续光谱、三瓣波环、双螺旋光带 | 彩色底图与旋转光谱 |

宝箱按其最低品质共用光效。光环经地形投影贴地，光柱深度测试；跟随 `WorldView` 在 34–42 逻辑单位渐隐。
光环描边按投影纹素尺寸设置最低两纹素有效线宽并进行边缘抗锯齿，主环亮度保底，避免草地上细线消失和随镜头位移断续。
光柱保留连续亮芯和渐隐光晕，使用绕世界竖轴朝向相机的公告板，旋转视角仍保持可见；普通白蓝掉落不生成光柱。
品质、颜色和实例距离使用 `flat` 插值；有符号距离的平方采用乘法，避免负数 `pow` 的未定义结果产生异常条纹。
光柱顶部衰减在乘幂前截断到非负值，覆盖 MSAA 边缘像素中心落在平面外、UV 略微越界的确定性情况。
光效固定两个实例批次，各上限 `64+81`，动画由 GPU 按模拟时间计算，暂停冻结，不创建逐物品灯光、计时器或无界粒子。
UI 使用 CSS 动画，尊重 `prefers-reduced-motion`；背包/打造的虚拟格子只在悬停或聚焦时运行流光，其余保留静态品质样式。流光层不拦截输入，品质名仍可读。
