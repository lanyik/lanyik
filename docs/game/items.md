# 通用物品与图标规范

物品定义、背包事务与所有界面图标使用同一合同。固定参数由 `apps/survivor/src/core/GameConfig.ts` 定义，
`ItemDefinition.ts` 约束公共字段，`InventoryItem.ts` 提供可辨别联合类型，`Inventory.ts` 执行分类容量和堆叠事务。

## 数据与容量

| 字段 | 含义 |
|---|---|
| id | 局内唯一物品/堆叠 ID；排序、选择、命令和浮窗身份使用它 |
| type | 大类，也是所属背包：equipment、orb、consumable |
| value | 大类下的子类；装备部位、宝珠类型或药剂恢复资源 |
| size | 当前格的数量；装备和宝珠固定 1，药剂为 1–99 |
| itemLevel / rarity / name | 等级、品质与显示名；具体属性保留在各自类型中 |

| type | value | 独立容量 | 堆叠上限 |
|---|---|---:|---:|
| equipment | weapon/head/chest/legs/boots/arms/hands/ring/necklace/bracelet/charm | 40 格 | 1 |
| orb | fortune/bounty/constellation/harmony | 24 格 | 1 |
| consumable | health/mana | 16 格 | 99 |

`value` 只表达子类，不复用为属性数值；`size` 表达数量，不表达图标像素大小或物品占用格形状。
`TypedValue<T,V>` 是物品与技能共用的大类/子类身份。技能定义为 `type: "skill"`、`value: pulse/frost/chain/dash/ward`，
另有解锁条件和独立技能等级；技能不堆叠、不占背包，不虚设 size、物品 ID 或背包容量。
背包内存仍是有界联合数组，分类容量分别计算，穿戴装备和已嵌宝珠不占背包格。不存在共享的总格数限制。

药剂只有 value、等级、品质、恢复量全部相同时才可合并。拾取先补已有同规格堆叠，再为余量占一格；
空间不足时整个拾取不提交，原有堆叠和地面物品数量不变。已有堆叠保留原 ID，新格保留新物品 ID。
显式“合并药剂”按当前背包顺序紧凑合并，先出现的 ID 保留，数量和药效守恒；整理只排序，不隐式改变选择的物品身份。
使用药剂只减少一瓶，数量为零才移除格；HUD 显示所有相应子类堆叠的总瓶数。
暂停、药剂冷却中或对应资源已满时禁用使用按钮，图标仍可显示详情。

同分类满包仍可穿戴/嵌珠交换，直接卸下必须有该分类的空格。宝箱先在副本上安排每一类奖励和堆叠，
全部能容纳后才提交库存、随机数、ID、金币和开箱状态，阻塞时不会先合并药剂再丢失其他奖励。
开箱受阻仍刷新地区宝箱的渲染缓存，避免地区变化后保留过时的宝箱显示。

## 通用图标

`IconFrame` 提供底图、主体、边框与角标，`ItemIcon` 和 `SkillIcon` 共用它。
`ItemIcon` 被背包、装备栏、宝珠槽、药剂快捷栏和拾取推荐共用。SVG 采用 48×48 坐标系，标准显示 44px，
装备槽缩放至 38px、宝珠与药剂快捷栏至 30px；缩放不改变四层结构。图标不依赖外部位图或字体符号资源。

1. 底图：固定圆角方形暗底，少量品质色渐变；空槽保留同一结构。
2. 主体：按 type/value 选图形。装备按部位，宝珠按四种子类，生命/法力药剂用十字/液滴区分。
3. 边框：同一品质色描边和内嵌线；焦点轮廓独立，不用改变品质来表达选择。
4. 角标：右下角统一位置；装备显示星数，药剂显示当前堆叠数量，宝珠不添加无意义数量 1。

技能使用本地 64×64 彩色 SVG，图鉴 62px、桌面装配槽 48px、HUD 38px；窄屏分别缩为 62/42/34px。
技能角标显示等级，边框为中性颜色，主体和底图表达虚空/冰霜/雷霆/疾风/星辉。技能目前没有物品品质，不能将功能色当成品质或等级。

物品名称、边框、品质标签和地面战利品颜色都从 `GAME_CONFIG.quality` 读取：

| 品质 | 名称 | 颜色 |
|---|---|---|
| common | 白 | #c1cbc8 |
| magic | 蓝 | #83baff |
| rare | 紫 | #bc91f3 |
| legendary | 金 | #efc572 |
| diamond | 钻 | #80e6e0 |
| rainbow | 彩 | #f498d5 |

品质不取代等级或星级；显示名和详情中的品质文字保留，不能只靠颜色理解物品。
生命条、法力条、Boss 标识和地区难度色是各自语义色，不表达物品品质。

## 详情浮窗

`ItemTooltip` 与 `SkillTooltip` 共用 `IconTooltip`，只包裹通用图标按钮。卡片留白、名称、评分、操作按钮及装备槽标签都不触发浮窗。
悬停或键盘聚焦图标显示详情，未固定时离开图标立即关闭；鼠标经过浮窗本身不会续显，浮窗不拦截点击。

底部显示“Alt 固定浮窗 · 移开图标关闭”。按 Alt 固定后，可以移开图标并进入浮窗滚动、查看词条说明。
再次按 Alt、Esc、点击关闭按钮或浮窗外部会关闭；原图标卸载和浏览器失焦也会关闭。
触屏在触碰图标时固定，提供可见关闭按钮，不依赖硬件键盘。

`ItemTooltipProvider` 协调全局一个活动浮窗；固定期间悬停其他图标不替换当前内容。
技能拖拽达到 6px 门槛时关闭浮窗，拖拽期间不再显示；触屏轻触保留固定详情，拖动则装配。
Esc 优先关闭详情，下一次才关闭界面窗口。Portal 避免面板裁切，定位以图标边界和实际浮窗尺寸计算。

## 自动清理

只有一个默认关闭的“自动清理”开关，开启后立即处理库存，之后在加点、升级、换装和入包边界应用同一规则。
同部位已有装备、换装后的总战力严格降低、物品评分不更高，三个条件同时满足才清理；不再额外按等级筛选。
战力提升、持平、空部位可用装备、高评分专项装备、宝珠和药剂始终保留，已穿戴物品不参与清理。
换装战力使用有效属性：命中、防暴、爆伤减免超过当前敌方规则的收益上限后不再加分；原始物品评分仍独立保留。
因此同样达到命中上限时，额外伤害不会被无效命中溢出的评分压过；对应回归覆盖实际入包和自动清理事务。
计数累计，清理不奖励金币；关闭只停止之后的自动处理。权威模拟决定结果，界面使用同一换装评估解释保留原因。
