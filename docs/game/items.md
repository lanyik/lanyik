# 通用物品与图标规范

物品定义、背包事务与所有界面图标使用同一合同。固定参数由 `apps/survivor/src/core/GameConfig.ts` 定义，
`ItemDefinition.ts` 约束公共字段，`InventoryItem.ts` 提供可辨别联合类型，`Inventory.ts` 执行分类容量和堆叠事务。

## 数据与容量

| 字段 | 含义 |
|---|---|
| id | 局内唯一物品/堆叠 ID；排序、选择、命令和浮窗身份使用它 |
| type | 大类，也是所属背包：equipment、orb、consumable、affix |
| value | 大类下的子类；装备部位、宝珠类型、药剂配方或词条属性 ID |
| size | 当前格的数量；装备和宝珠固定 1，药剂与词条为 1–99 |
| rarity / name | 品质与显示名；具体属性保留在各自类型中 |
| itemLevel | 仅装备拥有等级；药剂与宝珠不存在该字段 |

| type | value | 独立容量 | 堆叠上限 |
|---|---|---:|---:|
| equipment | weapon/head/chest/legs/boots/arms/hands/ring/necklace/bracelet/charm | 80 格 | 1 |
| orb | fortune/bounty/constellation/harmony | 48 格 | 1 |
| consumable | health/mana/health-percent/mana-percent | 32 格 | 99 |
| affix | BONUS_INFO 中的属性 ID | 80 格 | 99 |

`value` 只表达子类，不复用为属性数值；`size` 表达数量，不表达图标像素大小或物品占用格形状。
`TypedValue<T,V>` 是物品与技能共用的大类/子类身份。技能定义为 `type: "skill"`、`value: pulse/frost/chain/dash/ward`，
另有解锁条件和独立技能等级；技能不堆叠、不占背包，不虚设 size、物品 ID 或背包容量。
背包内存仍是有界联合数组，分类容量分别计算，穿戴装备和已嵌宝珠不占背包格。不存在共享的总格数限制。

药剂由固定配方和品质唯一决定药效，只有 value、品质相同才可合并。拾取先补已有同规格堆叠，再为余量占一格；
空间不足时整个拾取不提交，原有堆叠和地面物品数量不变。已有堆叠保留原 ID，新格保留新物品 ID。
显式“合并药剂”和整理先按当前背包顺序紧凑合并兼容堆叠，先出现的 ID 保留，数量和药效守恒；整理再排序，已合并消失的 ID 不再可操作。
词条精粹另有 `amount` 数值，只有属性、数值、品质完全相同才堆叠；提取时自动补满同规格堆叠。
通用紧凑合并同时处理可堆叠的精粹，装备与宝珠保持独立格。精粹不设等级，不生成随机额外属性。
使用药剂只减少一瓶，数量为零才移除格；HUD 显示所有相应子类堆叠的总瓶数。
暂停、药剂冷却中或该药能恢复的全部资源已满时禁用使用按钮，图标仍可显示详情。

### 固定药剂配方

`InventoryItem.ts` 的 `POTIONS` 和 `POTION_RARITIES` 是配方与数值的唯一来源，不随地域或角色等级增加规格。

| value / 名称 | 恢复方式 | 白 | 蓝 | 紫 | 金 |
|---|---|---:|---:|---:|---:|
| health / 生命药剂 | 定值生命 | 60 | 140 | 300 | 600 |
| mana / 法力药剂 | 定值法力 | 40 | 90 | 180 | 360 |
| health-percent / 生命精华 | 生命上限比例 | 20% | 30% | 45% | 60% |
| mana-percent / 法力精华 | 法力上限比例 | 20% | 30% | 45% | 60% |

四种配方等概率，只有 16 种可堆叠规格；金药额外恢复另一资源上限的 15%，不抽随机附加词条。
主副生命恢复都乘 `1+regenBonus`，法力直接恢复，按使用时的上限计算并封顶，共用 4 秒冷却。
品质按基础掉落分布抽取；精英药剂保底蓝、领主保底金，宝箱采用该箱保底且药剂最高金。
宝珠寻宝不影响药剂品质。快捷键 Q/E 按主恢复资源选药：优先最小足量，否则选恢复最多的一瓶；
恢复量相同时优先低品质，再按 ID 升序。HUD 图标、详情和实际使用共用 `selectConsumable`，不依赖背包排序。

同分类满包仍可穿戴/嵌珠交换，直接卸下必须有该分类的空格。宝箱先在副本上安排每一类奖励和堆叠，
全部能容纳后才提交库存、随机数、ID、金币和开箱状态，阻塞时不会先合并药剂再丢失其他奖励。
开箱受阻仍刷新地区宝箱的渲染缓存，避免地区变化后保留过时的宝箱显示。

## 通用图标

`IconFrame` 提供底图、主体、边框与角标，`ItemIcon` 和 `SkillIcon` 共用它。
`ItemIcon` 被背包、装备栏、宝珠槽、药剂快捷栏和拾取推荐共用。SVG 采用 48×48 坐标系，标准显示 44px，
装备槽缩放至 38px、宝珠与药剂快捷栏至 30px；缩放不改变四层结构。图标不依赖外部位图或字体符号资源。

1. 底图：固定圆角方形暗底，少量品质色渐变；空槽保留同一结构。
2. 主体：按 type/value 选图形。装备按部位，宝珠按四种子类；生命/法力用红色十字/蓝色液滴区分，定值用细口瓶，百分比用棱形瓶和 % 标记。功能色不替代品质边框。
3. 边框：同一品质色描边和内嵌线；焦点轮廓独立，不用改变品质来表达选择。
4. 角标：右下角统一位置；装备显示星数，药剂与精粹显示当前堆叠数量，宝珠不添加无意义数量 1。精粹主体为卷轴。

技能使用本地 64×64 彩色 SVG，图鉴 62px、桌面装配槽 48px、HUD 38px；窄屏分别缩为 62/42/34px。
技能角标显示等级，边框为中性颜色，主体和底图表达虚空/冰霜/雷霆/疾风/星辉。技能目前没有物品品质，不能将功能色当成品质或等级。

物品名称、边框、品质标签和地面战利品颜色都从 `GAME_CONFIG.quality` 读取：

| 品质 | 名称 | 颜色 |
|---|---|---|
| common | 白 | #c1cbc8 |
| magic | 蓝 | #83baff |
| rare | 紫 | #bc91f3 |
| legendary | 金 | #efc572 |
| diamond | 钻 | #80e6e0 |
| rainbow | 彩 | #f498d5 |

装备品质不取代装备等级或星级；药剂和宝珠不显示等级。显示名和详情中的品质文字保留，不能只靠颜色理解物品。
生命条、法力条、Boss 标识和地区难度色是各自语义色，不表达物品品质。

## 详情浮窗

`ItemTooltip` 与 `SkillTooltip` 共用 `IconTooltip`，只包裹通用图标按钮。卡片留白、名称、评分、操作按钮及装备槽标签都不触发浮窗。
悬停或键盘聚焦图标显示详情，未固定时离开图标立即关闭；鼠标经过浮窗本身不会续显，浮窗不拦截点击。

底部显示“Alt 固定浮窗 · 移开图标关闭”。按 Alt 固定后，可以移开图标并进入浮窗滚动、查看词条说明。
再次按 Alt、Esc、点击关闭按钮或浮窗外部会关闭；原图标卸载和浏览器失焦也会关闭。
触屏在触碰图标时固定，提供可见关闭按钮，不依赖硬件键盘。

`ItemTooltipProvider` 协调全局一个活动浮窗；固定期间悬停其他图标不替换当前内容。
技能与宝珠拖拽共用 `useSlotDrag`，达到 6px 门槛时关闭浮窗，拖拽期间不再显示；触屏轻触保留固定详情，拖动则装配。
Esc 优先关闭详情，下一次才关闭界面窗口。Portal 避免面板裁切，定位以图标边界和实际浮窗尺寸计算。

## 分类回收与自动处理

每个背包页签有独立品质上限，默认关闭，包含所选品质。装备/药剂/词条自动售出换金币，宝珠自动分解换粉尘。
药剂只显示白/蓝/紫/金四档，其余分类显示白/蓝/紫/金/钻/彩。切页同时切换设置、说明和本类累计处理件数。
选择后立即处理已有背包物品，之后拾取和宝箱奖励也执行同一规则；堆叠按整格回收。
设置后立即处理库存，之后在加点、升级、换装、打造、解锁和入包边界应用同一规则。
品质不高于阈值、未锁定、同部位已有装备且换装后的总战力严格降低时才清理；物品评分和等级不再阻止清理。
战力提升、持平、空部位可用装备始终保留。曾穿戴的装备自动设置 `locked=true`，换下后仍保持锁定。
背包与打造均支持 Ctrl＋点击格子、Ctrl＋空格快速锁定/解锁，触屏使用统一“锁定模式”；移除逐格锁定按钮。解锁立即应用自动售出规则。整格锁纹、大锁水印和角标共同标记锁定。
锁定同时阻止售出、提取和作为继承来源。打造后的目标自动锁定；作为保留的目标可接受打入和继承，每次单窗确认。锁定不阻止穿戴。
换装战力使用有效属性：命中、防暴、爆伤减免超过当前敌方规则的收益上限后不再加分；原始物品评分仍独立保留。
因此同样达到命中上限时，额外伤害不会被无效命中溢出的评分压过；对应回归覆盖实际入包和自动清理事务。
计数按物品件数累计，关闭停止之后的自动处理。权威模拟决定结果，界面使用同一换装评估解释保留原因。
回收收益由 `Recycling.ts` 定义：品质序号 `q` 从白 1 到彩 6，装备获得 `8*q*(星数+1)+2*等级` 金币，
药剂每瓶 `3*q` 金币，词条每份 `20*q` 金币；宝珠每颗 `3^(q-1)` 粉尘。回收不叠加寻宝金币加成。
无无偿丢弃命令。手动售出/分解只接受背包物品，单窗预览收益与整格销毁，再验证 ID/品质/数量/装备 revision 后原子提交。
打开背包先执行一次整理：合并同规格药剂/词条堆叠，按品质、装备等级、类型/value 和 ID 排序；之后的新物品仍追加。

手动“一键分解”按装备等级严格小于输入值筛选背包未锁定装备，跳过已穿戴装备；与自动回收不同，手动选择不按战力过滤。
一次确认窗列出实际装备、等级、总金币收益及不可撤销提示；提交捕获 ID+revision，任一装备变化/上锁/消失则整批拒绝，不把确认后新拾取的装备追加进去。
其收益与单件装备回收一致，均为金币。保留锁定保护，不提供隐式批量解锁。
打造费用、精粹事务、宝珠分解和继承详见[打造与灵境](crafting-and-spirit.md)。

## 宝珠拖拽

角色和背包宝珠页都显示同一组六槽；前两槽立即可用，其余由角色 50/100/150/200 级解锁。
单颗宝珠强度只取决于类型和品质，不设宝珠等级；已嵌组合可触发同类评分、金币和打造消耗共鸣。
背包宝珠可分解获得粉尘或用粉尘精炼到更高品质，规则见[打造与灵境](crafting-and-spirit.md)。背包图标拖到槽位嵌入或替换，已嵌宝珠互拖交换槽位；
双击槽位取下。满宝珠背包仍支持替换和槽间交换，直接取下需要空格，或满足自动分解品质条件。
被替换/取下的宝珠立即应用自动分解规则；设置命中的已嵌宝珠在槽下明确标记“取下分解”，留在槽内不会被分解。
删除目标槽下拉框及全局选槽状态。键盘聚焦宝珠图标按空格拿起，再按 1–6 指定槽，Esc 取消。
捕获指针支持鼠标、笔和触屏；无效落点、锁定槽、失焦、pointercancel、来源移除均取消，模拟层重复校验身份与解锁条件。

## 地面物品和品质表现

离开以玩家所在区块为中心、切比雪夫半径 3 的保留范围后，`reconcileRegions` 删除地面实体、空间索引及 `groundItems` 引用；
经验球同样删除。区块边长 12，并非圆形固定距离。返回不会恢复原掉落；地域人口和未持久化宝箱可按种子重新生成，可能产生新掉落。
地面所有物品共用 64 个容量，经验球独立上限 768；容量满时不再创建对应掉落，不设额外时间回收。

宝箱、武器、护甲标记和药瓶采用 [Kenney Mini Dungeon 2.0](https://kenney.nl/assets/mini-dungeon) 的 CC0 模型。
`assets/loot/sources.json` 记录原文件、来源和 SHA-256，构建用 `survivor-loot.mjs` 校验并将调色板烘焙为顶点颜色、合并与去重顶点。
运行时 `LootModels` 一次读取四模型，武器/护甲/饰品分别用剑/盾/环表示，宝珠用多面宝石，药瓶按资源着色、精华瓶放大。
装备部位的完整差异由 UI 图标表达；世界模型是大类标记。八类掉落池和一个宝箱池复用几何/材质，不逐物品克隆模型和纹理。
宝箱模型在构建时以底部归零并居中；`ChestGrounding` 按实际模型底部包围范围进行 5×5 高度采样，拟合坡面朝向，
再对旋转后的底面采样确定接触高度，避免只按中心高度摆放导致上坡侧下沉。箱体保持刚性，跨山脊时允许底面局部留缝。
地形高度沿用角色使用的微地形高度上界和间隙。放置矩阵缓存上限为 49，地形变化、区块挂载/卸载、重开时清空；
每帧仅换算相对玩家的坐标，不重复采样静止宝箱的底面。

| 品质 | 地面光效（`LootEffects`） | UI 图标 |
|---|---|---|
| 白 | 清晰单环、柔和辉光 | 静态描边 |
| 蓝 | 更亮单环、缓慢脉动 | 内发光 |
| 紫 | 流动外环、细光柱 | 低频扫光 |
| 金 | 更高光柱、环绕光点、上升光点 | 更快扫光、金色内光 |
| 钻 | 内外多环、更多光点 | 双流光、钻色内光 |
| 彩 | 连续光谱、三瓣波环、双螺旋光带 | 彩色底图与旋转光谱 |

宝箱按其最低品质共用光效。光环经地形投影贴地，光柱深度测试；24–30 逻辑单位渐隐。
光环描边按投影纹素尺寸设置最低两纹素有效线宽并进行边缘抗锯齿，主环亮度保底，避免草地上细线消失和随镜头位移断续。
光柱保留连续亮芯和渐隐光晕，使用绕世界竖轴朝向相机的公告板，旋转视角仍保持可见；普通白蓝掉落不生成光柱。
品质、颜色和实例距离使用 `flat` 插值；有符号距离的平方采用乘法，避免负数 `pow` 的未定义结果产生异常条纹。
光柱顶部衰减在乘幂前截断到非负值，覆盖 MSAA 边缘像素中心落在平面外、UV 略微越界的确定性情况。
光效固定两个实例批次，各上限 `64+49`，动画由 GPU 按模拟时间计算，暂停冻结，不创建逐物品灯光、计时器或无界粒子。
UI 使用 CSS 动画，尊重 `prefers-reduced-motion`；背包/打造的虚拟格子只在悬停或聚焦时运行流光，其余保留静态品质样式。流光层不拦截输入，品质名仍可读。
