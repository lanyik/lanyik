# 荒原场景比例与环境资产

`HexCombatView.ts`、`scripts/lib/survivor-environment.mjs` 和 `assets/environment/sources.json` 共同定义应用场景。
角色模型基准见[角色资产](actor-assets.md)；地貌与地表权威仍使用[世界生成合同](../world-style-generation-v1.md)。

## 比例

一个游戏单位等于 34 世界单位，主角站立基准 1.6，即 54.4 世界单位；敌人继续按玩法半径缩放，精英/领主保持可识别轮廓。
树模型在构建时居中并将根部归零，再归一到下表高度；应用 `treeScale=1`，运行时稳定抖动为 0.8–1.2。

| 树种 | 原始模型 | 基准高度 | 相对主角高度 | 近/中/远三角形数 |
|---|---|---:|---:|---|
| 温带 oak | tree_detailed | 155 | 2.85 倍 | 402 / 392 / 382 |
| 寒地 pinia | tree_pineTallA_detailed | 185 | 3.40 倍 | 134 / 134 / 122 |
| 热带 palm | tree_palmDetailedTall | 175 | 3.22 倍 | 336 / 336 / 336 |

森林每格候选密度由 1 降至 0.45，`treesPerTile` 支持非负小数密度，扩大采样间距而非把树随机隐藏。实际仍受气候、水岸和远距密度裁减控制。草高为 3。
山体显示幅度为 220；v20 扩大连续地貌尺度，陆地高低场频率 .052→.014，山脊场 .032→.012，海域噪声保持原参数。
生物的陡坡、树干与水体阻挡及刷怪净空见[地形通行](terrain-navigation.md)。
角色、宝箱、植被均读取该显示尺度下的同一地表。宝箱继续按底面采样贴坡；山脊上的刚性箱体允许局部留缝。

## 资产处理

树木来自 [Kenney Nature Kit](https://kenney.nl/assets/nature-kit)，CC0。OBJ/MTL 和原许可证固定入库，构建验证 SHA-256。
`.gitattributes` 保留这些原始文件的字节与发布者空白，防止跨平台换行转换破坏来源校验。
保持枝干/树冠原模型结构，叶片收敛为 `#52745c`、树皮为 `#71533c`；材质颜色烘焙进顶点，合并为单个 primitive。
三档 LOD 复用引擎已有 Meshoptimizer 离线简化器，保留物理边界、表面接缝和连通分量。
低面数/边界受限模型允许保持面数，不强制破坏轮廓；远档实例密度仍裁减。运行时仍为各块 InstancedMesh，不新增逐树材质或纹理。
应用覆盖生成目录内的 oak/pinia/palm 资产路径，程序化气候树种映射无需改写；根包演示模型保持独立。

山岩使用 [Poly Haven Rocky Terrain](https://polyhaven.com/a/rocky_terrain)，草地碎石使用
[Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02)，均为 CC0 漫反射资源；保留原 1K 文件与下载地址、作者、SHA-256。
构建以饱和度 .6、亮度 .85 缩至 512 格，分别写入 mountain 与 `_plains`。land 保持原图的低饱和苔绿；其余格保留原语义。
应用图集 2048²、格尺寸 512、间距 4，运行时每层剥除边距后为 504²；8 个独立材质层及 mip 链约 10.34 MiB RGBA。
不上传完整图集与分层纹理两份 GPU 副本，不使用位移贴图或额外法线贴图。离线处理和来源哈希使正常构建不依赖网络。

## 表面变化与开销

应用纹理周期为 4 格（原 2），像素粒度与角色比例统一。full/fast 共用两个显式梯度采样，
宏观噪声控制偏移之间的连续混合，世界相位与跨块浮动原点保持已有合同；未引入逐格随机旋转造成接缝。
顶点世界坡度在 .22–.85 区间增加岩石覆盖，最大 85%；平坡不采额外岩石，原 mountain 不再次采岩。
气候、宏观色变和雪线继续表达温带/干燥/寒地/高山差异；生成器已升级 v20，不引入额外生物群落。
主要开销是每材质由一次变两次纹理读取、陡坡另采岩石；相对抵消来自更少树实例及更低树面数。
实际浏览器验收同时覆盖地形/坡面宝箱、掉落投影与桌面/窄屏 UI，不能仅凭 shader 字符串测试宣称画面正确。

已有 full/fast 森林、坡面接触与亚纹素光环回归继续覆盖渲染。v20 固定 `new-world`、[-256,256)² 的四邻域山地连通观测：
最大连片山地由 957 格增至 2018 格，分量由 241 减至 76，总山地格 18455→13444；更连续不等于把所有区域都变成高山。
同次采样计时 245→230 ms，只作为本机观测，不据此宣称跨机器加速。新增导航基准及缓存开销见[地形通行](terrain-navigation.md)。
