# 荒原视觉与怪物体验评估

评估日期：2026-09-13。目标为现代暗黑奇幻：写实材质、克制配色、明确战斗轮廓；优先可商用免费资源。
本页区分已经实现的修正与尚未实现的美术路线。当前作品仍是可玩原型，没有完成次世代美术替换。

## 当前限制与本次修正

## 下一阶段的实现顺序（尚未实现）

先完成一块固定种子的可玩山谷样板：同一相机下包含林地、裸岩坡面、一条可通行山口、主脊远景和一组怪物。样板通过后再扩到全部生物群落。

1. **环境与光照**：先替换一套针叶树，保留自然枝干和透光叶片轮廓；离线制作近/中/远 LOD，并让森林材质真实使用法线、粗糙度和 alpha-test。地表补充同来源法线/粗糙度，统一阳光方向与角色光照，再评估接触阴影。已有地面投影是局部光环/阴影，不是完整场景投影阴影。
2. **地貌构图**：同时验收侧面剪影和俯视通行，不再仅用山地格连通数验收山势。需要主脊、支脊、谷地的轮廓后，再修改连续生成场；修改生成语义时升级生成器版本、重算固定指标和水系/导航身份。近景战斗镜头必须保留可见地面与输入方向可读性。
3. **敌人组合**：先接入“骨兵、持盾骨卫、四足猎兽、施法者”四类不同轮廓。每种都要求专用 Idle / Move / Attack；四足骨架走自己的动作烘焙，不能强行重定向现有人形 UAL。再扩弓手或潜伏者，并让出生组合表达近战压力、侧翼与支援，不继续用重复换色扩充物种数量。
4. **战斗与界面**：加入有上限的近战占位和攻击间隔，避免所有敌人挤向同一中心；受击与死亡演出必须对应权威状态。统一 HUD、地图、背包、工坊的边框、字号、留白和材质，仅在需要操作时显示次级信息；诊断始终可显式展开。

候选预算应在样板上验证：普通敌人近景约 5K–12K 三角形、单个主材质；树木近景约 3K–8K，中景约 1K–2K，远景数百三角形或离线代理。它们是制作起点，不是已经测得的性能结论。叶片 overdraw、morph 数据量、纹理显存和同时可见实例数必须一起测量。

继续使用现有有界实例池、空间查询和流式世界；没有证据表明改成 WebGPU 会自动改善当前美术。若目标明确变为 UE5 的 Nanite/Lumen 级生产管线，应另行做引擎迁移评估，不能把 Three.js 的资源替换描述成已经获得这些系统。

## 验证边界

本次使用应用单测保护独立 Idle 循环、攻击隔离、远程撤退缓冲、冷却绕行、受压治疗与朝向、受阻巡逻；原有地形测试保护真实树干碰撞、刷怪/宝箱净空和缓存边界。
浏览器验收覆盖真实 GLB、贴图、morph、攻击预警、暂停、界面操作以及斜坡上的宝箱/掉落投影。CPU 基准检查现有预算，不把软件 WebGL 截图速度当作物理显卡性能。
山体幅度会改变坡面通行范围；读档继续使用现有净空校验，对当前地形中受阻的位置明确拒绝，不进行隐式位置迁移。
