# 荒原免费美术与渲染升级

更新：2026-09-13。方向为现代暗黑奇幻，采用可离线构建的免费资源与程序化建模；没有美元支付、商店账户、Unity 或 UE 编辑器依赖。

## 已接入游戏

| 部分 | 实际实现 | 边界 |
|---|---|---|
| 森林 | EZ-Tree 生成橡树、松树、干地白蜡树；真实枝干、透明叶片、三档固定骨架 LOD；ambientCG 扫描树皮的颜色/法线/粗糙度；薄叶背光透射 | 仍按区块实例化，没有逐树阴影、实时树木生成或 Nanite |
| 地表 | Poly Haven 林地与两种岩地的颜色、法线、粗糙度和 AO；共享 GGX 高光与坡面混合；full/fast 均接入 | 材质细节不是几何位移；没有将纹理改善描述为重新生成山系 |
| 光照 | 地面、水面、天空和标准材质模型使用相同世界太阳方向；水面视线也转换到法线所在空间 | 战斗层保留独立补光，地面仍使用自定义显示颜色输出，未实现完整场景间接照明 |
| 怪物轮廓 | 裂隙蛛兽替代小恶魔斥候，裂岩守卫替代地精重卫；两者程序化建模、各自步态/攻击/三秒呼吸，沿用有界 morph 实例池 | 六种行为角色不变；现有地精、施法小恶魔和游侠仍偏风格化；新模型也不等同于专业雕刻的写实角色 |
| 怪物行为 | 冷却侧移、撤退缓冲、受压治疗、巡逻净空、受阻换点和真实移动朝向 | 群体攻击占位、受击/死亡演出尚未实现 |
| 山体与地图 | 连续 v20 山脊；应用高度 480、远景雾 820–1450；地图分页绘制稳定 | 山前平原、支脊、主谷的构图仍需生成器专项改进；本次没有再修改生成语义 |
| 界面 | 石墨蓝灰与暖金 HUD，诊断折叠、启动地图平滑显示，保留键盘与窄屏操作 | 尚未全面替换图标与掉落物模型，不能称为完整次世代美术改造 |

## 成本与验证

地形图集清除八个空槽后，两份八层 504² 数组连同 mip 约 20.67 MiB，等于此前一份十六层颜色数组；新增材质有额外纹理读取和像素着色成本。森林每种两部件，LOD 面数与资源所有权见环境合同。

六个角色 GLB、二十四张角色图集约 22.35 MiB。主角一组、敌人五组模型池；移除了不再被玩法使用的独立 Imp 生产模型。源 Imp 仍为术士构建输入。

回归覆盖 PBR 通道保留、原材质不被修改、LOD 材质共享、线性材质字节完整性、失败/取消不上传，以及真实游戏中的资产请求、动作、资源失败重试和释放。画面检查使用固定种子 `rift-ember-1` 的山脊、林地、完整战斗场景，以及中性光照下两种新怪物的姿势。

2026-09-13 验证记录：根包 417、应用 181 项单测通过；应用 20 项浏览器回归在 RTX 3060 Ti 上通过，包含新 full/fast 材质与连续世界替换；500 次世界替换 soak 通过。模拟 CPU 基准 travel .112、crowded .728、terrain .238 ms/tick，均在现有预算内，不能作为 GPU 帧率结论。26 份环境源文件的字节数与 SHA-256 全部验证。

根包软件 WebGL 全套初次 24 项通过、1 项计划 soak 跳过、小地图等待 1 项超时；该项保持原超时参数独立重跑通过。最终 shader 又通过 full 链接和双质量地面投影检查。5173 开发页也曾在并发验收期间等待超时，单独重跑已通过，未放宽检查阈值。生产构建、类型检查、优化门禁和生成文件一致性作为提交检查。

后续质量重点仍是山谷构图、林下地表遮蔽、专业角色造型与受击/死亡表现；本次交付是已运行的免费资产与渲染升级，不承诺已达到 UE5/Lumen/Nanite 的画面。
