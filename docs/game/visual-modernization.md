# 荒原免费美术与渲染升级

导航：[总导航 · 游戏设计](../README.md#game) · [按任务阅读](../README.md#routes)

方向为现代暗黑奇幻，采用可离线构建的免费资源与程序化建模；没有美元支付、商店账户、Unity 或 UE 编辑器依赖。本页定义整体美术方向与当前效果，各部分的实现规则由下方角色、环境和界面设计负责。

## 已接入游戏

| 部分 | 实际实现 | 边界 |
|---|---|---|
| 森林 | EZ-Tree 生成橡树、松树、干地白蜡树；真实枝干、透明叶片、三档固定骨架 LOD；ambientCG 扫描树皮的颜色/法线/粗糙度；薄叶背光透射 | 仍按区块实例化，没有逐树阴影、实时树木生成或 Nanite |
| 地表 | ambientCG Grass005 草坪、Poly Haven 林土与岩石；草土斑块、地类边界和坡面裸岩连续混合，full/fast 均接入 | 不再用林地碎石代替全部草原；微材质不改变碰撞高度 |
| 光照 | 地面、水面、天空和标准材质模型使用相同世界太阳方向；水面视线也转换到法线所在空间 | 战斗层保留独立补光，地面仍使用自定义显示颜色输出，未实现完整场景间接照明 |
| 天空与视野 | HDR 天空盒独立于地面雾；`WorldView` 统一地形视距 2312、植被 1700、地形雾 1156–1700 显示单位，近地雾 20/34/44/50 游戏单位；怪物在 34–42 淡出、44/46 唤醒/休眠，四圈 81 块提前驻留 | 固定天空，无昼夜循环；256² 六面纹理含 mip 约 4 MiB；近圈仇恨和战斗频率不随视野扩大 |
| 怪物轮廓 | 裂隙蛛兽替代小恶魔斥候，裂岩守卫替代地精重卫；两者程序化建模、各自步态/攻击/三秒呼吸，沿用有界 morph 实例池 | 六种行为角色不变；现有地精、施法小恶魔和游侠仍偏风格化；新模型也不等同于专业雕刻的写实角色 |
| 怪物行为 | 聚落驻留与同营血契；术士三发弯刃、领主两侧獠牙夹击/狂暴前扫、岩卫推进石脊，伤害跟随实际攻击轨迹；祭司消耗自身生命治疗同伴，附三秒护骨；140ms 动作过渡，飞刃与连线跟随真实施法手 | 敌方使用实体攻击和线形预警，独立于玩家法阵；聚落尚无建筑交互，群体攻击占位、受击/死亡演出未实现 |
| 山体与地图 | v22 降低短尺度噪声与平原粗糙度，保留缓丘、山脉、高峰的连续高度、低谷山口与峰顶压缩；高度幅度 480 | 不保证任意山体可翻越；40° 以上坡面和水体仍阻挡 |
| 通行与观察 | 接触切线滑行、圆形树干肩侧绕行、平滑停走转身；前景森林透视半径扩大到 2 游戏单位、镜头地形净空检查 | 封闭墙角会平滑停下；不以穿越树干或陡壁解决受阻 |
| 拾取 | 装备和药剂使用与经验相同的吸附范围、速度和插值；拾取词条同时扩大两者范围 | 满包时物品留在玩家附近，腾出空间后收入 |
| 界面 | 石墨蓝灰与暖金 HUD，诊断折叠、启动地图平滑显示，保留键盘与窄屏操作 | 尚未全面替换图标与掉落物模型，不能称为完整次世代美术改造 |

实现合同：[环境资产](environment-assets.md)、[角色资产](actor-assets.md)、[行为](simulation-and-ai.md)、[界面](interface-design.md)。

远景使用径向距离并匹配同视线的真实天空颜色，遮住高山加载轮廓，复用天空贴图且不增加绘制批次。六类怪物采用独立生命/伤害成长，参考装备和承伤范围见[数值期望与采样](combat-balance.md)。实际伤害、暴击、护盾、闪避与反伤使用一张字形图集批量上浮；256 条只增加一次 draw call，性能面板显示三维批次/P95 与三角形数。

远景验证在两个高度比较真实地形和标准材质的加载/移除像素，并用禁用雾的画面证明对照物可见；飘字验证比较同帧隐藏/显示字形网格后的真实 GPU 计数。历史原始结果收录到[测量索引](../README.md#evidence)，不在当前总览重复维护逐轮测试数量和 CPU 采样值。

背包/打造快速锁定使用 Shift＋点击或 Shift＋空格，避开 Ctrl 与移动 W 组合关闭浏览器标签页；保留锁定模式。主界面、存档与失败界面支持导出本地诊断，详见[运行诊断](../app-development.md#本地运行诊断)。

## 成本与验证

地表数组纹理、森林 LOD 的面数、材质读取成本与资源所有权统一见[环境资产](environment-assets.md)；角色模型、图集和实例池预算统一见[角色资产](actor-assets.md)。未被玩法使用的独立 Imp 生产模型已移除，源 Imp 仍是术士构建输入，不能按运行时模型名称清理源资产。

敌方实体獠牙采用一次构建的弯曲渐尖网格、根部渐暗和纵向细棱；岩块使用程序化岩层与细粒表面。四份固定实例池复用全部敌方攻击、血契和护骨，不引入纹理下载、付费资产或逐粒子对象。具体预算见[技能表现](skills-and-effects.md)。

回归覆盖 PBR 通道保留、原材质不被修改、LOD 材质共享、线性材质字节完整性、失败/取消不上传，以及真实游戏中的资产请求、动作、资源失败重试和释放。画面检查使用固定种子 `rift-ember-1` 的山脊、林地、完整战斗场景，以及中性光照下两种新怪物的姿势。

地貌检查覆盖有界、环绕与无限世界的远/中/近/调试视图。宝箱接地使用真实山脊，保留坡度和穿地标准；拾取检查覆盖 Worker 吸附、模型/光圈插值和最终背包刷新。天空验证地面雾不改变像素、转向改变天空，以及 WebGL 恢复后重新烘焙的一致性；源资产按字节数与 SHA-256 校验。

森林透视读取真实 framebuffer，对比中心淡出与外围像素；相机绕山使用地形视线采样。检查选择、开发页验收、构建和性能门槛统一见[测试策略](../testing.md)。

新增通行和生态迭代的合同及验证见[地形通行](terrain-navigation.md)与[角色资产](actor-assets.md)。后续美术重点为聚落实体建筑、专业角色造型与受击/死亡表现。

敌方表现验证夹击开放端、石脊侧移、横扫背后安全区、血契取消、飞刃曲率、满载实例池及与玩家法阵的分离。具体技能规则见[技能与效果](skills-and-effects.md)，历史视距及查询基准见[测量索引](../README.md#evidence)。
