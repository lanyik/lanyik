# 荒原免费美术与渲染升级

更新：2026-09-13。方向为现代暗黑奇幻，采用可离线构建的免费资源与程序化建模；没有美元支付、商店账户、Unity 或 UE 编辑器依赖。

## 成本与验证

地形图集清除八个空槽后，两份八层 504² 数组连同 mip 约 20.67 MiB，等于此前一份十六层颜色数组；新增材质有额外纹理读取和像素着色成本。森林每种两部件，LOD 面数与资源所有权见环境合同。

六个角色 GLB、二十四张角色图集约 22.35 MiB。主角一组、敌人五组模型池；移除了不再被玩法使用的独立 Imp 生产模型。源 Imp 仍为术士构建输入。

回归覆盖 PBR 通道保留、原材质不被修改、LOD 材质共享、线性材质字节完整性、失败/取消不上传，以及真实游戏中的资产请求、动作、资源失败重试和释放。画面检查使用固定种子 `rift-ember-1` 的山脊、林地、完整战斗场景，以及中性光照下两种新怪物的姿势。

2026-09-13 v22 验证：根包 423、应用 202 项单测通过，22 组地貌指标门禁通过。RTX 3060 Ti 上应用 24 项浏览器回归最终均通过，根包 26 项通过（含 500 次世界替换）；另复核有界、环绕与无限三组地貌远/中/近/调试视图。旧宝箱测试移到实际山脊，保留坡度、穿地与接地标准；新的物品检查覆盖 Worker 吸附、模型/光圈插值和最终背包刷新。
模拟 CPU 基准 travel .056、crowded .292、terrain .183 ms/tick，均在既有预算内；不能作为 GPU 帧率结论。天空背景验证地面雾不改变像素、转向改变天空，以及真实 WebGL 丢失后重新烘焙得到相同像素。26 份环境源文件的字节数与 SHA-256 全部验证。

森林新增检查读取真实 framebuffer：中心区域随淡出开关改变，外围像素不变；真实山体绕行检查 100 个视线采样点。现有开发页面、采样小地图、技能拖拽和未打包 Worker 物品合同独立检查通过，未放宽超时参数。生产构建、类型检查、优化门禁和生成文件一致性作为提交检查。

新增通行和生态迭代的合同及验证见[地形通行](terrain-navigation.md)与[角色资产](actor-assets.md)。后续美术重点为聚落实体建筑、专业角色造型与受击/死亡表现。
