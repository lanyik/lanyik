# 战斗模拟、技能与结算

导航：[文档索引](../README.md#game)

本文维护权威模拟、AI/线程、构筑施法、数值提交与状态生命周期。参数、阶段内算法、目录和容量常量直接查代码；角色事务归[成长与物品](items.md)，地形查询归[探索与通行](exploration-and-homestead.md)。

调用方向为技能/普攻/怪物动作 → 命中请求 → 数值结算 → 生命提交 → 事实 → 奖励与表现。状态参与结算输入；常驻被动低频编译属性，不通过定时状态伪装。角色事务由 CharacterState 提交，技能构筑与战斗实体仍由各自所有者维护。


## 实体、时钟与容量

[GameConfig](../../apps/survivor/src/core/GameConfig.ts)和 [CombatSimulation](../../apps/survivor/src/core/CombatSimulation.ts)定义固定频率、阶段和容量。高频实体使用定容 SoA，低频角色/构筑/背包由领域对象拥有，不为统一存储搬进逐 tick ECS。热路径只读已编译角色属性。

实体句柄、存储槽和查询游标不同；跨阶段/异步保存完整安全整数句柄并重新解析。借用查询结果不能跨下一次查询保留，必要时复制至有界缓冲。出生、移动、移除更新空间索引，槽复用前清理；结算候选顺序稳定，不让密集数组交换改变随机消费。

AI/动作先形成有界请求，再在固定阶段提交，不能在借用查询过程中任意移除实体或重入结算。空间索引不保证密集围攻常数成本，查询和缓冲仍受容量限制。

权威命中/事件溢出明确失败；弹道整轮准入，失败不部分发射或排队补射，普攻 CD 不积累负值。经验池满可合并价值，物品池满按规则放弃新生成，但入包必须原子提交；出生槽实际创建后才消费。可丢视觉不影响权威规则。

暂停/隐藏不补算墙钟空档；玩法绝对坐标保持双精度，GPU 转局部。改频率联查回复、AI、自动施法单位和整除关系；改视野联查人口/唤醒/淡出/卸载，改容量联查查询、传输、实例池及预算，改槽位联查命令、快捷键和存档。

## 怪物行为与动作

[EnemyBehavior](../../apps/survivor/src/core/EnemyBehavior.ts)复用静态行为树，运行态属于实体；响应式分支切换先 halt 旧分支。控制、目标丢失、脱战、移除清理动作；决策可降频，已开始的移动/攻击时间线逐 tick 推进。

前摇、出手和恢复归核心，未出手中断保留 CD，已释放效果继续自身生命周期。领主与普通怪共用行为和结算入口，差异由定义表达，不能另建伤害系统。模型只读权威进度。

### 受阻寻路与群体占位

CombatWorld 拥有 [EnemyNavigation](../../apps/survivor/src/core/EnemyNavigation.ts)和 [EnemyCrowd](../../apps/survivor/src/core/EnemyCrowd.ts)。追击、寻射线、归位持续受阻后排队搜索；遭遇连通图只证明出生可达，不承担战斗路线。

怪物与玩家复用 LocalNavigationPath 四邻接局部 A*，各自拥有缓冲。怪物共享定容搜索槽及每 tick 总展开预算，轮转准入、单次截止、失败退避；仅保留路径前缀再续规划，不为每实体分配完整网格。追击允许射程内无遮挡节点结束，归位最后扫掠到精确岗位，隔墙近战继续接近。

请求持完整句柄；目标/意图变化、位移、控制、攻击、脱战及移除取消旧路径。净空按实际体型，执行仍经 moveActor；窗口、净空余量和搜索预算是能力边界，不承诺任意长绕路/窄道，不可达不能忽略碰撞。

近战使用有限身体大小占位，内圈满则外围等待，释放后补位；局部避让只读定量近邻并稳定处理等距/重合，位移不超过移速。已承诺攻击/冲锋不被避让改写。占位不消费战斗随机数，但移动可改变后续命中；这是软分离，不承诺极端密度零重叠。

## 玩家自动战斗

[PlayerAutoCombat](../../apps/survivor/src/core/PlayerAutoCombat.ts)拥有目标、路径、让行和躲避意图；移动走统一通行，攻击走统一施法，无专属速度或无视障碍。玩家独占局部搜索预算，不与怪物抢搜索槽。

AutoCombatThreats 只预测已知攻击，使用有界缓冲，不预判未发生 AI；几何提前排除必须保守，不能缩短预测窗、丢边界接触或改变等分顺序。手动输入优先，安全时可为站定法术让路，紧急躲避可中断吟唱。

自动施法独立于自动寻怪；[配装事务](items.md#自动配装与回收)由输入变化触发，不逐 tick 扫全包。死亡/传送/恢复清运行态，存档不自动恢复开关，暂停/隐藏不推进搜索。

## 多 Worker 职责与执行协议

[CombatWorkerClient](../../apps/survivor/src/worker/CombatWorkerClient.ts)创建并拥有整组 Worker、端口与请求。唯一权威 Worker 拥有 ECS、随机流、命令和结算；可选查询 Worker 只读数值快照，不写实体、不掷骰、不发奖励。

批次连续序列且仅一个在途，命令按接收顺序先于本批 tick，查询 join 时不插命令；暂停为零 tick 屏障。积欠 tick 有界并计数丢弃，命令溢出明确失败。并行只算候选，权威端整批按原顺序提交并执行地形/效果检查。生产默认串行，启用查询线程先有负载证据和共享预算。

UI 低频快照与表现帧分离；表现用两份独立缓冲交替转移，下一请求归还旧帧，绝不转移活跃 ECS 数组。[RenderFrame](../../apps/survivor/src/worker/RenderFrame.ts)统一布局/字节数，改字段同时改写入、读取、回收和校验。

命令、死亡、屏障可立即发布 UI；主线程插值最新完整帧、夹紧范围，不预测命中。RAF 不等 Worker，无新帧保留上一完整结果。任何成员失败终止整组并拒绝等待者，旧结果/错误不得污染新世代；重试建新组，不切回主线程或部分续跑。

## 生命周期与诊断

Worker 在异步初始化/读档前取得模拟所有权，区块准备和查询共用串行屏障。[玩法区块准备](exploration-and-homestead.md#遭遇布局与可达性)逐块让出真实事件循环，不能用已完成 Promise 冒充让出；初始化/传送/跨界失败只报一次且不发布半成品。生产走异步准备，立即执行仅服务离线回放。

销毁关闭让出端口、唤醒等待者并幂等释放模拟/地形/仓库，恢复执行先检查关闭状态；不能迟到提交。主线程沿地图帧循环采输入/表现/诊断，应用当前关闭自适应流送，改变调度须有实际瓶颈证据。

Worker 活跃比是采样窗占用率，不是系统 CPU。执行、查询等待、区块让出、持久化等待分别计时，批次 CPU 扣等待；整 tick 墙钟保留等待，命令让出不混入 tick。GPU 时间异步，诊断窗口有界。最大值和对应工作量不能被均值/P99 掩盖，阶段探针只在独立基准运行，口径归[测试策略](../testing.md#benchmark-scope)。

## 构筑提交与交互

[SkillBuild](../../apps/survivor/src/core/SkillBuild.ts)拥有节点 ranks/revision，[SkillSystem](../../apps/survivor/src/core/SkillSystem.ts)拥有施法和装配。目录/倍率以 Skills 为准，UI 草稿没有战斗效力，关闭丢弃。提交完整 ranks 与 revision，整体校验等级、点数守恒、前置、互斥及真实购买顺序可达性，不允许自身投入或循环解锁。

过期/非法/重复提交不重复扣点，失败保持原状，成功才编译修正和增加 revision。野外只加点，家园可退款；死亡禁止，暂停允许，动作/持续技能未结束拒绝退款。退款清失效装配及相应自体效果，保留其他来源状态、已付费用和 CD，属性重算保持生命/法力比例。

主动槽可空，须已学习并满足等级，换槽交换且终极数量受限。CD 按技能身份存，换槽/退款/重学/换装不重置；拖放和按键归[界面设计](interface-design.md)。

## 通用主动与常驻被动

通用主动独立成长，四系侧路随构筑编译。[PassiveSkills](../../apps/survivor/src/core/PassiveSkills.ts)的常驻被动须装入独立被动槽，学习不等于生效，不占主动槽、不伪装无限 Buff。

装卸只允许存活角色在家园且动作/持续技能结束，校验解锁、学习和唯一性。收益代价进入同一属性体系并统一封顶；装备比较、寻宝和结算读同一已提交上下文。装卸/升级/退款保留资源比例，不刷新技能/免伤盾 CD；恢复从身份重编译。

全域拾取只消费当前世界已生成有界池，轮转按尝试预算处理，失败也占预算但物品完整保留；不加载远方、开远箱或绕过库存/副本保存屏障。暂停/死亡停止。

## 施法时间线与战斗提交

每角色只有一个前摇→出手→可选引导→后摇共享动作。起手检查生命、学习、装配、控制、资源、容量和 CD，全部通过才扣费/启 CD，快照输出、修正和落点/方向。出手前不伤害，换槽不绕动作锁。

命中读起手输出和当下目标防御，换装/被动/强化到期不改在途输出。范围/连锁用权威遮挡与稳定句柄顺序；表现不选敌或掷骰。持续场/弹体池先准入再扣费，各场本阶段结算完再进下一场；弹体扫掠最早接触且只爆炸一次，目标失效不改落点。

手动移动/冻结可中断站定前摇或引导，不退款/清 CD/撤回独立效果；疾行抢断仍保留原最晚恢复期限并受地形限制。死亡不补发，过图/读档清未出手动作和在途效果，保留费用、CD、剩余恢复；普通保存不取消当前施法。周期按 tick，尾段不足周期不补跳，暂停停止。

自动施法低频且一次最多起手一个，无有效目标/忙碌不空耗资源，优先级由核心定义；与自动移动协调，紧急躲避和手动操作优先。

## 批量特效与伤害飘字

权威效果与可丢视觉分离。主线程只插值传输的轨迹/期限/进度；敌方预警同样读取实际动作与取消。瞬态、附着状态、攻击和文字使用固定实例池，复用角色遍历/地表高度并只上传有效前缀，不逐实体创建网格、材质、DOM 或计时器。

地面法阵/预警/光环由战斗层投影、真实地表接收；立体粒子/弹体保留深度测试。资源加载和预算准入后才挂载，失败/取消释放半成品和晚到结果，重开清状态并复用资源。所有权与资产输入归[资产设计](assets.md)，投影预算归[渲染流送](../render-streaming.md#渲染层与表现资源)。

飘字来自实际生命变化及结算暴击/反伤标记，不再掷骰。按完整实体身份及类型合并，死亡不抹已有字、复用不串字，满额只淘汰显示。出生时间与当前模拟 tick 同源，暂停冻结。DamageNumbers 共享字形图集/实例池，按屏幕像素保持字号，不因命中更新独立 React 状态。

## 结算与事件合同

命中请求保存完整实体句柄，跨阶段重新解析。已释放攻击可以在来源失效后造成伤害，但反伤、吸血返还等需要存活来源的操作必须重新确认身份，不能读取复用槽。

CombatVitality 返回实际生命损失/治疗量，吸血和飘字不能使用超过剩余生命的名义伤害。死亡只提交一次，死亡事实在实体移除前复制，奖励不回读已回收的槽。

防御、保护和吸收顺序由 CombatResolution 唯一维护。反伤直接提交生命损失，不再触发命中、吸血或新的反伤；双方同时死亡时保留既定事实顺序和随机消费顺序，不能因拆分模块改变奖励。

事件使用预分配有界缓冲，每笔结算及派生效果完成后同步消费，再进入下一笔。消费者借用当前记录，不能保存数组索引作为历史，也不能递归调用伤害或生命修改；重入和权威缓冲溢出明确失败。

权威事实和可丢弃视觉缓冲分开，表现丢弃不影响奖励。药剂、自然回复、升级及换装比例重算目前仍由角色命令处理；新增“任意治疗触发”前必须统一这些入口，不能假定现有战斗事件已覆盖全部生命变化。

主角动作和声音消费固定大小的 PlayerFeedback 投影，规则只能写入实际完成的攻击、掉血和拾取提示；不得等待音效/动作结束后结算。合并、丢弃与生命周期由[角色表现合同](assets.md#主角动作与声音)维护。

## 状态合同

StatusSystem 是状态唯一拥有者，定义控制种类、强度、来源容量和期限；消费者只读投影和门禁，不直接写入。字段、上限和状态目录见实现，不在此维护第二张数值表。

普通标量状态按来源保存强度与期限。同来源刷新整体替换，不能拆开取最大；不同来源独立到期，弱效果不能给强效果续期。容量满时按已定义强度和稳定优先级准入，失败不部分修改。特殊状态的次数、吸收量和周期层使用各自有界数据，不混入普通刷新入口。

完整目标句柄失效时拒绝施加，非法参数明确报错；目标移除清空状态，来源失效不自动清除已附着效果。已快照强度不因来源换装重算。状态不创建逐项计时器或无限事件历史。

到期批次完成后发布新投影，下一模拟阶段必须立即看到正确移动、保护和控制状态；同批目标可去重计算，但不能把死亡、破盾或控制门禁推迟到帧尾。

冻结限制行动并取消未出手动作，保留 CD；不追溯撤销已释放攻击。免疫、抵抗、来源刷新与控制时长修正都在准入时处理，恢复存档不再次乘抗性。自然到期的后继抵抗从原截止 tick 计算，不能因跳步额外延长。

取消、耗尽、自然到期、净化、引爆和清理是不同原因，不能共用一个隐式“移除即触发”回调。范围持续场由技能拥有，附着在目标身上的周期状态由状态系统拥有。

## 灼烧与引爆合同

灼烧独立保存目标句柄、来源组、已快照每跳输出、期限和下一跳。成功命中且目标存活后才附加；闪避不附加，盾全吸收仍属于命中。来源消失可继续燃烧，目标移除立即清理。

来源数与每来源层数均有界。满层只按剩余未结算总量和稳定顺序替换符合条件的层，不刷新其他层，不预发伤害；缩小新施加上限不追溯删除旧层。周期包含恰好到期的末跳，不足完整周期的尾段不补跳。
已有来源追加/替换不重新统计不同来源；新来源准入只使用来源上限大小的临时去重缓冲，该缓冲独立于周期批次，回调中追加灼烧不能覆盖待结算数据。

捕获到期批次、推进层时钟与发布投影后再回调结算，回调新增层只参与后续批次。同 tick、同目标、同来源的周期量先合并，按完整身份稳定提交；死亡及槽复用不把旧批次作用于新实体。这个合并依赖当前没有逐跳命中触发器，增加触发器时必须重审。

周期伤害读取当前有效保护/护盾和适用防御，不重新走直接命中的闪避、暴击、吸血或反伤链；仍通过公共生命/死亡/奖励入口结算。

引爆只在直接命中成功后消费本人剩余灼烧，其他来源保留；已快照输出不能重复乘施放者增伤或再掷暴击。它作为该次直接命中的组成部分，不另造攻击链。自然到期、替换、移除和退款不触发引爆。

## 雷电命中与防护合同

导电、聚焦等命中后结果依据本次真实命中与完整目标句柄提交，闪避不累计，复用槽不继承；导电改变后续候选优先级，不隐含控制或额外伤害。

各系自体防护拥有独立类别，节点退款只移除对应来源/类别。Protection、StaticGuard 和 AstralGuard 由统一入口取有效最强值，各自到期；不能在各技能中重复相加或相乘。周期伤害不冒充直接命中来刷新防护。

## 星辰强化防护与净化合同

同次施放的星能获取有统一消费标记，不能按命中目标数量重复获取。虚弱读取可解析来源的当前状态，不改变已快照灼烧或失效来源的槽数据。

Empowered 整体比较强度、次数和期限，不能让较弱效果延长更强效果。灌注成功写入后才消费星能；伤害技能全部准入成功后每次起手扣一次强化，整次施法和最后一次都使用完整快照，不逐目标/弹体/周期扣次。失败施放不扣，空放或之后中断不返还。

净化只在出手阶段执行，仍受起手控制门禁；按稳定优先级和有限预算移除来源组，不触发跳伤、引爆或自然到期逻辑。未选中状态照常计时。

壁垒与结界共用一个吸收盾，替换时强度、期限和回护快照整体替换，不相加或继承旧回护。破盾先提交溢出伤害，仍存活才治疗；致死溢出不复活，到期/替换/清理不治疗。保护减伤与盾量分别拥有生命周期。

## 保存与表现

状态保存来源分组和剩余时间，周期保存输出与相位，次数/回护等特殊数据按定义校验。外部来源恢复为不可解析的独立分组，不能连到新世界实体；不重复叠加输出或抗性，也不结算离线时间。详细范围归[角色存档](character-saves.md)。

CombatEvents 留在权威 Worker 同步消费，主线程只读快照和表现帧。视觉、UI 草稿或动画不得反向决定伤害与状态期限。

## 后续接入边界

沉默、元素抗性和通用触发被动尚未形成完整协议；吸血、反伤与回护仍是明确的现有规则。新增消费者时再定义效果身份、来源、触发阶段、容量与取消语义，禁止以事件回调递归造成伤害，不预造无消费者的注册框架。

套装复用装备变更后的属性编译；连携先定义条件、窗口、资源和优先级，不能看特效是否重叠决定触发。任务与剧情需要稳定地点/任务身份及持久进度，不能长期保存 ECS 句柄。开发顺序只维护在[开发重点](development-priorities.md)。

## 验证

按变更选择 SkillBuild/Skills/PassiveSkills、各系 Casting、模拟/Worker、EnemyNavigation/EnemyCrowd、状态与结算测试。覆盖点数可达性、过期提交、取消扣费、快照/帧缓冲、导航总预算、封闭/贴墙目标、体型净空、补位、失败重建及迟到结果。

StatusSystem、BurnSystem 和 CombatEvents 测试保护来源、到期、槽复用、实际生命变化、死亡去重、防重入、取消与存档。结算重构用固定种子比较玩法快照及随机检查点；性能优化不得排除生命、奖励或随机数差异。

[测试策略](../testing.md)维护执行命令；管线 CPU 对照不能替代完整遭遇平衡或浏览器帧率验证。
