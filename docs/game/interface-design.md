# 生存 RPG 界面设计

导航：[总导航 · 游戏设计](../README.md#game) · [按任务阅读](../README.md#routes)

本页描述当前界面。四系技能树的分支展开、草稿加点、节点详情及 Buff 展示目标见[四系技能树与状态设计（待实现）](skill-tree-and-status.md#4-技能树界面)，尚未替换当前技能图鉴。

启动入口为种子预览和存档主界面，点击开始后才创建战斗场景。`O` 打开游戏与存档界面并暂停，自动槽与三个手动槽展示等级、种子、金币、物品格数、保存时间，详见[角色存档](./character-saves.md)。
快捷菜单包含世界传送在内共九项，统一放右下；桌面五列两行，窄屏九列单行，窗口打开时状态栏避让导航。
背包和打造使用虚拟化网格，仅挂载可见行及缓冲；Shift＋点击/空格快速锁定，触屏使用统一锁定模式，逐格锁定按钮删除。
快速锁定不再绑定 Ctrl，避免与移动 W 组合为浏览器关闭标签页的 Ctrl+W；最后一个标签页关闭时窗口也会关闭。
这是浏览器保留快捷键，不能依靠页面的 preventDefault 可靠接管，见 [Chrome 快捷键](https://support.google.com/chrome/answer/157179)与 [Chromium 预处理逻辑](https://chromium.googlesource.com/chromium/src/+/2592adf6c41bc0753c814e3747ab49d67f31075c/chrome/browser/ui/views/frame/browser_view.cc)。
Shift＋空格长按只切换一次，不触发原生按钮二次点击或打造拖拽；锁定操作关闭详情浮窗，解锁后自动售出导致物品卸载也保持界面有效。
手动批量分解按严格低于目标等级筛选，只用一个清单/收益/警示合一的确认窗。格子常驻显示品质，流光只在悬停或聚焦时运行。

对应 `apps/survivor/src/presentation/{App,WindowChrome,CharacterPanel,InventoryPanel,CraftingPanel,SpiritRealmPanel,WorldTravelPanel,WorldTravelGraph,SessionMenu,StartScreen,ItemView,RegionMap,UiIcon,WorkerLoadPanel}.tsx`
与 `app.css`、`menus.css`。地域、奖励和成长数值以[战斗与成长合同](combat-and-progression.md)为准，背包、回收与比较以[物品合同](items.md)为准；
状态发布与命令边界见[应用架构](../app-development.md)。

## 视觉与信息层级

采用石墨蓝灰面板、克制的暖金强调、红色生命、蓝色法力和绿色正向属性。启动页与战斗 HUD 使用相同基础色板，地图预览使用平滑缩放。
窗口使用不透明底色，HUD 使用接近不透明的底色，避免明亮草地与单位从文字下透出。
不使用背景模糊、在线字体或第三方图标依赖；装备图标与界面图标均为本地 SVG。

| 层级 | 表现 | 内容 |
|---|---|---|
| 主要数值 | 23–30px，等宽数字 | 生存时间、击杀、等级、攻击/防御/生命 |
| 窗口与物品标题 | 15–22px，较高亮度 | 角色、背包、装备名称 |
| 正文与属性 | 12–13px，名称和值分列 | 属性、词条、操作 |
| 辅助信息 | 10–11px，次级文字色 | 等级、分类计数、品质、快捷键 |

窄屏的辅助信息进一步压缩；物品正文保持可读尺寸。
品质同时显示名称与边框色，空装备有“未装备”文字，锁定宝珠槽显示锁和解锁等级。
图标仅辅助识别，操作仍提供中文标签或可访问名称。键盘焦点有统一金色外框。
系统开启 `prefers-reduced-motion` 时禁用过渡和旋转动画。

视觉层级参考 [Diablo IV 的公开角色界面](https://blog.playstation.com/2023/06/02/diablo-iv-interview-paragon-system-pvp-replayability-and-more/)
中的深色分区、主属性摘要与品质识别；实现根据本项目的紧凑评分卡和独立窗口重新组织，未引入游戏图片资产。

## 统一窗口与操作

`WindowHeader` 统一标题、资源摘要、操作说明、快捷键与右上关闭。移除重复的英文副标题和常驻大段说明；帮助与管理弹层只在打开时监听外部指针，点击外部或聚焦其中按 Esc 关闭，Esc 不同时关闭主窗口。原生键盘焦点与按钮禁用语义保留。

内容遵循“顶部分类/工具 → 中间选择与预览 → 底部执行”。`action-footer` 固定显示结果/费用、次操作和暖金主操作，正文独立滚动；不会在每张背包卡或每个灵境属性上复制一组动作。技能升级和角色加点保留与目标紧邻的上下文操作。

打造四页签共用底部报价与确认；宝珠先选精炼或分解，再执行。灵境先选属性，底部显示费用/不足数量并统一注入。存档卡仅选择槽位，列表下方集中保存/读取，底部统一继续或保存返回；自动槽不可手动覆盖。保存状态留在存档窗口，后台保存失败进入统一通知区。

窗口使用同一间距、标题高度和按钮尺寸；窄屏保留底部导航，收起背后 HUD，动作区不随长内容滚走。说明、地图与管理弹层不增加轮询、逐帧 React 更新或背景模糊。

## 战斗 HUD

- 左上为品牌和探索/暂停状态，下面三列分别展示生存时间、击杀、当前驻留怪物数。
- 战斗记录下方的“性能诊断”默认折叠，点击后逐行展示战斗模拟、每个碰撞查询 Worker 和每个地形 Worker 的负载：
  近一秒任务占用率、每秒结束的任务数和最近一次任务耗时；首次取样显示“采样中”。
  百分比有背景条，文字保留数值；面板明确注明任务占用包含通信与等待，不代表系统 CPU 利用率。
  没有分配的查询 Worker 不显示空行；无任务时显示 0%，尚未完成过任务的耗时显示破折号。
  窄屏压缩为三列，任务频率放在线程名称下方，矮屏限制高度并允许滚动；面板随左上 HUD 在任意管理窗口打开时隐藏。
  暂停状态位于战斗栏和导航，继续操作统一使用右下 P；不再增加中央暂停操作浮条。
  窄屏领主生命放到右侧地图下方，避免覆盖左侧 Worker 行。
- Worker 行上方展示“帧与响应”：实际/理论 FPS、逻辑实际 Hz/120Hz 目标、预计逻辑上限、逻辑预算占比、帧间隔 P95、CPU、GPU、快照年龄和采样到绘制延迟。
  “阶段耗时与积压”折叠区展示角色/镜头、挂载、收包、浏览器长帧、模拟执行、查询等待、通信调度和有界队列指标，
  分开显示积压丢弃的 tick 与超出时钟追赶上限的累计时间，并显示三维绘制批次均值/P95 和三角形数。
  窗口指标与“最近批次”耗时分别标注；GPU/长帧计时不可用或没有样本时使用破折号。面板整体限制高度并允许滚动。
  窄屏的指标改为名称/数值同行，减少换行占用，使下方 Worker 负载更早进入可视区域。
- 右上为当前地域、环数、等级带和地形采样地图：底色保留山川、水域与地貌，叠加低透明琥珀/玫瑰难度色晕；没有六边形铺排与边框。折叠只显示玩家及恐怖地域 ◆，展开补充困难/恐怖地域等级；底部三种难度图例，北向标记和柔化边缘统一画风。色晕表示邻近危险程度，当前地域精确等级仍以上方信息为准。
- 底中为免伤盾、主动结界余量、自动施法开关、角色等级、生命、法力、经验、四个技能槽和两个药剂槽。
  血蓝显示完整名称和当前值/上限；经验同时显示进度条和数值。
  生命不超过最大值的 25% 时显示“生命危急”与强调边框，无额外闪烁计时器。
- 桌面右下提供角色、背包、地图、技能、打造 J、灵境 L、传送 H、存档 O、暂停九项菜单，显示图标、名称、快捷键、待分配属性点和技能点。
  窄屏改为底部横向导航，战斗面板移到导航上方。
- 领主生命保留独立显示层。操作通知、保存失败和传送错误集中在同一通知区，最多显示最近两条普通通知；保存与旅行错误不截断。死亡和加载使用遮罩。

常规 UI 更新由 `CombatSession` 的低频快照发布驱动。诊断面板通过地图的 `afterframe` 约每秒采样一次，
按实际采样间隔计算负载，并独立触发快照发布；暂停后仍采样，因此完成在途任务后下一窗口归零。
没有新增动画帧循环、轮询消息或定时器，`WorkerLoadPanel` 仅在负载快照变化时重绘。

技能 K 面板采用深蓝灰秘典样式、暖金标题线、学派色图标和等级菱形刻度；桌面双列图鉴，窄屏单列。
每张卡只展示名称、定位、主效果和升级操作，详细说明/法力/冷却/自动条件放在图标浮窗中，沿用 Alt 固定规范。
拖动图鉴或槽位中的图标，放入面板或 HUD 的目标槽即可装配，已有技能交换位置；不用选择槽位再确认。
空格拿起聚焦的技能、数字 1–4 装配、Esc 取消；鼠标/触屏拖动显示跟手图标、目标槽边框与结果播报。
槽数及快捷键范围来自 `GAME_CONFIG.skills.slots`；技能距离、时长、衰减、减速和自动施法阈值直接使用核心 `SKILL_RULES`，说明文案不单独保存数值。
指针拖动中用 Esc 取消也会抑制随后生成的点击，避免取消装配意外触发 HUD 技能。
升级按钮显示所需角色等级；HUD 用 1–4 施放、Q/E 使用药剂，F 控制自动施法，冷却图标有遮罩。
技能列表独立滚动，标题、关闭按钮和底部四个装配槽始终固定；桌面 HUD 压缩到窗口下方，窄屏用窗口内装配区并收起后方 HUD。
技能卡片和自动条件见[技能合同](skills-and-effects.md)。六个快捷槽在窄屏仍保持单行，名称与冷却各占独立一行。

## 角色与背包工作区

工作区承载独立角色和背包窗口；桌面为两列 Grid，窗口宽度由网格分配，互不覆盖。
单开窗口居中；角色最大宽度 680px，背包 840px。
标题栏、背包工具栏和底栏固定在各自窗口内，内容区有界滚动。
工作区从视口顶部展开；宽桌面打开窗口时，底部战斗面板切换为血蓝与技能并列的紧凑布局，
为物品详情留出更多高度。关闭窗口后恢复探索 HUD 的常规排列。
同时压缩右下功能菜单以保持所有按钮可点击；暂停状态移入底部战斗栏。
任意管理窗口打开时隐藏其后的战斗记录、Boss 血条和收起状态的地域地图；桌面所有窗口统一避让底部 HUD，宽度不足 1180px 时收起后方 HUD。

| 视口条件 | 布局 |
|---|---|
| 宽度 ≥1180px | 角色和背包并排；角色装备、属性分别滚动 |
| 宽度 <1180px | 同时打开时显示窗口切换按钮，仅显示当前窗口；切换保留筛选、选择和滚动状态 |
| 宽度 ≤700px | 角色装备与属性纵向排列、物品卡按容器宽度计算且至少两列、底部横向导航 |
| 桌面高度 ≤800px | 压缩探索 HUD；管理窗口保持顶部 20px、底部 180px 的边界 |
| 高度 ≤600px | 内容有界滚动，底部操作区与导航始终可达 |

菜单开关与快捷键仍共用 App 的目录。最近打开的角色/背包成为窄屏前台窗口；
切换按钮只改变本地前台状态，不关闭或重建另一窗口。关闭一个窗口后直接显示另一个。
隐藏的背包不响应 Enter/Del 物品操作；可见性在按键边界读取，不新增 resize 监听或重复 UI 状态。
物品详情与窗口的 Esc 优先级见[输入路由](#快捷键与输入路由)。

角色左列依次展示 11 个固定体位槽、6 个宝珠槽和选中装备详情。
装备详情保存 ID，随当前装备/宝珠快照重新解析；卸下或替换后不保留旧物品详情。
角色装备格直接展示评分与星级，只在图标上悬停或聚焦显示浮窗。右列首先展示总战力与装备贡献，随后是攻击、防御、生命、基础加点、装备爆率和三个可折叠属性组：
进攻与命中、防御与生存、回复与探索。完整展示 38 种属性及法力、法力回复，进攻组默认展开。

背包标题显示当前分类容量与满包状态；分类显示使用格数/各自上限，容量与堆叠上限取[物品合同](items.md#数据与容量)。
默认装备分类；分类、整理与“管理”位于工具栏。“管理”展开自动品质阈值（含关闭）、保护规则、累计清理数、锁定模式和按等级批量分解。药剂分类提供合并按钮。
底栏展示选中物品、金币/粉尘及统一操作组；未选择时提示选择物品，选择失效或换分类立即清空动作。宝珠分类顶部显示六个拖拽槽。空分类说明掉落与自动拾取来源。

背包物品格由 `VirtualItemGrid` 按容器宽度计算列数，目标列宽 174px、间距 8px，至少两列；行高 112px。显示名称、品质色、装备等级、部位、星级、评分、换装战力差和保留标记；虚拟化规则见[UI 性能](ui-performance.md)。
图标与浮窗交互遵守[通用图标](items.md#通用图标)和[详情浮窗](items.md#详情浮窗)合同。同部位当前与待装备并排比较，窄于 480px 上下对照；长内容独立滚动。
基础属性与附加词条分开、名称和值分列。物品卡仅负责选择和图标详情，不放逐格动作按钮；选中后在底栏执行装备/使用/前往打造，售出/分解为次操作，装备另提供打造入口。宝珠拖动图标嵌入或交换，双击槽位取下，空格后按 1–6 支持键盘装配。
各类自动回收的保护规则和收益见[物品合同](items.md#分类回收与自动处理)；界面展示对应说明和累计处理数，以整格斜纹、大锁水印、角标显示锁定，锁定物品禁用售出。
自动穿戴产生的锁显示“自动锁定”，详情提示挂机可淘汰；Shift＋点击/空格或锁定模式先将其转为手动保护，再次操作才解锁。角色详情的“锁定保留”也可直接转为手动保护。背包装备/宝珠页及 Z 按钮说明[挂机自动装配](items.md#挂机自动装配)的策略与淘汰边界。
每次打开背包提交整理命令；手动回收使用[打造合同的统一确认窗](crafting-and-spirit.md#危险操作交互)。装备、宝珠和词条的打造入口定位到工坊对应页签与物品。
筛选、排序、快捷键选择使用稳定物品 ID；排序保留选择，切换分类清空选择。卡片本身可聚焦，内部仅保留图标详情按钮，避免嵌套按钮。生产界面没有演示物品或虚假比较分。
稳定 ID 只在同一局有效。新局按会话 generation 重建交互区，关闭窗口并清除选中物品和浮窗，取消正在进行的拖拽；锁定槽不可执行嵌入。

主 HUD 持续显示总战力及装备贡献。新拾取更好装备在主界面右下弹出，展示换装前后总战力、评分和一键穿戴按钮；
支持忽略本件、图标悬停对比，多件按提升量依次展示。打开角色、背包、技能或展开地图时收起，回到主界面继续提示。
不设自动穿戴倒计时；候选身份与失效处理由[会话](../app-development.md#领域集成与界面状态)维护。

## 其他窗口与反馈

小地图保留玩家圆点，并画带深色描边的朝向箭头；北向固定，箭头按玩家 heading 和地图长宽比计算，
独立于镜头旋转。同一位置原地转向也会触发重绘。

M、右上展开按钮或点击小地图打开居中的世界地图，尺寸同时受窗口宽高约束。展开后保留完整矩形底图，不再使用折叠态的边缘遮罩。
滚轮以鼠标位置为中心缩放，右键拖动浏览世界；空格或“回到玩家”按钮复位视口中心并保留缩放倍率。
点击选点仅改变金色准星与目标栏，不移动玩家或镜头。已解锁区域显示目标坐标、地域难度及等级；未探索区域覆盖暗雾，目标栏显示“未探索 · 禁止传送”，隐藏等级并禁用传送。
T 或“传送到目标”提交已解锁目标并收起地图；不可站立的落点保持原位并提示重新选择陆地，死亡后禁用传送。已解锁同级及以下不限次，越级探索目标共用 5 秒冷却，按钮显示剩余时间并禁用；暂停允许已就绪的传送，但不推进冷却。步行揭示和低等级地域自动解锁由[探索与家园](exploration-and-homestead.md)定义。
M/Esc 或关闭按钮取消浏览，恢复折叠地图跟随；再次展开重置倍率与中心。世界地图与角色、背包、技能、打造、灵境、存档窗口互斥，避免空格选取/地图复位冲突。
地图顶部提供定位与折叠操作说明，底部固定目标摘要和唯一传送按钮；按钮及说明摘要保留原生空格激活，文字输入、模态及已处理按键不触发地图操作。
家园地图显示“灯火营地 / 安全区域 / 64×64”，全域可见。家园技能快捷栏允许手动施放，装备和成长窗口继续可用。
H 或右下“传送”打开世界传送窗口，与其他窗口互斥并暂停战斗。左侧使用相连的图节点表示家园、荒野及四个 Boss 副本，显示当前所在、卷轴数量或本轮剩余怪物；右键拖动航图，“全览”复位。拖动通过指针捕获只更新一个 DOM transform，不触发 React 快照更新或地形采样；松开、取消、丢失捕获结束拖动。点击节点，右侧复用真实小地图及其缩放、拖动、选点、空格复位与 T 传送，两个拖动区域相互独立。区域摘要显示等级、领主、三星彩装、三倍经验与本轮进度；“挑战规则”展开 1.3/1.5 强度、固定雾边界、中心宝箱、扣卷轴与保留进度规则。无卷轴的新轮次禁用入场和选点传送，续战不重复扣费。右下提供“区域入口 / 地图选点”模式，共用一个主按钮和 T 快捷键。点击地图自动切到选点模式，切回入口可使用默认位置；当前区域入口禁用，仍可选点移动。T 与点击的可用条件一致，不能绕过卷轴、迷雾和冷却。H/Esc/关闭恢复打开前的暂停状态；切换期间显示加载遮罩并禁止重复操作，保存失败原地显示原因。窄屏上下排列节点航图和区域地图，节点改为两行连接图以保持可辨认；区域地图和规则独立滚动，标题、模式与传送操作区固定。航图空白处支持触摸拖动。
九个快捷入口（含 H、暂停）统一在右下，桌面采用五列两行横向网格，暂停占末行两格；中窄屏为一行九列，中等宽度 HUD 上移以避让导航。桌面角色/背包/技能窗口打开时，压缩 HUD 靠左并给右下导航留出空间。H 不再放左上，也不直接触发往返。

打造 J 与灵境 L 使用独立窗口，打开时关闭角色/背包/技能工区；快捷键和关闭按钮行为一致。
打造四页签采用单侧格子物品库、另一侧带图标槽位的打造台，继承为左来源/右目标和下方前后对比，单次模态预览确认；详见[打造与灵境](crafting-and-spirit.md)。
窄屏九项底部导航保持一行，工坊改为纵向列表，模态可滚动且不接受背后的移动或技能快捷键。
进入确认前关闭活动物品浮窗，Esc 直接取消确认。操作通知统一在窗口下沿集中显示，避免散落在标题、内容和地图中央。
角色宝珠区显示当前配对/类型数量和经济共鸣；属性详情注明灵境点数，金币加成包含装备与宝珠共鸣之和。

## 快捷键与输入路由

| 键 | 功能 |
|---|---|
| C / B（I）/ M / K / J / L | 角色 / 背包 / 展开地图 / 技能 / 打造 / 灵境 |
| 空格 / T（展开地图时） | 视口回到玩家 / 传送到选中目标 |
| P | 暂停或继续 |
| H | 打开 / 关闭世界传送航图 |
| Alt / Esc | Alt 固定物品浮窗，再按关闭；Esc 先由拖拽、模态或浮窗处理，随后依次关闭存档、传送、打造、灵境、背包、角色、技能、地图，无窗口时切换暂停 |
| 1–4 / Q / E / F | 四槽技能 / 生命药剂 / 法力药剂 / 自动施法开关 |
| Z | 自动战斗开关（家园/死亡时不可开启），HUD 与自动施法分别显示开关 |
| Enter / Delete | 背包选中装备/药剂的穿戴/使用 / 预览售出或分解 |
| R | 死亡后重开 |
| O | 游戏与角色存档；打开后暂停 |
| WASD | 相对镜头移动，仍由输入控制器管理 |

全局菜单忽略快捷键重复、输入法组合事件、Ctrl/Meta/Alt 修饰及可编辑区域；复选框聚焦时仍可使用界面/移动快捷键。存档窗口打开时仅接受 O/Esc 关闭操作，传送窗口仅接受 H/Esc；两者打开时禁用底部暂停切换，避免绕过窗口暂停。

自动战斗按钮保留 Z 提示与开关状态，提示说明低生命用药、自动换装/嵌珠/淘汰及手动接管；F 继续独立控制自动施法，1–4/Q/E 保留手动技能与药剂。状态栏允许换行，窄屏以及同时显示暂停/结界时不挤压开关。挂机期间 WASD 接管移动，死亡自动关闭。行为优先级、用药阈值、搜索范围与闪避限制统一见[玩家自动战斗](simulation-and-ai.md#玩家自动战斗)。
原生按钮和说明/管理摘要的 Enter 保持原生激活，不触发背包使用；物品卡 Enter 执行选中物品操作；切换分类清空选择，避免对隐藏物品执行快捷键。
Shift 锁定、Alt 浮窗固定及拖拽键盘操作由各自交互处理；全局菜单不抢占这些输入。暂停/隐藏和死亡后的命令边界见[应用设计](../app-development.md#权威状态与时钟)与[角色存档](character-saves.md)。

## 验证

应用类型检查与生产构建覆盖组件和资源打包，核心测试保护装备/宝珠/背包命令。
浏览器验收使用真实 Worker、WebGL 和角色资源，检查穿脱装备、筛选与整理、概率提示、
快捷键、并排窗口不重叠、图标触发范围、Alt 固定、分类容量/药剂合并，以及窄屏切换后装备和关闭操作可达。
视觉检查覆盖 1440×900、1280×720、390×844 与矮屏布局；截图作为本地验证产物，不作为应用资产。
`interface-layout.spec.ts` 遍历八个窗口，验证说明 Esc 优先关闭、固定操作区与导航不重叠、窄屏无横向溢出，以及航图选点模式与 T 执行一致；背包和存档用例另验证摘要 Enter 不误装备、锁定禁售、自动槽禁覆盖及空槽禁读取。
Worker 浏览器验收还检查角色更新→绘制→采样的真实顺序、帧指标、五条线程记录、满载查询的完成数与耗时、暂停归零、重开不累积行，以及窄屏无横向溢出、不与领主血条重叠。

伤害飘字由世界层统一实例化，至多 256 条共用一个绘制批次，见[飘字合同](skills-and-effects.md#伤害飘字)。React HUD 接收 10Hz 战斗快照，诊断窗口每秒汇总；背包继续使用虚拟列表、快照结构共享和已有 memo 组件。DOM 元素不逐一对应 WebGL draw call，面板三维计数包含投影、世界和天空，界面布局/绘制成本使用浏览器长帧和布局指标评估。命中不新增 DOM 节点或独立 React 状态更新。
五条线程的专门验收显式启用碰撞 Worker；默认界面只列实际拥有的模拟/地形线程。
同步 WebGL 创建失败须显示原因和重试按钮，资源清理失败时显示刷新提示；新局回归验证旧 ID 不会选中新物品、旧拖拽状态不会带入新局且低等级锁定槽拒绝装配。
主界面与 O 存档界面将“导出诊断日志”归入“诊断与日志”折叠区；失败界面直接提供导出，显示记录范围和存储不可用原因；日志跨刷新保留，详细事件和空间上限见[本地运行诊断](../app-development.md#本地运行诊断)。
