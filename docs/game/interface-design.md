# 游戏界面与交互

导航：[文档索引](../README.md#game)

本页约束当前 React HUD/窗口、输入、状态订阅和性能。写实暗黑游戏 UI 的整体重设计归[视觉改造项目](visual-overhaul.md#游戏界面与交互)，尚未替换当前界面。装备/构筑等合法性由核心校验，UI 不维护第二套规则。

修改入口为 [presentation](../../apps/survivor/src/presentation/) 中 App、WindowChrome、各 Panel、ItemView/SkillView、RegionMap、VirtualItemGrid、WorkerLoadPanel 与 CSS；发布和世代归[应用设计](../app-development.md)。具体尺寸、断点、属性目录和数值摘要直接查组件/样式，不另列完整布局参数表。

## 视觉与信息层级

当前使用深色不透明窗口、接近不透明 HUD、暖金重点和血蓝语义色，背景不能透过文字影响阅读。使用本地 SVG/CSS，不依赖在线字体/图标或背景模糊。主要数值、标题、正文和辅助信息分层，窄屏正文仍须可读。

品质/锁定/空槽/职业限制同时用文字、形状或图标表达，不能只靠颜色；按钮有中文标签或可访问名称，键盘焦点可见。prefers-reduced-motion 禁用过渡/旋转。具体装饰不是游戏交互完成度的依据，关键是战场视野、操作路径和信息优先级。

## 统一窗口与操作

WindowHeader 统一标题、资源摘要、折叠说明、快捷键和关闭；帮助/管理浮层只在打开时监听外部指针，Esc 先关浮层而不同时关主窗。顶部筛选、中部选择/预览、底部固定执行区，长正文独立滚动，主操作/费用/销毁结果相邻。

角色与背包可并排，空间不足用前台切换且保留各自筛选/选择/滚动；隐藏背包不能响应物品操作。其他管理窗按现有互斥关系切换，打开后后方战斗记录/地图等避让，底部 HUD 和右下导航不遮住操作区。矮屏/触屏保持关闭、固定底栏和全部导航可达。

新局按 session generation 重建交互区，关闭窗口、详情和浮窗，清选择并取消拖拽；即使物品 ID 重用也不能继承上一局选择。排序用稳定 ID，换分类/目标失效清操作状态；不能将数组索引当操作身份。

IconFrame/ItemView 的图标 hover/focus 驱动单个 Portal 浮窗，Alt 固定有单一所有者，触屏和键盘同样能访问。详情/使用按钮不嵌套；拖放经 Pointer Capture/阈值区分点击，失焦、取消、卸载统一收尾。悬停、拖动和取消不写库存。

危险操作只有一份包含结果预览、费用和销毁警示的确认窗，取消为安全默认，模态阻断背景输入。确认后核心再校验 ID/revision；可跳过提示范围和保护规则归[物品事务](items.md#危险操作交互)。

## 战斗 HUD

主要战斗信息为生命/法力/经验、六主动槽和药剂、状态/保护、自动施法/自动战斗；领主血条独立。右上地域/地图反映实际权威位置与危险度，右下为带名称/快捷键的统一功能入口。窄屏调整排列，诊断行、领主和窗口不得相互遮挡。

状态条读取实际剩余量、次数、控制分类和动作阶段，辅助技能不显示虚假攻击倍率；危急生命有明确文字/边框，不新增闪烁计时器。普通通知有界，保存/旅行错误保留完整原因，死亡/加载用遮罩。新拾取提升提示只引用真实当前库存，按钮走正式命令，无倒计时自动穿戴。

诊断区区分实际 FPS、理论工作上限、逻辑频率、预算、队列和采样延迟；未测/不可用显示缺失，不当零。窗口统计与最近批次分开，隐藏等待不当 CPU 工作；GPU 结果是异步样本。诊断沿地图 afterframe 低频更新，暂停仍采样直到在途完成，无独立 RAF/轮询。

## 角色、背包与技能

角色装配、宝珠、属性和比较读同一权威成长上下文；详情按 ID 随快照重新解析，卸下/替换后不保留旧对象。背包按分类显示容量、整理、保护/回收设置，选择后统一底栏执行；物品卡负责选择/详情，不复制一排动作按钮。装备比较与真实穿戴共用算法，职业不符不显示不可兑现的收益。

Shift＋点击/空格切换锁定，触屏用锁定模式；长按只切换一次，不触发原生二次点击或拖拽，操作关闭旧浮窗。避免 Ctrl 与移动键组合触发浏览器保留快捷键。自动穿戴经历不构成第二种锁，回收仍遵守核心保护。批量分解预览一个合并清单，不串联多个确认窗。

打造使用分类物品库和来源/目标台，继承展示前后差异，一次模态提交；角色/背包入口定位到具体页签和 ID。宝珠拖放/交换及键盘装配也只提交命令，锁定槽核心拒绝。灵境与角色经济分别展示，永久存储语义不由窗口推断。

技能分页星图只挂当前学派，主动/侧路/专精有可区分形状，真实前置才连线。点击选择，悬浮/焦点说明；图可滚动/拖动/键盘导航，连线避文字。详情显示已提交→草稿及费用，关闭丢草稿，应用一次整体提交，退前置级联清非法后代；家园洗点及退款限制归[构筑合同](combat-architecture.md#构筑提交与交互)。

主动装配标记只读权威槽，草稿不提前生效；学习主动可拖到六槽，重复交换，空格拿起/数字装配/Esc 取消，移动阈值避免误施法。常驻被动有独立固定槽、解锁/家园限制提示，无施法键和倒计时，学习不等于生效。加点长按只在按住时持单个延时任务，松开/边界/失焦/关窗即停。

## 地图、旅行与存档窗口

M 展开真实地图，滚轮以指针缩放、右键拖动、空格回玩家并保留倍率；点击只选点，不移动角色/镜头。北向与角色朝向独立于镜头，转向也重绘。隐藏地表和等级，未知目标禁传；T/按钮共用权限/冷却/净空，失败留位置并提示。关闭取消浏览，再开重置视口。

H 打开并暂停世界航图，左侧节点表示家园/荒野/副本，右侧复用真实地图。航图与地形拖动独立；左图仅改一个 transform，不触发快照或地形采样。入口/选点共用主按钮与 T，点击地图选点切模式，当前世界入口禁用但可选点传送。无卷轴开新轮拒绝，续战不重复扣，规则读副本核心。

保存中只阻止旅行提交，仍可选目的地、浏览、关窗；不能在 pointerdown/up 间禁用浏览控件吞点击。切换锁住重复提交，保存失败原地显示原因；H/Esc 关闭恢复打开前暂停状态。窄屏节点与地图上下排列，标题/模式/操作固定，内容独立滚动。

开始页先于 3D 创建，种子预览/存档列表由应用持有。O 暂停并管理自动槽与手动槽；自动槽禁手动覆盖、空槽禁读取。音效/环境声和音量是会话设置，浏览器未解锁显示启用，失败可重试。日志入口按需折叠，失败页直接提供导出；存储/关闭合同归[角色存档](character-saves.md)和应用设计。

## 快捷键与输入路由

| 键 | 功能 |
|---|---|
| C / B（I）/ M / K / J / L | 角色 / 背包 / 展开地图 / 技能 / 打造 / 灵境 |
| 空格 / T（展开地图时） | 视口回到玩家 / 传送到选中目标 |
| P | 暂停或继续 |
| H | 打开 / 关闭世界传送航图 |
| Alt / Esc | Alt 固定物品浮窗，再按关闭；Esc 先由拖拽、模态或浮窗处理，随后依次关闭存档、传送、打造、灵境、背包、角色、技能、地图，无窗口时切换暂停 |
| 1–6 / Q / E / F | 六槽技能 / 生命药剂 / 法力药剂 / 自动施法开关 |
| Z | 自动战斗开关（家园/死亡时不可开启），HUD 与自动施法分别显示开关 |
| Enter / Delete | 背包选中装备/药剂的穿戴/使用 / 预览售出或分解 |
| R | 死亡后重开 |
| O | 游戏与角色存档；打开后暂停 |
| WASD | 相对镜头移动，仍由输入控制器管理 |

全局菜单忽略快捷键重复、输入法组合事件、Ctrl/Meta/Alt 修饰及可编辑区域；复选框聚焦时仍可使用界面/移动快捷键。存档窗口打开时仅接受 O/Esc 关闭操作，传送窗口仅接受 H/Esc；两者打开时禁用底部暂停切换，避免绕过窗口暂停。

自动战斗按钮保留 Z 提示与开关状态，提示说明低生命用药、自动换装/嵌珠/淘汰及手动接管；F 继续独立控制自动施法，1–6/Q/E 保留手动技能与药剂。状态栏允许换行，窄屏以及同时显示暂停/结界时不挤压开关。挂机期间 WASD 接管移动，死亡自动关闭。行为优先级、用药阈值、搜索范围与闪避限制统一见[玩家自动战斗](combat-architecture.md#玩家自动战斗)。
原生按钮和说明/管理摘要的 Enter 保持原生激活，不触发背包使用；物品卡 Enter 执行选中物品操作；切换分类清空选择，避免对隐藏物品执行快捷键。
Shift 锁定、Alt 浮窗固定及拖拽键盘操作由各自交互处理；全局菜单不抢占这些输入。暂停/隐藏和死亡后的命令边界见[应用设计](../app-development.md#时钟输入与暂停)与[角色存档](character-saves.md)。

## 更新与性能

React DOM/SVG/CSS 的成本是组件计算、布局、绘制与合成，不能用 WebGL draw call 替代。UI 读低频战斗快照，诊断独立低频；命中飘字由世界固定实例池处理，不逐次命中创建 DOM/React 状态。

ShareSnapshot 在 Worker 结构化克隆后递归比较并复用等值只读分支，只有发现变化才分配容器；保留属性删除、数组缩短/清空的失效，不修改新旧快照。它仍有比较成本，不是领域 revision 增量传输。装备比较缓存包含物品/穿戴/属性/等级/被动等完整输入。

VirtualItemGrid 按实际容器和滚动只挂可见行及缓冲、保留总高度/稳定 ID，过滤/分类重置窗口，列数变化保留首行锚点。常驻品质/星级/锁纹，只有 hover/focus 流光，离屏无 DOM/动画；Portal 浮窗不被滚动裁切。

SkillGraph memo 依赖构筑/节点/选择，冷却发布不重遍历连线；核心修正仅提交时编译，草稿仅编辑时编译。星图滚动不触发整树 React 更新，隐藏学派不挂载，纹样不带常驻循环任务。

### 地图迷雾

缓存失效与页请求归[探索设计](exploration-and-homestead.md#地图迷雾与采样)。指针、采样完成和覆盖层更新合并到已有帧，未知页面不生成地形；测量分别报告同步 Canvas 绘制和 RAF 间隔，不能把同步计时当 GPU 完成时间。

### 性能测量

满包/技能窗口用 scripts/benchmark-survivor-ui.mjs 对生产预览：真实检查点夹具、世界暂停但背景仍绘制，统计挂载数、主线程任务、布局和 RAF，不代表持续战斗或纯 UI 耗时。pipeline 基准独立测分支复用，不包含结构化克隆，不能互相替代。

地图用 scripts/benchmark-survivor-map.mjs 对实际运行地址，保留真实指针、地图帧、地形 Worker 和战斗更新，分别测静止/默认比例拖动/最远比例拖动；不直接改视口或冻结快照。后台战斗与机器负载会影响整帧，报告请求/重绘、覆盖层/整图耗时、长任务与 RAF，具体场景参数由脚本维护。

## 验证

按[测试策略](../testing.md)选择类型/构建、核心命令和真实 Worker/WebGL 用例。验证固定操作区不重叠、窄/矮屏无横向溢出、虚拟滚动可到末件、隐藏物品不响应、Alt/Shift/拖放收尾、长按取消、Esc 层级及原生按钮 Enter 不误使用。

地图验证负坐标未知像素不泄露、严格等级/冷却、缓存命中/失效、突发指针合帧；航图 T/按钮一致、保存不吞选择和旅行失败。存档/新局验证身份重置、旧拖拽/ID 不残留，音频/诊断验证暂停、重开和关闭。

同步 WebGL 创建失败显示真实错误/重试，清理失败提示刷新。画面尺寸取现有浏览器用例，截图只作本地验证。诊断线程只列实际拥有者，碰撞 Worker 专测显式启用，不声称默认就有全部线程。
