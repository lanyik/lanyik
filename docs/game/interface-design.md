# 生存 RPG 界面设计

导航：[总导航 · 游戏设计](../README.md#game) · [按任务阅读](../README.md#routes)

启动入口为种子预览和存档主界面，点击开始后才创建战斗场景。`O` 打开游戏与存档界面并暂停，自动槽与三个手动槽展示等级、种子、金币、物品格数、保存时间，详见[角色存档](./character-saves.md)。
快捷菜单现为八项，桌面双栏排列时保持四行，窄屏保持八列单行，避免新增存档入口后挤入背包或状态栏。
背包和打造使用虚拟化网格，仅挂载可见行及缓冲；Shift＋点击/空格快速锁定，触屏使用统一锁定模式，逐格锁定按钮删除。
快速锁定不再绑定 Ctrl，避免与移动 W 组合为浏览器关闭标签页的 Ctrl+W；最后一个标签页关闭时窗口也会关闭。
这是浏览器保留快捷键，不能依靠页面的 preventDefault 可靠接管，见 [Chrome 快捷键](https://support.google.com/chrome/answer/157179)与 [Chromium 预处理逻辑](https://chromium.googlesource.com/chromium/src/+/2592adf6c41bc0753c814e3747ab49d67f31075c/chrome/browser/ui/views/frame/browser_view.cc)。
Shift＋空格长按只切换一次，不触发原生按钮二次点击或打造拖拽；锁定操作关闭详情浮窗，解锁后自动售出导致物品卸载也保持界面有效。
手动批量分解按严格低于目标等级筛选，只用一个清单/收益/警示合一的确认窗。格子常驻显示品质，流光只在悬停或聚焦时运行。

对应 `apps/survivor/src/presentation/{App,CharacterPanel,InventoryPanel,CraftingPanel,SpiritRealmPanel,ItemView,RegionMap,UiIcon,WorkerLoadPanel}.tsx`
与 `app.css`。玩法数值以[战斗与成长合同](./combat-and-progression.md)为准；
状态发布与命令边界见[应用架构](../app-development.md)。

## 视觉与信息层级

采用石墨蓝灰面板、克制的暖金强调、红色生命、蓝色法力和绿色正向属性。启动页与战斗 HUD 使用相同基础色板，地图预览使用平滑缩放。
窗口使用不透明底色，HUD 使用接近不透明的底色，避免明亮草地与单位从文字下透出。
不使用背景模糊、在线字体或第三方图标依赖；装备图标与界面图标均为本地 SVG。

| 层级 | 表现 | 内容 |
|---|---|---|
| 主要数值 | 23–30px，等宽数字 | 生存时间、击杀、等级、攻击/防御/生命 |
| 窗口与物品标题 | 15–22px，较高亮度 | 守夜人、行囊、装备名称 |
| 正文与属性 | 12–13px，名称和值分列 | 属性、词条、操作 |
| 辅助信息 | 10–11px，次级文字色 | 等级、分类计数、品质、快捷键 |

窄屏的辅助信息进一步压缩；物品正文保持可读尺寸。
品质同时显示名称与边框色，空装备有“未装备”文字，锁定宝珠槽显示锁和解锁等级。
图标仅辅助识别，操作仍提供中文标签或可访问名称。键盘焦点有统一金色外框。
系统开启 `prefers-reduced-motion` 时禁用过渡和旋转动画。

视觉层级参考 [Diablo IV 的公开角色界面](https://blog.playstation.com/2023/06/02/diablo-iv-interview-paragon-system-pvp-replayability-and-more/)
中的深色分区、主属性摘要与品质识别；实现根据本项目的紧凑评分卡和独立窗口重新组织，未引入游戏图片资产。

## 战斗 HUD

- 左上为品牌和探索/暂停状态，下面三列分别展示生存时间、击杀、当前驻留怪物数。
- 战斗记录下方的“性能诊断”默认折叠，点击后逐行展示战斗模拟、每个碰撞查询 Worker 和每个地形 Worker 的负载：
  近一秒任务占用率、每秒结束的任务数和最近一次任务耗时；首次取样显示“采样中”。
  百分比有背景条，文字保留数值；面板明确注明任务占用包含通信与等待，不代表系统 CPU 利用率。
  没有分配的查询 Worker 不显示空行；无任务时显示 0%，尚未完成过任务的耗时显示破折号。
  窄屏压缩为三列，任务频率放在线程名称下方，矮屏限制高度并允许滚动；面板随左上 HUD 在双窗口打开时隐藏。
  窄屏暂停提示位于底部状态栏，继续操作使用底部菜单，避免浮条覆盖负载记录。
  窄屏领主生命放到右侧地图下方，避免覆盖左侧 Worker 行。
- Worker 行上方展示“帧与响应”：实际/理论 FPS、逻辑实际 Hz/120Hz 目标、预计逻辑上限、逻辑预算占比、帧间隔 P95、CPU、GPU、快照年龄和采样到绘制延迟。
  “阶段耗时与积压”折叠区展示角色/镜头、挂载、收包、浏览器长帧、模拟执行、查询等待、通信调度和有界队列指标，
  分开显示积压丢弃的 tick 与超出时钟追赶上限的累计时间，并显示三维绘制批次均值/P95 和三角形数。
  窗口指标与“最近批次”耗时分别标注；GPU/长帧计时不可用或没有样本时使用破折号。面板整体限制高度并允许滚动。
  窄屏的指标改为名称/数值同行，减少换行占用，使下方 Worker 负载更早进入可视区域。
- 右上为当前地域、环数、等级带和地形采样地图：底色保留山川、水域与地貌，叠加低透明琥珀/玫瑰难度色晕；没有六边形铺排与边框。折叠只显示玩家及恐怖地域 ◆，展开补充困难/恐怖地域等级；底部三种难度图例，北向标记和柔化边缘统一画风。色晕表示邻近危险程度，当前地域精确等级仍以上方信息为准。
- 底中为免伤盾、主动结界余量、自动施法开关、角色等级、生命、法力、经验、四个技能槽和两个药剂槽。
  血蓝显示完整名称和当前值/上限；经验同时显示进度条和数值。
  生命不超过最大值的 25% 时显示“生命危急”与强调边框，无额外闪烁计时器。
- 桌面右下提供角色、背包、地图、技能、打造 J、灵境 L、暂停七项菜单，显示图标、名称、快捷键、待分配属性点和技能点。
  窄屏改为底部横向导航，战斗面板移到导航上方。
- 领主生命、暂停提示、掉落通知和失败/死亡反馈保留独立显示层。

常规 UI 更新由 `CombatSession` 的低频快照发布驱动。诊断面板通过地图的 `afterframe` 约每秒采样一次，
按实际采样间隔计算负载，并独立触发快照发布；暂停后仍采样，因此完成在途任务后下一窗口归零。
没有新增动画帧循环、轮询消息或定时器，`WorkerLoadPanel` 仅在负载快照变化时重绘。

技能 K 面板采用深蓝灰秘典样式、暖金标题线、学派色图标和等级菱形刻度；桌面双列图鉴，窄屏单列。
每张卡只展示名称、定位、主效果和升级操作，详细说明/法力/冷却/自动条件放在图标浮窗中，沿用 Alt 固定规范。
拖动图鉴或槽位中的图标，放入面板或 HUD 的目标槽即可装配，已有技能交换位置；不用选择槽位再确认。
空格拿起聚焦的技能、数字 1–4 装配、Esc 取消；鼠标/触屏拖动显示跟手图标、目标槽边框与结果播报。
槽数及快捷键范围来自 `GAME_CONFIG.skills.slots`；技能距离、时长、衰减、减速和自动施法阈值直接使用核心 `SKILL_RULES`，说明文案不单独保存数值。
指针拖动中用 Esc 取消也会抑制随后生成的点击，避免取消装配意外触发 HUD 技能。
升级按钮显示所需角色等级；HUD 用 1–4 施放、Q/E 使用药剂，F 控制自动施法，冷却图标有遮罩。
技能列表独立滚动，标题、关闭按钮和底部四个装配槽始终固定；桌面 HUD 压缩到窗口下方，窄屏用窗口内装配区并收起后方 HUD。
技能卡片和自动条件见[技能合同](skills-and-effects.md)。六个快捷槽在窄屏仍保持单行，名称与冷却各占独立一行。

## 角色与背包工作区

工作区承载独立角色和背包窗口；桌面为两列 Grid，窗口宽度由网格分配，互不覆盖。
单开角色或背包时最大宽度均为 680px。
标题栏、背包工具栏和底栏固定在各自窗口内，内容区有界滚动。
工作区从视口顶部展开；宽桌面打开窗口时，底部战斗面板切换为血蓝与技能并列的紧凑布局，
为物品详情留出更多高度。关闭窗口后恢复探索 HUD 的常规排列。
同时压缩右下功能菜单以保持所有按钮可点击；暂停状态移入底部战斗栏。
双窗口打开时隐藏其后的战斗记录和收起状态的地域地图，避免从窗口边缘露出零碎信息。

| 视口条件 | 布局 |
|---|---|
| 宽度 ≥1180px | 角色和背包并排；角色装备、属性分别滚动 |
| 宽度 <1180px | 同时打开时显示窗口切换按钮，仅显示当前窗口；切换保留筛选、选择和滚动状态 |
| 宽度 ≤700px | 角色装备与属性纵向排列、单列物品卡、底部横向导航 |
| 桌面高度 ≤800px | 压缩左上记录和标题栏，工作区从 16px 开始 |
| 高度 ≤600px | 窗口使用距上下边缘各 12px 的区域，内容可滚动 |

菜单开关与快捷键仍共用 App 的目录。最近打开的角色/背包成为窄屏前台窗口；
切换按钮只改变本地前台状态，不关闭或重建另一窗口。关闭一个窗口后直接显示另一个。
隐藏的背包不响应 Enter/Del 物品操作；可见性在按键边界读取，不新增 resize 监听或重复 UI 状态。
物品获得焦点时 Esc 先关闭其详情提示；随后依次关闭背包、角色、技能、地图，最后切换暂停。

角色左列依次展示 11 个固定体位槽、6 个宝珠槽和选中装备详情。
装备详情保存 ID，随当前装备/宝珠快照重新解析；卸下或替换后不保留旧物品详情。
角色装备格直接展示评分与星级，只在图标上悬停或聚焦显示浮窗。右列首先展示总战力与装备贡献，随后是攻击、防御、生命、基础加点、装备爆率和三个可折叠属性组：
进攻与命中、防御与生存、回复与探索。完整展示 38 种属性及法力、法力回复，进攻组默认展开。

背包标题显示当前分类容量与满包状态；分类显示使用格数/各自上限，装备 80、宝珠 48、药剂 32、词条 80 格。
默认装备分类；清理行包含自动品质阈值下拉框（含关闭）、保护规则和累计清理数。药剂分类提供合并按钮，最多 99 瓶同规格药剂占一格。
底栏分别显示格数、数量、金币和键盘操作；宝珠分类顶部直接显示六个拖拽槽，删除目标槽下拉框。空分类说明掉落与自动拾取来源。

背包物品格最小列宽 174px、间距 7px，窄屏保持两列；显示名称、品质色、装备等级、部位、星级、评分、换装战力差和保留标记。
图标遵守[四层图标与品质色规范](./items.md#通用图标)。卡片非图标区域、文字、评分和操作按钮不触发浮窗。
图标悬停或键盘聚焦显示完整属性，同部位当前与待装备并排，窄于 480px 上下对照。
浮层通过 portal 渲染，底部提示 Alt 固定；未固定时移开图标立即关闭且不拦截指针。
固定后才可移入详情滚动/操作，Alt/Esc、关闭按钮或外部点击关闭；触屏触碰图标固定，全局同时最多一个物品浮窗。
固定期间悬停其他图标保留当前详情，原图标卸载、浏览器失焦时关闭；长内容独立滚动，不被面板裁切。
基础属性与附加词条分开、名称和值分列。装备/使用为主按钮，售出/分解为次按钮；宝珠拖动图标嵌入或交换，双击槽位取下，空格后按 1–6 支持键盘装配。
各类背包独立设置自动处理品质：装备/药剂/词条售出，宝珠分解。装备保留提升、持平、空部位和锁定物品，保护规则共用 `compareEquipment`。
穿戴过的装备自动锁定，背包以整格斜纹、大锁水印、锁角标展示；解锁立即应用回收规则，锁定物品禁用售出。
每次打开背包先执行一次合并堆叠及品质排序。手动售出/分解只弹一次预览收益和整格销毁的确认窗。
删除显式品质一键清理，装备/宝珠/词条提供打造入口，定位到工坊对应页签和物品。
筛选、排序、快捷键选择使用稳定物品 ID；生产界面没有演示物品或虚假比较分。
稳定 ID 只在同一局有效。新局按会话 generation 重建交互区，关闭窗口并清除选中物品和浮窗，取消正在进行的拖拽；锁定槽不可执行嵌入。

主 HUD 持续显示总战力及装备贡献。新拾取更好装备在主界面右下弹出，展示换装前后总战力、评分和一键穿戴按钮；
支持忽略本件、图标悬停对比，多件按提升量依次展示。打开角色、背包、技能或展开地图时收起，回到主界面继续提示。
不设自动穿戴倒计时；实际穿戴后重算其余候选，过期或已经售出的装备不会继续推荐。

## 验证

小地图保留玩家圆点，并画带深色描边的朝向箭头；北向固定，箭头按玩家 heading 和地图长宽比计算，
独立于镜头旋转。同一位置原地转向也会触发重绘。

打造 J 与灵境 L 使用独立窗口，打开时关闭角色/背包/技能工区；快捷键和关闭按钮行为一致。
打造四页签采用单侧格子物品库、另一侧带图标槽位的打造台，继承为左来源/右目标和下方前后对比，单次模态预览确认；详见[打造与灵境](crafting-and-spirit.md)。
窄屏七项底部导航仍为一行，工坊改为纵向列表，模态可滚动且不接受背后的移动或技能快捷键。
进入确认前关闭活动物品浮窗，Esc 直接取消确认。工坊与灵境打开时仅显示最近一条操作通知，放在下沿，避免遮挡选择列表。
角色宝珠区显示当前配对/类型数量和经济共鸣；属性详情注明灵境点数，金币加成包含装备与宝珠共鸣之和。

应用类型检查与生产构建覆盖组件和资源打包，核心测试保护装备/宝珠/背包命令。
浏览器验收使用真实 Worker、WebGL 和角色资源，检查穿脱装备、筛选与整理、概率提示、
快捷键、并排窗口不重叠、图标触发范围、Alt 固定、分类容量/药剂合并，以及窄屏切换后装备和关闭操作可达。
视觉检查覆盖 1440×900、1280×720、390×844 与矮屏布局；截图作为本地验证产物，不作为应用资产。
Worker 浏览器验收还检查角色更新→绘制→采样的真实顺序、帧指标、五条线程记录、满载查询的完成数与耗时、暂停归零、重开不累积行，以及窄屏无横向溢出、不与领主血条重叠。

伤害飘字由世界层统一实例化，至多 256 条共用一个绘制批次，见[飘字合同](skills-and-effects.md#伤害飘字)。React HUD 接收 10Hz 战斗快照，诊断窗口每秒汇总；背包继续使用虚拟列表、快照结构共享和已有 memo 组件。DOM 元素不逐一对应 WebGL draw call，面板三维计数包含投影、世界和天空，界面布局/绘制成本使用浏览器长帧和布局指标评估。命中不新增 DOM 节点或独立 React 状态更新。
五条线程的专门验收显式启用碰撞 Worker；默认界面只列实际拥有的模拟/地形线程。
同步 WebGL 创建失败须显示原因和重试按钮，资源清理失败时显示刷新提示；新局回归验证旧 ID 不会选中新物品、旧拖拽状态不会带入新局且低等级锁定槽拒绝装配。
主界面、O 存档界面和失败界面提供“导出诊断日志”，显示记录范围和存储不可用原因；日志跨刷新保留，详细事件和空间上限见[本地运行诊断](../app-development.md#本地运行诊断)。
