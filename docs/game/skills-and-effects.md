## 技能配置与成长

`Skills.ts` 提供技能参数、施法时序和数值计算；`SkillBuild.ts` 提供节点、前置、上限、图坐标和编译后的侧路修正。技能仍使用 `TypedValue<"skill", SkillId>`，不占背包。
每次角色升级 1 点，角色 1 级未用点为 0。点数账本为 `未用 + Σ(节点等级−初始等级) = 角色等级−1`；目前没有道具赠点入口。
默认六槽为脉冲、空、疾风步、空、空、空。冰霜、火焰、雷电节点从 0 学习；其余五个旧术式初始 1 级并保留角色解锁限制，其中疾风步固定 1 级，其他最高 5 级。连锁闪电已移入雷电分支，不再作为免费初始技能。

### 冰霜树

```text
冰霜弹 ─┬─ 冰枪 ─ 冰晶风暴 ─ 极寒破碎
        │                 └─ 碎冰专精
        └─ 霜环 ─ 暴风雪 ─ 绝对零度
                          └─ 永冬专精
每个主动另有伤害、形态、节奏三条侧路；树侧边有四个全系被动。
```

| 节点 | 上限 | 首点前置 |
|---|---:|---|
| 基础主动 | 10 | 角色 2 级 |
| 中级主动 | 10 | 角色 8 级、本系其他节点投入 6 点、基础主动 3 级 |
| 高级主动 | 10 | 角色 20 级、其他节点投入 18 点、本分支中级 3 级 |
| 终极主动 | 5 | 角色 45 级、其他节点投入 40 点、本分支高级 5 级 |
| 三条专属侧路 | 各 5 | 绑定主动分别达到 1 / 3 / 5 级 |
| 四个公共被动 | 各 5 | 本系其他节点分别投入 2 / 6 / 12 / 18 点 |
| 两个互斥专精 | 各 3 | 角色 30 级、本系其他节点投入 28 点、对应高级主动 3 级 |

一系 7 主动、21 侧路、4 公共被动、2 专精；两个专精最多选一个。可以学习两个终极，但六槽最多装一个。门槛始终排除节点自身投入。
Worker 整体检查数组长度、整数上下限、等级、父节点、互斥、实际可达的购买顺序和点数；不能让尚锁定的分支相互资助前置。

普通冰主动伤害为一级倍率 × `(1 + .06 × (等级−1))`，终极改为每级 .12。专属伤害每点 +4%，研习每点全冰伤 +3%，两项相加后乘入。
形态每点让冰弹/冰枪多命中一个不同目标（现有侧路最多六个）；其他冰技能半径每点 +5%。
节奏分别修改冰弹耗蓝（每点 −3%）、冰枪/极寒破碎 CD（每点 −2%）、冰晶风暴持续（每点 +10%）、霜环/暴雪寒意积累（每点 +10%）、零度寒意持续（每点 +10%）。
公共被动为研习、全冰减耗每点 2%、寒意持续每点 5%、寒冰韧性每点缩短自身减速/寒意/冻结持续 4%。**当前韧性是控制时长抗性，不是尚未接入的元素抗性。**
碎冰每点使冻结目标的冰伤乘数增加 .1，本人寒意积累统一乘 .75；永冬每点寒意积累 +15%、冻结时长 +.1 秒，本人冰伤统一乘 .85。
法力減耗合计最多 50%，向上取整且至少 1；冰系 CD 经侧路和施速计算，普通最短 .5 秒、终极最短 10 秒。所有描述与预览读取相同目录。

| 冰技能 | 一级法力 / CD | 一级行为 |
|---|---|---|
| 冰霜弹 | 9 / 2s | 7 距离内最近可见目标，90% 攻击；命中附 1 寒意 |
| 冰枪 | 20 / 5s | 7 距离、锁定朝向的窄通道内选目标，200% 攻击；命中附 1 寒意 |
| 冰晶风暴 | 30 / 10s | 8 距离锁定落点，半径 3.4；4s 每 .5s 造成 50% 攻击并附 1 寒意 |
| 霜环 | 22 / 8s | 半径 4，80% 攻击；区域独立积累 2 寒意 |
| 暴风雪 | 28 / 11s | 8 距离锁定落点，半径 3.4；4s 每 .5s 造成 22% 攻击并附 1 寒意 |
| 极寒破碎 | 45 / 30s | 半径 5，400% 攻击；冻结目标额外乘 1.5，命中后消费冻结，再附 1 寒意 |
| 绝对零度 | 42 / 32s | 半径 5，150% 攻击；区域先尝试冻结，再积累 1 寒意 |

寒意基础持续 3s，冻结基础 1s；完整合并、免疫与抵抗规则归[状态合同](combat-architecture.md#状态合同)。
冰弹/冰枪目前是出手 tick 的射线/通道命中，视觉冰晶连线不参与弹道碰撞；不是新增可飞行、可拦截的抛射体。
范围查询使用共享空间索引与完整句柄稳定排序，距离同分按句柄；射线候选用最多八项的预分配数组，不排序全世界。

### 火焰树

```text
火球（炽焰 / 溅射 / 节流）
├─ 灼热射线（热流 / 扩束 / 速燃）
│  └─ 烈焰火墙（火势 / 火线 / 余烬）
│     ├─ 燎原专精
│     └─ 焚天火域（焚蚀 / 疆域 / 长燃）
└─ 爆裂炎弹（爆芯 / 弹群 / 急咏）
   └─ 陨星坠落（陨击 / 冲击范围 / 蓄能）
      ├─ 爆燃专精
      └─ 末日炎爆（终焰 / 毁灭范围 / 复苏）
公共：火焰研习 / 控火节流 / 余热延续 / 耐热体魄
```

沿用冰霜表中的等级、父节点、投入门槛与等级上限，**各系分别统计投入**；冰霜投入不能解锁火焰节点，同系专精互斥，跨系专精互不排斥。陨星已从初始术式移入火树，需角色 20 级、爆裂炎弹 3 级和本系其他节点 18 点。

| 火技能 | 一级法力 / CD | 一级行为，不含前后摇 |
|---|---|---|
| 火球 | 10 / 2.2s | 最远 8、速度 14 的真实弹体；首次接触敌人/地形或达到射程时半径 1.2 爆炸，75% 直接伤害；每层灼烧每跳 6% |
| 灼热射线 | 24 / 7s | 原点/方向固定，长 8、半宽 .35；引导 2s，每 .5s 造成 25% 直接伤害及一层每跳 6% 灼烧；射线被地形截断，显示与判定同端点 |
| 烈焰火墙 | 28 / 10s | 8 距离锁点，横向条带半长 3、半宽 .65；4s 每 .5s 造成 12% 直接伤害及一层每跳 8% 灼烧 |
| 焚天火域 | 44 / 32s | 8 距离锁点、半径 5；6s 每 .5s 造成 18% 直接伤害及一层每跳 12% 灼烧 |
| 爆裂炎弹 | 23 / 6s | 基础一弹，扇形相邻方向差 .15 弧度；同火球速度/射程，爆炸半径 1.4，每枚 70% 直接伤害及一层每跳 6% 灼烧；同轮同目标最多两次成功命中，闪避不占额度 |
| 陨星坠落 | 30 / 9s | 8 距离、半径 2.6 固定落点；出手 .9s 后 280% 直接伤害，命中消费本人灼烧并加入剩余量的 50% |
| 末日炎爆 | 48 / 30s | 在起手时锁定的自身位置引爆半径 5，450% 直接伤害；同样消费本人灼烧，基础转化 50% |

普通火主动每级伤害增加一级值的 6%，终极为 12%，同时作用于该技能施加的灼烧。威力每点 +4%、研习每点 +3%，同桶相加；直接伤害再乘爆燃增幅或燎原代价，灼烧另乘燎原增幅或爆燃代价。
形态每点 +5% 作用半径/射线半宽/火墙半长；炎弹改为每点多一枚，最多六枚。火球节流每点 −3% 法力；炎弹急咏、炎爆复苏每点 −2% 基础 CD。
射线速燃每点 −3% 间隔（最短 .25s，向上量化为整数 tick）并 +10% 所附灼烧持续；火墙余烬每点 +10% 所附灼烧持续；火域长燃每点 +10% 场持续；陨星蓄能每点 +4 个百分点转化率。预览显示实际间隔、完整打击次数、持续及总直接倍率，不将不足一周期的尾段算作一跳。
公共控火节流每点 −2% 法力，余热延续每点 +5% 灼烧时长。**耐热体魄当前为火系直接命中后两秒 Protection，每点减伤 1%，重复刷新、不叠层，灼烧不触发；尚无元素抗性系统。** 减少该节点或洗点会移除该来源保护，其他来源保留。
燎原每点 +1 层本人灼烧上限（最多八层）、+8% 灼烧伤害，直接火伤统一乘 .85；爆燃每点 +10% 直接火伤、+5 个百分点引爆率，灼烧统一乘 .8。引爆率全来源最多 80%，不再放大被消费灼烧的施放者增伤；不引爆其他来源，不因到期/替换/洗点爆炸。
火系减耗上限 50%，消耗向上取整且至少 1；CD 经侧路/施速计算后普通最短 .5s、终极最短 10s。灼烧的来源、满层、末跳及结算合同只维护在[战斗架构](combat-architecture.md#灼烧与引爆合同)。

### 雷电树

```text
电弧（电势 / 支路 / 节流）
├─ 雷枪（高压 / 穿透 / 急咏）
│  └─ 雷霆轰击（雷威 / 落雷数 / 聚焦）
│     ├─ 过载专精
│     └─ 天罚（天威 / 覆盖 / 复苏）
└─ 连锁闪电（初压 / 跳跃 / 远导）
   └─ 雷暴力场（电场 / 扩域 / 持续）
      ├─ 导流专精
      └─ 万雷连锁（主脉 / 分叉 / 续流）
公共：雷电研习 / 电荷节流 / 导电专注 / 静电防护
```

沿用冰霜表的节点上限、等级与前置，独立计算雷电投入。连锁闪电需角色 8 级、电弧 3 级和本系其他节点 6 点；可同时学习两条路线，过载与导流互斥。终极装配上限仍是跨系合计一个。

| 雷技能 | 一级法力 / CD | 一级行为，不含前后摇 |
|---|---|---|
| 电弧 | 9 / 2s | 6 距离内最近可见目标，90% 直接伤害；支路从玩家分别连接不同目标，不回跳 |
| 雷枪 | 20 / 5s | 长 8、半宽 .35 的锁向通道，200% 直接伤害；按沿线距离最多穿透三个目标，地形截断判定与表现端点 |
| 雷霆轰击 | 32 / 11s | 8 距离锁点、半径 2.6；出手 .45s 后开始，间隔 .4s，共三次 80% 直接伤害 |
| 天罚 | 45 / 30s | 8 距离锁点、半径 4.5；出手 .85s 后命中，落点 .8 距离内最近可见目标受 500%，其他区域目标受 250%；核心不重复受外围伤害 |
| 连锁闪电 | 24 / 7s | 首跳 7、后跳 4，最多三个不同目标；首跳 160%，每跳保留 80% |
| 雷暴力场 | 28 / 11s | 8 距离锁点、半径 3.4；4s 每 .5s 造成 25% 直接伤害；每周期从最近的区域目标最多引出一条短链，命中至多三个区域外的新目标，逐跳保留 80% |
| 万雷连锁 | 46 / 30s | 首跳 8、后跳 4，首跳 200%；广度优先，每个节点至多两个分支，整张电网基础十二个不同目标；按深度每跳保留 75% |

普通雷主动每级伤害增加一级值的 6%，终极为 12%；专属威力每点 +4%、研习每点 +3%，同桶相加。所有成功雷电直接命中在目标存活时附导电，基础 4s；导电专注每点延长 5%。静电防护每点提供 1% 短暂减伤，具体命中、替换及与火系保护合成的规则只维护在[状态合同](combat-architecture.md#雷电命中与防护合同)。
形态每点让电弧、连锁、电网多命中一个不同目标，雷枪多穿透一个（最多八个），轰击多一次落雷（最多八次）；天罚/力场半径每点 +5%。电弧节流每点 −3% 法力，雷枪急咏/天罚复苏每点 −2% 基础 CD，力场持续每点 +10% 场持续。
远导每点 +5% 后跳距离；续流每点提高 .02 后跳保留比例，最多 .95。聚焦每点让同次轰击对同一完整实体的后续成功命中增加 3% 直接伤害，累计最多 15%；闪避不累计，槽复用重新计数，不增加落雷次数。
过载每点 +12% 直接雷伤，有该专精时法力统一乘 1.2 一次；导流每点 +1 个电弧/连锁/力场短链/电网目标、+5% 后跳距离，直接雷伤统一乘 .85。远导和导流的后跳距离加成相加、最多 50%；普通链硬上限十二个、电网二十四个，当前合法满构筑电网为二十个。首跳永远取最近可见目标，后跳才优先导电，同条件按距离再完整句柄；导电不赋予眩晕、增伤或额外触发。
电荷节流每点 −2% 法力，与电弧节流相加后最多减耗 50%，最终向上取整、至少 1；取整会产生相邻等级消耗相同的区间。CD 经侧路/施速后普通最短 .5s、终极最短 10s。详情显示实际次数、距离、衰减、聚焦上限与导电期限。

传导复用空间索引，每批次一个访问戳数组和固定 24 项队列，所有分支共用目标额度；不递归派生被动，不创建逐跳 Set。距离、遮挡与稳定排序在每跳局部候选内处理，已选目标即占访问额度，闪避不会导致本批次再次回跳。力场先标记本周期全部区域目标，再发起一条短链，区域内不会因短链重复受击；满人口仍不超过 896 笔命中。雷枪用八项预分配候选数组；聚焦仅在购买该侧路的轰击存续期分配有界句柄/计数数组，结束即释放。

### 现有其他术式

结界、刃阵角色 2 级可装，涡旋 3 级；升级需角色等级不低于解锁等级加当前技能等级。
旧术式冷却继续为基础 CD 除以 `1+施法速度`。实际 CD 全部向上量化为整数 tick，按技能 ID 存绝对期限，换槽、洗点、重学和换装不刷新。

## 构筑提交与交互

K 打开星图：五个学派入口、发光连线、方形主动、圆形侧路、菱形专精；冰霜、火焰、雷电各显示完整两条纵向分支，星辰明确标记尚待扩展。
星图按自然间距展开在 1240×1250 画布，空白处可拖动，滚轮/方向键和“定位”同样可导航；位移由画布边界约束，不缩小节点塞满窗口。主干从完整名称/等级下方出线，侧路在主干外侧走线，互斥专精进入内侧独立通道；不再绘制穿过文字的装饰中轴。
桌面窗口最大 1640px 并居中，画布在宽浏览区内居中；已装备主动显示槽位角标，状态来自已提交 loadout，不来自草稿。布局和标记交互归[界面设计](interface-design.md)。
所有节点悬浮/聚焦可查看说明、等级和前置，Alt 固定浮窗；点击选择后右侧展示当前→草稿等级及参数。加减支持鼠标、触屏和键盘长按：350ms 后每 85ms 一点，达到上限/点数不足、松开、取消、失焦或卸载停止。尚无缩放和搜索。
加减点只改本地草稿，撤销恢复已提交值；关闭窗口丢弃未应用草稿。减少前置会级联退款，提交时再次验证整图。“免费洗点”在家园直接提交全部初始等级并退还已投入点数；荒野或施法/持续效果未结束时禁用且显示原因，不再用“重置草稿”代替洗点。
一次 `commit-skill-build` 携带完整 ranks 与 revision；过期或重复提交不会重复扣点，失败保持原构筑。成功才编译修正和增加 revision，不逐帧遍历节点。
野外只允许增加点数；家园可免费退款，但动作/持续效果未结束时拒绝。移除已学主动清空对应槽，保留技能 CD、生命、法力。
暂停可装配/提交，死亡禁止改动。预览没有战斗效力，自动装备评分不读取草稿。

六个槽允许空位，1–6 施放、Q/E 用药、F 自动施法。主动需已学且满足等级才可装配；相同技能换槽会交换，装配第二个终极被拒绝。
Pointer Capture 与 6px 拿起阈值、空格拿起/1–6 放入、Esc/失焦/取消拖放沿用已有组件。面板和 HUD 都接受拖放；拖动结束不会误触发施法。
详情图标/槽图标共用浮窗与 Alt 固定；树节点点击只选中，已提交的主动才可拖动。桌面固定六槽装配区；窄屏树与详情上下排列，标题和关闭按钮可见。

## 施法时间线与战斗提交

每个角色只有一个施法动作：前摇 → 出手一次 →（射线引导）→ 共享后摇。开始时校验生命、学习、槽、等级、冻结、资源、运行容量和 CD，立即扣法力并启动自身 CD；保存本次攻击属性、技能修正和落点/方向。
技能效果到出手 tick 才生成，期间不会预先造成伤害或附状态；后摇阻止其他法术和普通自动射击。普通射击也在前摇停用。
换槽不能绕开共享动作。移动可在后摇执行，不取消其剩余锁定时间。

| 技能 | 基础前摇 / 后摇，秒 | 移动 |
|---|---|---|
| 脉冲 / 闪电 / 冰弹 / 结界 | .18/.28、.20/.30、.16/.22、.15/.25 | 可移动吟唱 |
| 霜环 / 冰枪 | .25/.30、.30/.30 | 站定 |
| 陨星 / 涡旋 / 刃阵 | .45/.40、.35/.35、.30/.30 | 站定 |
| 冰晶风暴 / 暴风雪 | .45/.40、.40/.35 | 站定 |
| 极寒破碎 / 零度 | .60/.50 | 站定 |
| 疾风步 | 0/.25 | 固定朝向疾行 |
| 火球 | .20/.25 | 可移动吟唱 |
| 灼热射线 / 火墙 / 炎弹 | .30/.30、.40/.35、.35/.35 | 站定；射线出手后另有 2s 引导 |
| 焚天火域 / 末日炎爆 | .65/.50、.70/.55 | 站定 |
| 电弧 | .14/.22 | 可移动吟唱 |
| 雷枪 / 雷霆轰击 | .30/.30、.45/.40 | 站定 |
| 天罚 / 雷暴力场 / 万雷连锁 | .65/.50、.40/.35、.60/.50 | 站定 |

前后摇受施法速度缩短；除疾行外前摇不低于 .10s，后摇不低于 .15s。
手动移动取消站定法术前摇及射线引导；挂机普通寻路在前摇/引导等待，紧急躲避优先打断。冻结同样取消未出手动作和射线引导、禁止新施法与移动。射线中断立即停止后续周期与射线表现，保留其他已释放的火墙/火域；费用只在开始支付一次，不退费。
取消保留法力消耗和该技能 CD，并有 .12s 短恢复。疾风步可以抢断施法/后摇，但保留被抢断动作的最晚恢复期限，不能用来连续倾泻法术；冻结期间不能疾行。药剂不受施法锁限制。
死亡不释放余下前摇。保存/过图/恢复丢弃未出手和持续场，保留费用、技能 CD 和动作剩余恢复。

F 每 12 tick（10Hz）检查，**一次最多启动一个技能**；优先低血护盾，其次站定法术，最后移动法术，同类按槽顺序。动作忙碌时跳过。Z 复用当前威胁预测检查原地停步是否安全，安全时允许主动停步起手重型法术；吟唱期间以实际站定意图继续预测，不将原寻路轨迹的风险误判为必须中断。真正需要移动躲避时仍优先打断。手动持续移动只自动释放移动法术；关闭 F 不发起自动施法。
自动范围技能需有可见有效目标，空范围不扣费；结界需生命不高于 60% 且无已有结界。玩家仍可独立手动施法/用药。Z 的移动与寻怪规则见[玩家自动战斗](simulation-and-ai.md#玩家自动战斗)。

家园允许空放手动技能并推进全部时间线；自动施法不在家园运行。地面法术无目标时取前方 4 单位，手动冰弹/闪电空放可见射线。技能从实际区域中心检查地形遮挡，近战范围包含目标半径；连锁逐跳检查视线且不重复命中同一目标。
霜环和零度的区域控制独立于伤害命中；其余冰法只在命中成功、目标仍存活时附加寒意。碎冰倍率读取命中时的目标冻结状态，倍率来自本次施法快照；闪避不消费冻结。
火系与雷系完整攻击属性和修正取起手快照，通过命中缓冲的 `castStats` 传递；命中/致命/吸血也使用该快照，目标防御在实际命中时读取。冰霜和其他旧通路的攻击掷骰、技能倍率/范围/寒意参数已快照，准确率、致命、吸血仍在结算时读取角色属性；不能宣称旧技能已经全部迁移。

持续技能每种最多一份：涡旋/刃阵、两份冰场、火系射线/火墙/火域/陨星、雷系轰击/力场/天罚，受已学习和实际装配约束；换槽不清除已释放场。陨星出手后第 108 tick 命中；涡旋和基础冰场每 60 tick 一跳，共八跳（含末 tick），刃阵每 30 tick 共十六跳。雷轰击首次延迟 54 tick、间隔 48 tick，天罚延迟 102 tick，力场间隔 60 tick、次数按完整周期计，不足一周期的尾段只保留场。
火系另有固定 24 弹运行池；每 tick 用扫掠圆柱求最早接触，地形平手优先，怪物平手按句柄。每颗弹只爆一次，爆炸按真实接触点查询并检查遮挡，满池在扣费前拒绝。单轮炎弹的命中计数跟随该轮弹体，全部弹体结束即释放。
逐场排空命中缓冲再处理下一场；权威效果不受 128 项视觉缓冲丢弃影响。持续期拒绝重放，落点不追踪原目标，目标移除/槽复用不改变落点；刃阵跟随当前玩家。
牵引走地形通行，领主只承受 20%。暂停不推进；清场、过图或读档取消场，不返还资源。场本身不是附着在目标身上的 DoT。
疾行遵守 `moveActor/SurfaceMotion`，受阻停止且不切向滑行；已发布的敌方弹道和地面攻击不因施法者冻结被追溯撤销。
结界不可刷新，防御、闪避、格挡和被动免伤盾之后才吸收；耗尽或到期可重施，生命损失和反伤只计算穿透部分。

## 免费资源与批量表现

采用 [Kenney Particle Pack](https://kenney.nl/assets/particle-pack) 中的六张透明 PNG：
`magic_03`、`star_05`、`flame_01`、`smoke_04`、`slash_02`、`twirl_01`，下载包内许可证标识版本 1.1，许可为 CC0。新增四张分别用于陨星火焰、爆炸烟尘、脉冲/刃阵斩痕和涡旋；没有运行时消费者的素材不打包。
调研还比较了 [Mikodrak 的 2D Spell Effects](https://opengameart.org/content/2d-spell-effects)
和 [Cethiel 的 Arcane Magic Effect](https://opengameart.org/content/arcane-magic-effect)，均为 CC0，未作为本次构建输入。
选择 Kenney 是因为透明形状可以与当前 3D 地表、技能色和同一实例材质配合，避免为每个技能加载独立序列图。

源文件位于 `assets/effects`，`sources.json` 登记作者页面、下载 URL、包/文件 SHA-256、原始路径、字节数和许可。
离线构建复用 `sourceReader` 校验每份输入，六张图各缩至 248²，加四像素透明间隔组成 3×2 格、768×512 图集，格位顺序与上述文件一致。
输出 `effects/skills.png`，随游戏发布原文 `kenney-LICENSE.txt` 与来源清单；不在运行时下载资源。
技能界面使用本地彩色 SVG 图标，与装备共用框体和角标位置；角标显示技能等级，颜色表达学派，不代表物品品质。

模拟端用固定 128 项的 `CombatEffects` 保存种类、起终点、半径和起止 tick。
起终点绝对世界坐标使用 Float64，表现帧保留原精度；实例位置相对当前玩家原点计算，绝对坐标只用于地表高度查询。
到期用末项交换删除；满容量时只跳过新表现，不跳过伤害、治疗、减速或资源消耗。
表现事实经独立转移缓冲发送，主线程不持有 ECS 引用。效果可以跨多次发布存在，避免一次性事件被低刷新错过。
显示时按模拟时间推进，暂停时冻结；极慢的表现端可能错过已经在模拟中结束的短效果，不阻塞战斗。

主线程按种类分流同一份 128 项表现事实。`SkillEffects` 接受玩家技能、陨星落地、碎裂与引爆事实，并读取独立的 24 弹表现数组，展开成最多 4096 个平面实例，一张图集和两份不受场景曝光压暗的加色材质（空中绘制与地面投影）。
实例属性选择图格、透明度和环/辉光/光带/冰晶/符文形状，并在形状高位标记地面投影；两次绘制共享几何、矩阵、颜色与形状属性，
各自在顶点阶段裁剪不属于本通道的实例，只上传本帧使用的矩阵与属性区间，不创建逐粒子 Mesh。
火域最多 98 个实例，其他效果更少；总额由 4096 池约束。使用种类、坐标、起始 tick 和模拟时间生成稳定变化，不读取 Math.random，也不消耗模拟随机数。

每绘制帧先俯视合成一次，再由 full/fast 地形与水面在实际片元 XZ 接收。
它不取技能中心的海拔、不细分逐技能网格，也不把图案投到怪物或掉落物上；实体照常遮挡其后的地面。
正常透明印记保存预乘颜色与覆盖率，加色印记累加 RGB 并保留已有覆盖率；地表先合成印记再应用远景雾，未探索区不显示印记。
冰晶、飞散粒子、电弧与结界球壳保留立体表现及深度测试；电弧光带按起终点高差倾斜，不再只取两端平均高度铺平。
投影纹素密度固定为每逻辑单位 32 像素；细线精度受这项独立的表现预算限制，不随怪物数量增加渲染目标。
纹理、实例缓冲与投影附件进入共享资源预算；世界切换复用目标、重新绑定接收材质，关闭时由层释放。
掉落品质环在这张投影中按片元导数保证最低两纹素有效描边宽度，边缘抗锯齿并保留主环亮度；无需提高投影分辨率。
其光柱采用保持世界竖直的相机朝向平面，支持旋转视角，细亮芯与外围光晕共同提供辨识度。
表现帧大小由 `RenderFrame.bytes` 的布局计算，两份交替转移，不手写偏移，也不复制未消费的怪物等级与 AI 活跃标记。
资源归 `CombatLayer` 所有，与角色资源共同完成加载、预算申请后挂载；任一加载失败会释放已成功项并明确报错。
图集通过带 AbortSignal 的 fetch 和 createImageBitmap 解码，解码时翻转 Y；关闭时中止加载并关闭已解码的 bitmap。
重开复用池，重置清空实例并隐藏结界，关闭释放图集、几何、材质和实例缓冲。世界运行时的资源所有权机制沿用现有合同。

冰系新增冰晶射线与周期冰场，复用 Frost 图集格位和固定实例池；不增加贴图资产。冻结期限随有界表现包传输，怪物呈冷色并停留静止姿态。HUD 区分增益/减益、控制标签与剩余时间，施法条显示前摇/后摇。

`ActorStatusEffects` 为玩家与可见怪物补充附着式状态表现：减速/寒意显示贴地霜环和三枚缓慢环绕的冰晶；冻结另显示六棱半透明冰壳，冰晶固定并长高。两者同时存在时共享一组霜环/冰晶，冻结解除而减速仍在时只退回减速表现。角色位置使用原插值结果，霜环复用地形投影；冰壳按体型缩放，透明度沿用角色距离和出生点淡出。

表现逐帧读取权威 `slowUntil/frozenUntil`，玩家表现包携带实体槽定位同一组状态数组；不重新计时、推断命中或在主线程保存 Buff。动画只用模拟时间，暂停冻结；到期、移除、死亡、实体复用和世界重置不残留实例。冻结时玩家与怪物均保持静止姿态。三份固定池最多容纳 897 组霜环、897 个冰壳、2691 枚冰晶，双面透明材质使用单遍，最多增加三批绘制，仅上传已用前缀；复用已有角色遍历与地面高度，不逐角色创建 Mesh、材质、DOM、计时器或新纹理。池在 `CombatLayer` 构造时进入资源账本，随层释放。

灼烧另读取 `burnUntil/burnStacks`，每个可见角色三片附着火舌、两团上升烟尘和三颗火星；强度随层数增长，到八层达到视觉上限，多来源更高层数不继续堆实例。可与减速/冻结同时显示，各自独立到期。
三份新增实例池容量分别为 2691/1794/2691，最多增加三批绘制；无逐角色对象、计时器或新贴图。火舌为本地程序化 shader，烟尘正常透明混合，火焰/火星加色；复用角色位置和海拔。资源记账、重置和释放沿用上述状态池。
火系弹体的 XYZ/前帧 XYZ/种类通过 `fireShotArrays` 与同一 `RenderFrame` 双缓冲批量传输，权威弹体不依赖可丢弃的 128 视觉事实，主线程不预测命中。HUD 显示灼烧层数、剩余时间和射线引导阶段。没有新增外部资产，原图集来源及许可不变。

导电与静电防护分别读取 `conductiveUntil/staticGuardUntil`：导电为身体周围三道蓝白程序化折线电流，静电防护为两道蓝色倾斜环绕电环，均为增量扩展已有角色遍历。两份固定实例池分别最多 2691/1794 个实例；合计八个附着状态池，资源记账、已用前缀上传、距离淡出、重置与释放规则相同。可与冰、火独立叠加显示；动画与截止时间只读模拟时钟，暂停不走动，到期或实体移除立即消失。HUD 区分导电减益与静电防护增益，两者都不标成控制。复用图集与本地 shader/SVG，不增加外部资产或纹理下载。

## 伤害飘字

`CombatVitality` 记录实际生命损失到模拟内部 `CombatEvents`，`CombatFeedback` 再写入 `CombatText`，包含普攻、技能、反伤。暴击标记从攻击结果经弹道/命中缓冲传入，不在表现端重新掷骰。过量伤害只显示剩余生命；闪避、免伤盾、结界全吸收和零伤格挡显示对应文字，受击免疫期内未结算的攻击不刷字。献血、治疗和死亡事实不直接生成飘字；奖励不依赖飘字是否显示。
表现时间与飘字出生时间统一使用 `tick / simulationHz` 换算；不使用累计或乘法近似，避免部分 tick 出现极小负年龄，使暂停在命中时的新飘字一直隐藏。

最多 256 条事实保留 .95 秒，同一完整实体句柄和类型在首击后 .08 秒内合并；普通与暴击不合并，实体槽复用不会串字。死亡不清掉已有飘字；容量满覆盖最旧的显示事实，不影响任何战斗结算。暂停冻结模拟时间，重开清空表现缓存。

`DamageNumbers` 使用一张 1024×128 Canvas 字形图集（RGBA8 约 512 KiB，无 mip）和一个实例化字形网格。数字、闪避、格挡、护盾、反伤共用材质，最多 2560 个字形，只上传有效前缀；满容量仍只增加一次 draw call，不创建逐条 DOM、网格、贴图或定时器。普通伤害为浅米色、暴击金色放大、玩家受伤红色、护盾青色，并保留文字/符号区分。字号按屏幕像素保持，随模拟时间上浮淡出，沿用角色远距淡出。

图集与实例缓冲归 `CombatLayer`，加载完成且预算申请成功后挂载，失败、关闭时释放。事实经两份交替表现包传输，飘字字段占 10,496 字节，总包大小由 `RenderFrame.bytes` 计算（包含新增冻结期限投影）；没有每命中一条跨线程消息。

## 验证范围

怪物施法起点使用 `hand_l` 的离线曲线；抬手飞刃和血契连线按网格实际混合权重计算，释放帧的同源常量与权威地面高度决定弹道 XYZ。表现包传输 `age/y/previousY`，飞行直接插值模拟海拔；移除旧的 `launchHeight/groundX/groundZ` 表现字段和沿地面升降的衔接。完整序列、缓冲与资源成本见[角色资产](actor-assets.md)。

伤害/治疗遵守[攻击遮挡](terrain-navigation.md#攻击遮挡)：脉冲和霜环只影响与玩家身体中点间无遮挡的目标；连锁每跳重新检查上一目标到下一目标的视线；敌方挥击、冲锋、夹击、横扫、石脊和治疗同样在结算时检查。范围预警不按障碍裁剪几何，遮挡通过目标筛选生效。没有可见目标时自动范围技能及连锁不消耗资源，手动脉冲/霜环仍允许空放。

`SkillBuild`、`StatusSystem`、`FrostCasting` 与 `Skills` 契约测试覆盖购买可达性、互斥专精、来源独立到期、控制免疫、命中附加、施法打断/恢复和装配/升级约束、冷却保存、无目标施放、闪电目标唯一性与衰减、减速到期及实体复用、
疾行位移和真实受击免疫、结界消耗/到期、陨星锁点与快照伤害、八次牵引与领主抗性、刃阵内圈/跟随/重放约束、三技能满人口分段结算、表现容量耗尽以及真实 ArrayBuffer 转移隔离。
浏览器检查真实技能 Worker 命令、34 节点星图与草稿原子提交、拖拽交换/取消、键盘装配、图标浮窗与 Alt 固定、升级、窄屏、图集加载与着色器绘制，
同时检查六种怪物实际进入五组模型池及新预警；图集失败走明确失败与重试路径。
`skill-expansion.spec.ts` 检查新技能跨 Worker 的在途/命中事实、图集格位、暂停冻结，以及三种新增领主的 HUD 名称、动作与前摇/释放截图。Boss 震波、三段锁向弹幕、取消与满载表现池另有契约保护。
`benchmark:app` 的满载场景使用六种怪物混编和受伤同伴，包含祭司感知成本。
`BurnSystem`/`FireCasting` 测试覆盖独立层期限、同刻合并、末跳、来源失效、满层替换、满人口/满池、保存周期相位、盾内附加、闪避不消费、本人引爆与快照、真实弹体遮挡、同轮上限、射线中断及退款清保护。`fire-skills.spec.ts` 用真实 Worker/WebGL 检查火树 34 节点、2K 居中、节点装备标记、各火技能与持续状态、暂停和到期清理。
`fireEffects` 基准先给 896 目标挂满四来源×八层（28,672 层），再叠加火墙/火域/陨星，推进 1,200 tick；包含状态与实际伤害/死亡事件消费，记录直接命中、合并后的周期事件、P95/P99 和最大 tick。它是极限同步负载，CPU 平均不能代替峰值或 GPU 帧率结论。
`LightningCasting` 测试覆盖导电优先与地形阻断、全电网预算、穿透顺序、区域/短链去重、聚焦命中与槽复用、天罚核心唯一、盾内附加、来源失效、满人口和视觉池耗尽、快照/退款/恢复、版本 8 与真实缓冲转移。`lightning-skills.spec.ts` 用真实 Worker/WebGL 检查雷树、七个主动、导电/静电附着、暂停与到期清理。
`lightningEffects` 基准以 896 个目标叠加十二次力场、八次轰击、一次天罚及十次二十目标电网，推进 1,200 tick，核对 19,016 次实际命中、所有状态最终到期，记录查询/候选数、每 tick P95/P99 与最大值；包含实际结算和事件消费，不包含 AI、移动或 GPU。
2026-09-21 的[雷树测量](measurements/lightning-skill-tree.json)中，五次样本平均 tick 耗时的中位数为 .0213ms；最后一个样本 P99 为 .7751ms、最大 4.6845ms，234 次查询累计返回 209,348 个候选。这个同步密集场景通过现有 CPU 门禁，但不能据平均数宣称无峰值，也不代表 896 个可见导电角色的 GPU 成本。雷系首轮参数尚待完整中后期构筑平衡；既有普攻校准重跑不变，不是雷系平衡证明。
2026-09-20 的[火树测量](measurements/fire-skill-tree.json)中，五次样本平均 tick 耗时的中位数为 .0287ms；最后一个样本的 tick P99 为 1.504ms、最大 17.949ms，不能只用平均数宣称没有峰值。构建、规则与浏览器回归、500 次世界替换及开发页检查通过。当前火系数值为首轮可玩参数；既有普攻平衡报告重跑无变化，不代表火系完整构筑已完成中后期平衡。
同一基准的 `iceEffects` 使用 896 个目标、4,480 份初始状态（四来源减速与同步冻结到期）、双冰场共 14,336 个命中，推进 480 tick，包含实际伤害/附加状态及事件消费；记录中位每 tick、P95/P99 与最大 tick，不包含 AI/移动/GPU。这个场景与既有完整赶路、人群和自动战斗场景分别验收，不能互相代替。
