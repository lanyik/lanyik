## 构筑提交与交互

技能不占物品库存。节点等级是构筑权威数据，已装配槽与 UI 草稿分开：预览没有战斗效力，关闭窗口丢弃未提交草稿。提交携带完整 ranks 和 revision，核心整体校验等级、点数、前置、互斥和实际购买顺序的可达性；节点不能靠自身投入或循环前置解锁。

点数必须守恒。过期请求、非法构筑或重复提交不能重复扣点，失败保持原状态；成功后才编译修正和增加 revision。编译发生在构筑变化时，不在每个 tick 遍历树。

野外只允许加点，家园可退款；动作或持续技能未结束时拒绝退款。死亡禁止构筑修改，暂停可以操作。退款移除失效装配与对应自体效果，保留其他来源状态及已付费用、技能 CD；属性重算保持生命/法力比例。

主动槽允许空位，必须装配已学且满足等级的技能。同技能换槽交换位置，终极装配数量受核心限制。CD 按技能身份保存，换槽、退款、重学和换装均不能重置；施法键和拖放规则由界面设计维护。

## 通用主动与常驻被动

通用主动独立成长；四系侧路按学习结果编译。通用常驻被动还必须装入独立被动槽，不能因已学习就生效，也不占主动槽或生成无限期 Buff。

被动装卸只允许存活角色在家园且动作、持续技能结束后进行；核心校验槽位解锁、学习状态和唯一性。被动收益与代价进入同一属性加成体系，统一应用最终上限。装备比较、寻宝和实际结算必须读取同一份已提交被动上下文。

装卸、升级、退款保持生命/法力比例，不刷新技能或免伤盾 CD。存档只保存节点与装配身份，恢复时重编译派生结果。

全域拾取只消费当前世界已生成的有界地面池，使用轮转和每批尝试预算；失败也占预算且物品完整保留，不能因满包饿死其他分类。它不加载远方地图、远程开箱或绕过库存事务和副本持久化屏障。暂停、死亡停止拾取。

## 施法时间线与战斗提交

每个角色只有一个共享动作：前摇 → 出手 → 可选引导 → 后摇。起手前检查生命、学习、装配、控制、资源、容量和 CD；通过后扣费、启动 CD，并快照攻击属性、技能修正及落点/方向。出手前不产生技能伤害，换槽不能绕开动作锁。

命中使用起手输出快照和命中时的目标防御；后续换装、被动装卸或强化到期不改写在途输出。范围和连锁通过权威地形查询检查遮挡，候选按完整句柄稳定排序，不能让表现端重新选敌或掷骰。

手动移动和冻结可打断站定前摇/引导；取消不退款、不清 CD，也不撤销已经释放的独立效果。疾行可以抢断动作但保留原动作最晚恢复期限，遵守地形通行。死亡不补发余下前摇。检查点不保存未出手动作和在途效果，过图或读档恢复时清除这些运行态，保留费用、CD 与剩余恢复；普通保存不因此取消当前施法。详细持久化归[角色存档](character-saves.md)。

持续场和火系弹体使用有界运行池，准入在扣费前完成；每场完成本阶段命中提交再处理下一场。弹体按扫掠最早接触处理，同一弹只爆炸一次，落点不因目标移除或槽复用改变。场的周期按模拟 tick 推进，不足完整周期的尾段不补跳；暂停停止全部时间线。

自动施法低频检查，每次至多启动一个技能；忙碌或无有效目标时不空耗资源。防护、强化和攻击优先级由核心定义。它与[自动战斗移动](simulation-and-ai.md#玩家自动战斗)协作：安全时可停步施法，紧急躲避优先打断；手动移动优先。自动施法和自动寻怪是独立开关。

## 免费资源与批量表现

权威效果和可丢弃视觉事实分开：视觉池满不能改变伤害、持续场、掉落或奖励。弹体、攻击轨迹、状态期限通过表现帧传输；主线程插值已有结果，不推断命中或维护第二份状态。敌方攻击同样复用权威轨迹和取消结果，模型演出不决定实际攻击区域。

瞬态特效、附着状态和敌方攻击使用固定实例池，复用角色遍历、插值位置和地表高度，只上传有效前缀；不逐角色创建网格、材质、DOM 或计时器。所有动画使用模拟时间，暂停冻结，实体移除、复用和世界重置不残留状态实例。

地面法阵、预警、光环和接触印记提交到战斗层的地面投影，由真实地表接收；立体弹体、电弧和粒子保持深度测试。投影范围/分辨率是独立表现预算，接收与资源合同见[渲染流送](../render-streaming.md#渲染层与表现资源)。

资源归 CombatLayer：加载和预算申请成功后才挂载，任一加载失败释放已完成项；中止加载、关闭位图、释放图集/几何/材质/实例缓冲随层完成。重开复用池并清空状态。资产来源与生成输入由[资产清单](../README.md#assets)维护，不在本文复制许可文本。

## 伤害飘字

实际生命损失和防御结果经 CombatEvents → CombatFeedback → CombatText 发布，暴击与反伤标记来自结算事实。表现不重新掷骰，奖励不依赖飘字显示。

事实按完整实体身份及类型合并，槽复用不能串字；死亡不抹去已有文字，满额只淘汰显示事实。出生与当前时间使用同一 tick 换算，保证命中当帧与暂停时可见。

DamageNumbers 使用共享字形图集和实例池，按屏幕像素保持字号，资源归战斗层并计入预算。不逐条创建 DOM、网格、贴图或定时器。

## 验证

规则变更检查 SkillBuild、Skills、PassiveSkills、各系 Casting 和 CharacterSave 测试：覆盖点数与可达性、过期提交、取消扣费、容量、快照、槽复用和存档。交互变更跑对应真实 Worker 浏览器用例；表现变更核对暂停/重置、像素与绘制批次。

执行命令与选择范围统一见[测试策略](../testing.md)。具体倍率和时序的独立预期保留在测试，不在文档维护第二份参数表。
