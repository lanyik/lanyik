# 主角行走、镜头跟随与就近施工

状态：已实现。登陆后操控一名先遣员，镜头持续跟随主角。沿用
[建造与采矿](./construction-and-mining.md)、[能源与加工](./energy-and-production.md)
的工业规则。存档与跨区勘察仍待实现。

## 操作与边界

- 登陆选址保留原镜头操作和矿区定位。指挥中心展开后在相邻可通行格生成主角；
  建造前检查出舱位置，没有出口时拒绝展开。
- 画布获得焦点后，WASD 按镜头朝向行走，Shift 奔跑。右键旋转、滚轮缩放，镜头
  保留原视距范围和朝向，目标连续跟随脚下地表，禁用自由平移。
- 登陆后的矿区/返回基地按钮发起真实步行导航，到目标相邻可通行格停下。WASD 接管，
  空格或停止按钮取消；导航按钮将焦点交回画布，WASD 可立即接管。打开建造目录也停止
  自动导航，仍允许手动边走边规划；空格仅在画布内生效，不覆盖 UI 按钮的键盘操作。
- 建造、拆除的完整占地必须在主角所在格 6 格内。建造不能覆盖身体；原有地形、
  矿点、基地 32 步服务和实际物资约束继续检查。设备配置仍通过终端进行。
- 工业暂停和 1/2/4 倍只影响生产、昼夜与电量。主角始终常速走路，方便暂停规划。
  页面隐藏或窗口失焦停止移动且不补算；画布失焦清空手动按键。
- 当前活动范围为已有 96×96 勘察窗口。海洋、海岸、湖泊、山体和建筑不可通行；
  干燥丘陵与森林可走，每棵树尚无独立碰撞体。仓库继续统一收货，未增加个人背包、
  搬运、远程施工或离线收益。

## 核心与时间

[Explorer.ts](../../apps/expedition/src/core/exploration/Explorer.ts) 持有连续地面坐标、
朝向、步行距离和导航状态，不依赖 DOM、Three.js 对象或异步移动任务。坐标以一个
六边形半径为单位，与公开 `getHexCenter()` 的 even-q 布局及半行偏移一致，支持负坐标。
[配置](../../apps/expedition/src/content/explorer.ts) 为：20ms 固定步长，步速 3.2 半径/秒，
奔跑 5.6，身体半径 0.18，施工距离 6 格。对角输入归一化，不因多按一个方向而加速。

绝对时间戳转为整数微秒后累计，每帧最多接受 250ms，不无限追赶。失焦/隐藏后的首帧
只建立新基准。每固定步长检查身体圆与当前格及六个邻格的精确多边形距离；最大单步
位移小于身体半径，受阻时尝试沿轴滑动。建造复用同一身体/占地相交判断。

导航在已勘察地形内执行 BFS，最多展开 9,216 格，使用与手动行走相同的通行规则。
拆建后重算当前路线，不可达时明确停止。长距离运输仍按总体设计使用分层寻路，
本轮没有创建跨园区运输系统。

## 会话、输入和表现

[GameSession.ts](../../apps/expedition/src/app/GameSession.ts) 负责出舱、导航、施工校验与
重开清理，在工业更新之前独立推进主角。状态/所在格变化立即更新只读 UI 快照，
连续坐标至多每 100ms 发布；模型与镜头逐帧插值，不反写核心位置。移动时复用基础
施工预览，只重查距离和身体碰撞；地块、布局或材料足够与否变化才重算基地服务通路。

[ExplorerInput.ts](../../apps/expedition/src/presentation/ExplorerInput.ts) 拥有画布按键、
窗口释放和焦点监听，从相机前向量计算移动方向。输入框、组合输入和 Ctrl/Alt/Meta
组合不触发行走，释放时移除全部监听。

[ExplorerLayer.ts](../../apps/expedition/src/presentation/layers/ExplorerLayer.ts) 通过公开
`WorldRenderLayer` 挂载一个带头盔、背包、步态和定位标识的宇航员。几何与材质一次创建，
专属资源账户持有；换世界时拆下，最终释放归零。高度取自 `WorldSurfaceAnchor`，
行走不重建几何，渲染驻留不决定主角或工业状态。
闲置时复用跟随位置，不重复查询地表或写相机目标。

根库的 [HexMap.ts](../../src/HexMap.ts) 新增并实际用于游戏：

- `cameraPanEnabled`：布尔属性，控制 WASD、触摸和修饰键平移，保留旋转/缩放。
  修改时清空原键盘和拾取状态，避免残留输入。
- `setCameraTarget(worldX, worldZ)`：以浮动原点之前的连续逻辑坐标跟随地表，保持镜头
  偏移。校验已加载世界、有限数值和有限地图边界。`setCameraTargetTile()` 归一化
  格坐标后复用此接口。
