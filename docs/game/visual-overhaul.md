# 写实暗黑视觉改造项目

导航：[文档索引](../README.md#game) · [当前进度](development-priorities.md)

2026-09-27 确定方向：写实暗黑，桌面独显、2560×1440 / 60 FPS。目标是材质、光照、角色动作、世界氛围、技能与界面共同成立的现代游戏画面。最终目标硬件、最低配置和完整游戏达标验收仍待确定。

本页维护跨领域美术标准、工作包和验收顺序；当前实现分别归[角色资产](actor-assets.md)、[环境资产](environment-assets.md)、[技能效果](skills-and-effects.md)和[界面设计](interface-design.md)。主角骨骼分层已落地；B1 已接入固定检查点、统一线性 HDR 输出及天空环境照明，B2 已交付近景动态阴影、副本连续路线、首批扫描石材、共用树木风动，以及副本连续岸坡、暖火与倒木。山地结构、体积雾、荒野岸线、完整废墟和界面改造仍待实施；已交付渲染能力不代表世界美术品质已验收。

2026-09-29 现有六边形版本已留存。新世界的数据、仓库、Three.js 限制与基建实施顺序统一归[连续世界基座设计](../decisions/continuous-world-foundation.md)；本页保留美术目标、样板方法和验收边界。先完成技术样板，B2 的山地/大气扩展据此接续，不把渲染能力设想记为交付。

## 统一标准与差距

以风化石材、泥土、旧铁、皮革为主要材质语言，冷色天光与局部暖火形成层次。暗处仍保留轮廓与必要细节；粗糙度、法线、磨损和潮湿要对应物体结构，不能用全屏压黑、统一油亮或高频噪声替代质感。建筑、人物、怪物和植被保持一致比例及细节密度。

| 领域 | 现有基础 | 改造缺口 |
|---|---|---|
| 角色 | 主角骨骼分层、敌人实例化动作、基础合成声音 | 写实模型、职业武器握持与专属动作、侧移/后退/转身、脚部接地、声音层次 |
| 地表与植被 | 法线/粗糙度/AO、坡面混合、树木 LOD、树冠风动及同步阴影、副本连续岸坡 | 山脊沟谷与崖壁结构、陡坡材质尺度、接触细节、树冠透光细化、荒野自然岸线 |
| 光照与大气 | 同源天空/PMREM 环境照明、线性场景合成、统一 ACES 输出、近景太阳阴影、距离雾与边界面片 | 有空间密度的体积雾、深度交界、接触阴影、辉光与进一步抗锯齿评估 |
| 技能 | 有界实例池、投射图案、元素颜色 | 蓄势/释放/命中/残留的视觉节奏、材质和场景交互、拥挤时的优先级 |
| 界面 | 快捷键、事务反馈、焦点语义、虚拟网格 | 游戏 HUD 构图、装备槽位与角色布局、图标资产、操作动效与声音 |

美术可见性按环境、普通反馈、关键技能、敌方危险逐级提高；避免所有东西同时发光。先统一一套主角、一个普通怪、一个首领和一组环境素材的品质，再扩大内容。素材须可合法用于游戏并符合仓库分发方式，新增来源、许可、哈希与离线构建同时落地；现有免费试装不能作为最终品质上限。

## 山地与大气验收缺口

2026-09-28 复核：现有检查点主要覆盖林地、空地和有限副本岸坡，没有覆盖山脊轮廓、深谷、陡崖与低角度地平线。地形环境反射已修正粗糙度积分，受控小场景与 Standard 对照通过；整体材质观感、山地与雾仍须独立验收，既有帧时记录不能代替这些画质检查。以下为新基座样板的美术验收要求，先于继续扩充营地道具与废墟：

- **山地结构**：山脊—沟谷—山口具有清晰的大尺度关系，崖壁、冲刷沟、岩层和坡脚堆积具有中尺度形态，材质尺度与陡坡投影合理；增加噪声或单独提高贴图分辨率不能替代地貌设计。角色落脚、阴影和可通行形态一致。
- **体积大气**：现状见[环境资产](environment-assets.md#地表数据和着色)，距离混色与透明薄片均不算体积雾。新效果须有空间厚度、正确的山体遮挡及相机进出连续性；受阴影影响的体积光另行验收。替换旧边界面片时保留玩法边界提示。
- **材质校准**：在同一光照下检查干土、岩石、树皮、皮革与潮湿局部的反射差异，湿润范围必须有场景依据。粗糙表面转到低视角仍须保持材质层次，不以全局压暗掩盖错误反射。

新样板沿山脊→山口→峡谷支流→汇流平原→入海口连续游玩，同时检查正常游戏镜头、低角度地平线及穿雾移动；验收轮廓尺度、陡坡拉伸、岩土衔接、阴影/碰撞一致性，以及没有白线、悬空雾层和壳体穿帮。按原生 1440p 的短场景记录画质与成本，本轮未进行这些新样板的性能验收。

## 首个可玩样板

固定种子、镜头和路线：破败营地 → 林间石路 → 湿润河岸 → 首领空地。样板同时包含近景材质、树冠遮挡、远景天空、明暗交界、浅水岸线和混合战斗；不为截图单独调出一套实际游玩无法维持的效果。

一名主角、一种普通怪与一个首领，四系各选一个代表技能。动作覆盖待机、行走、侧向出手、向后移动攻击、定点引导、受击与死亡；体验闭环包含拾取、开包、比较、换装和返回战斗。交付同路线前后截图、短视频、可运行场景及资源记录，界面必须叠在真实战场上验收。

稳定场景以 CPU 和 GPU 各自 P95 帧时不超过 16.7ms 为目标，并记录 P99、最长帧、加载尖峰和输入响应；CPU/GPU 并行耗时不能简单相加。注明实际渲染分辨率、硬件、驱动及浏览器，不以降低内部渲染分辨率的结果冒充原生 1440p。首轮验证使用短场景与单实例，不自动开展全量压测。

### B1 固定光照样本

当前使用 [visual fixture](../../scripts/lib/survivor-visual-fixture.ts) 固定 `visual-dark-10`、初始游侠存档、镜头和林地/空地/岸边三个检查点。每个位置验证真实地形可站立，再通过现有存档加载入口进入真实 Worker 场景；静止比较时暂停玩法，另以键盘移动采样真实战斗。位置和镜头值只在 fixture 维护。

运行、交互游玩和报告命令见[测试策略](../testing.md#视觉改造样板)。输出同检查点截图、视频、有效检查点、逐帧 CPU/异步 GPU 样本及资源账本。这三个荒野检查点继续用于原有光照回归；连续路线另用下面的副本样板，不作为四系技能或最终角色资产验收。战斗资产先选一个近战普通怪与一个首领，施法普通怪在 C 阶段扩展。

### B2 近景阴影交付

同一组检查点已接入地形、树木、主角骨骼、敌人实例动画和实体道具的太阳阴影；地表、水面、草与标准材质共用受影，移除主角圆形假阴影。远行对齐、深度目标、边缘渐出和所有权归[近景太阳阴影合同](../render-streaming.md#近景太阳阴影)。阴影首批沿用既有素材，后续路线交付见下节。

### B2 副本连续路线

连续样板已落入真实首领副本：入口废弃营火台与散落石材→林间嵌石路→河岸→首领空地。四个副本共用布局与真实碰撞，保留各自 61 名怪物、卷轴入口和续战存档；固定检查点使用裂爪巢穴。路线不修改战斗数值或替换角色模型，不以测试专用渲染器展示。素材来源、离线构建、静态实例池与当前局限归[环境资产](environment-assets.md#副本路线布景)。

`--route` 记录四个暂停检查点及一个真实键盘移动/战斗窗口，`--play=camp` 可直接进入可操作场景；完整通行由双向连续扫掠验证。截图视频中的四段切换是检查点加载，不能称为完整路线的连续实战录像。后续批次已补齐副本连续岸坡、局部暖火及倒木；天空和边界雾仍使用既有配置，完整建筑废墟及大气联调尚待完成，B2 尚未全部结项。

### B2 树木风动

荒野橡树、松树、白蜡树与副本橡树已接入同一套风动，树根固定，树冠缓摆和细小颤动同步影响法线与太阳阴影；模型共享高度与相位，切换 LOD、环绕或重置原点不重启摆动。前景透视保留，玩法碰撞不随树冠摆动。材质、裁剪、时间和深度材质所有权归[森林风动](../render-streaming.md#森林风动)，资产现状归[环境资产](environment-assets.md#免费森林构建)。

受控像素测试检查根部、颜色/深度同步、LOD 相位、时间回环与原点平移；帧时另按真实场景测量。现有 LOD 的轮廓跳变、荒野岸线、完整废墟及大气仍需后续完善。

### B2 副本岸坡与营火

副本已用连续几何替换六边形岸线，沿权威河岸形成湿土坡面、浅深水色及细小涟漪；地表草土、道路和营火空地连续混合。原有石台增加柴木、火焰与局部暖光，营地周围补入三根有碰撞的倒木。地面预警、光环、太阳阴影和天空照明继续共用现有系统；输入、离线构建、资源及局限归[连续岸坡与营火](environment-assets.md#连续岸坡与营火)。

本批只覆盖四个有限首领副本；荒野自然岸线、完整建筑废墟、烟雾与边界雾联调仍待后续。地面/水面共两份静态网格，火焰一次绘制、一盏不投影局部灯，没有新增渲染目标。出生净空、奖励位置和双向路线由副本通行测试保护。

## 世界渲染工作包

| 顺序 | 工作包 | 验收重点 |
|---|---|---|
| 1 | 已接入统一颜色空间/曝光、太阳与静态天空预过滤照明；创建及恢复时烘焙。动态光照变化随实际消费者接入 | 皮革、石材、金属在同一环境中响应可信；亮部保留层次，转镜头不出现材质亮度割裂 |
| 2 | 已接入有界近景动态阴影，统一地形与标准材质的受影；后续在完整布景继续检查角色、树根和岩石接触关系 | 移动不抖动，远行不失准；没有明显悬浮、阴影条纹或漏光 |
| 3 | 山地宏观轮廓与崖壁/沟谷、陡坡材质尺度、坡岸混合；植被透光、风动及 LOD | 山地具有可信结构，地形没有规律拼贴或陡坡拉伸，树冠不塑料化，LOD 不突然换形，岸线不呈硬切片 |
| 4 | 天空、地平线与空间密度积分的体积雾；先补场景深度和有界合成，局部体积光按样板预算接入 | 远近层次清晰，低视角及进出雾区没有薄片白线，遮挡成立，战斗与地面危险仍可辨认 |
| 5 | 在已有统一 HDR 输出上增加深度相关接触遮蔽、克制辉光、调色与抗锯齿评估 | 细枝和轮廓稳定，发光保留形体，透明效果不穿地；运动模糊/景深不遮挡玩法信息 |

渲染宿主持有深度、阴影、环境光及后处理目标，统一处理尺寸变化、上下文恢复、重建和释放；历史缓冲须在切图、镜头跳转时失效。新纹理、目标和 CPU 缓冲进入现有资源预算。按样板中的实际消费者增加通道，不先搭建空泛的通用效果框架。

地形高度、树干碰撞和权威位置沿用现有合同，视觉风动与粒子不消费玩法随机数；世界局部坐标与远行精度保持一致。地形自定义着色器和角色标准材质须共享光照、雾与输出约定。画质档位是明确的产品设置，资产/着色器失败必须报告，不以静默替代掩盖故障。后端取舍继续依据[渲染后端评估](../render-backend-evaluation.md)，本项目不以更换后端为前置条件。

## 角色、技能与声音

当前主角已具备上下身独立采样、动作切换融合及移动/瞄准方向分离。现有素材只有向前移动，向后移动攻击采用反向步态采样；普攻仍借用通用施法动作。这是动画控制基座，距离完整职业表现仍缺真实武器、握持和专门制作的侧移、后退、转身片段。

下一批资产围绕游侠实际武器设计，统一握持点、出手时刻与投射物起点；落脚、坡地接触和必要的脚部 IK 随真实动作接入。先完成一个近战怪、一个施法怪的受击与攻击表达，首领用独特轮廓、动作节奏与材质建立身份。模型与动作替换不改变技能、职业或装备规则。

每个代表技能设计蓄势、释放、命中、残留四段，效果与实际结算事实对齐：冰强调结晶和冷雾，火强调亮芯、余烬与烟，雷强调短促分叉及瞬时照明，星辰强调聚合轨迹与符文。声音、镜头反馈与视觉共用释放/命中时机；新增内容进入已有容量、优先级和生命周期，不逐实体创建材质、声部或灯光。

危险预警的形状、边界与剩余时间优先于友方辉光、掉落和雾。深度淡出粒子使用同源地表；预算同时约束屏幕覆盖、透明叠层、灯光影响范围和实例数。拥挤时按效果优先级分配展示容量，重要预警不可丢失；命中闪白和屏幕震动须克制，并提供减少动态效果设置。

## 游戏界面与交互

沿用 React、现有状态发布和命令事务，重新设计画面组织、图标和操作反馈。界面材质采用克制的旧金属、石材与皮革边框，主要信息区保持干净；文字以阅读和数值比较为先，装饰纹理不覆盖正文。

| 区域 | 目标结构与交互 |
|---|---|
| 战斗 HUD | 生命/法力与药剂围绕底部技能带组织，中央战斗区域保持通透；首领条、地图和必要目标靠边，诊断指标收进可展开区域 |
| 背包 | 物品图标占据规则槽格，常驻品质、锁定和限制标记；详细评分与词条集中在选中详情和对比浮层，保留现有容量和虚拟化 |
| 角色与装备 | 角色形象居中，职业武器、防具和饰品按部位布置；生存/输出摘要直接可见，次要属性展开查看，职业不符原因就地显示 |
| 技能与构筑 | 图标、连接和装配槽明确区分已学、草稿、可学、锁定与冷却；提交反馈遵循现有构筑事务 |
| 打造 | 投入物、加工步骤和结果预览构成操作工作区，代价与不可逆操作清晰；保留单次确认和失败反馈 |
| 地图与旅行 | 以空间关系和地点状态组织信息，浏览、选择和实际出发有明确反馈，避免与移动输入冲突 |
| 主菜单与设置 | 继续游戏、角色存档和设置具有清晰主次；补齐分辨率比例、UI/文字缩放、音频及控制说明 |

统一槽位、按钮、九宫格边框、图标、品质与焦点样式，新增位图资产登记来源和构建。拖动具有拿起、可放置、不可放置、取消和成功反馈，点击/键盘可完成相同操作；保留禁用原因、可访问名称、焦点恢复、Esc 层级与减少动态效果。信息不能仅靠悬停、颜色或装饰传达。

先验收桌面鼠标键盘、1440p 与 UI 缩放，窄窗口保持关键控件可达；手柄和触屏操控须单独设计，不能把响应式排版当作已支持整套操作。先交付 HUD＋背包＋角色换装闭环，再扩展其他窗口，避免全量换皮后才发现空间和操作冲突。

验收场景分开记录平原赶路、密林交战、首领特效、满包开窗和跨区加载的 CPU/GPU 帧时、峰值显存、透明覆盖及上传成本，采用同硬件、同种子和同镜头比较；历史 Node 基准不能证明画质或游戏帧率。短样板用于日常视觉迭代；资源记账、生命周期或 WebGL 恢复改动仍执行[测试策略](../testing.md#change-based-local-validation)要求的 500 次世界替换验证。额外长期压测和大批量设备测试另行安排，优化按[门禁](../optimization-gates.md)推进。
