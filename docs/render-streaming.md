## 数据与会话

WorldSource 管源区块的 I/O、生成和释放，WorldStreamer 管摄像机需求；渲染区块按几何、LOD 和 GPU 生命周期分组。两种区块不必同尺寸，不能把一次 GPU 淘汰解释为源数据或玩法删除。

静态地图使用完整权威网格；程序化世界按需提供区块及稀疏增量，不能为渲染重新物化无限网格。生成基底、作者编辑和生效地表的合成顺序由世界生成文档定义。

WorldLoadPlan 在替换当前世界前完成新输入校验，未发布资源在失败时释放。RenderWorldController 拥有当前会话，摄像机、输入、拾取和公开 API 留在 HexMap；宿主通过回调连接渲染，不把 Three.js 对象塞入流送协调器。

缓存读取、Worker、增量读取及异步资源准备返回后都检查世界世代。过期成功结果只能释放，过期错误也不能覆盖新世界。加载/替换的释放顺序与部分挂载失败处理见[基础设施](foundation-infrastructure.md#渲染会话与区块租约)。

## 可见性与 LOD

裁剪采用保守世界包围盒，覆盖地形位移、植被和模型缩放；由流送调度统一管理可见性，不能同时依赖不知 shader 位移的默认对象裁剪。摄像机变化阈值须配合保守扩张，静止时仍执行过期驻留维护。

地表 LOD 保持共享边界、法线和 CPU 高度查询一致，不允许近远景接缝改变可通行地形。环绕世界的显示副本共享数据与缓冲，规范坐标拥有资源，副本不能重复记账或独立释放共享对象。

植被 LOD 使用稳定布局及抽稀，同一位置不因分块或切档重新随机。近景原始模型与离线简化输出分开；修改简化器先验证拓扑、轮廓和法线，再覆盖受跟踪产物。生成入口与来源见[资产清单](README.md#assets)。

## 驻留、缓存与资源预算

GPU 淘汰可以保留可重建的 CPU 数据；CPU 淘汰不删除权威编辑或游戏状态。可见资源固定驻留时允许暴露超预算，不为满足数字卸掉必要工作集。

按实际保留的分配容量记账，不能用当前实例数量代替已分配容量；共享 backing buffer 和资源标识去重，CPU 数据与 GPU 上传对象分别记录。这些数值不是进程堆占用或驱动真实显存。

模型缓存归地图会话，使用租约与引用计数，共享几何/材质不被某个克隆提前释放；无引用条目有界淘汰。禁止无所有者的全局 Promise 缓存；取消后晚到的模型只能归还或释放。

程序化持久缓存是可重建加速层，权威增量另存。清缓存等待在途写入并换世代，旧写入不得回填；不能顺带删除编辑或角色存档。缓存缺失/读取失败按现有缓存策略处理，权威源的非法数据不能伪装成缓存未命中。

内部创建的依赖随所有者关闭；外部注入的存储按接口约定保留给调用者。所有权不由“当前是否为空”推断。

## 异步准备与帧预算

中心必要内容与周边排队挂载分开，队列在任务间让出；一个同步挂载无法抢占，不能据预算宣称没有长帧。优先级、容量和公平性统一遵守基础设施调度合同。

植被 Worker 只准备稳定布局，草与林共享任务；海拔在主线程由当前生效地表求值。布局签名、世界世代与地表 revision 一起控制发布，旧结果不能替换新编辑。多个配置 setter 合并刷新，无关资源不重复拆建。

编辑刷新先准备新资源再发布；需要防止旧高度外观残留时隐藏旧几何。部分加载失败必须释放已完成项，不能把一个成功子任务遗留为无主资源。

属性更新合并脏区间，包括仍待上传的范围；已缓存各档 LOD 同步接收迷雾变化。改变陆地/水面成员关系时按结构重建，普通局部编辑只更新受影响邻域。

Worker 请求取消应及时拒绝调用方，实际执行槽在确认结束后才能复用；结构错误明确失败，重试仅限协议已定义的瞬态错误。总览等大任务按有界批次让出，分批不改变结果或随机顺序。

## 材质、坐标与贴地

纹理输入先验证必要映射与整数索引范围；纹理数组按层处理边缘与 mip，不能让图集相邻格渗色。可选表面数据的长度、线性色彩与通道语义必须匹配，不能借透明度暗藏其他数据。

加载覆盖 fetch、解码和上传准备的取消；晚到位图关闭且不得上传。贴图、材质与 shader 变体有明确所有者，加载失败不留下半套必需资源。

CPU 保持绝对双精度坐标，GPU 使用区块局部坐标；周期与哈希锚定逻辑世界，浮动原点不能让纹理、草或水面花纹游动。无效或溢出的坐标/周期明确拒绝，不用钳制隐藏错误。

full/fast 路径共享宏观地貌、水体、坐标和光照空间。细节位移受 CPU 包围盒与共享边界约束；单位、标记、植被、相机及拾取使用同一生效地表，不能从某一档显示网格反查权威高度。

远景雾与未探索迷雾分开：前者按视线匹配天空，后者约束可见信息。天空资源在初始化和恢复时准备，帧循环不反复烘焙；恢复钩子与 GPU 资源随宿主释放。

相机地表约束复用有界高度采样，不另建世界或物理副本。前景遮挡淡出改变覆盖率，不删除树干通行和攻击遮挡，也不为每个物体复制透明材质。

## 场景照明与颜色输出

`HexMapRendererHost` 持有静态太阳、天空、预过滤环境图和 `SceneOutput`。颜色纹理在采样时由 sRGB 解码，表面数据保持线性；地形、水、草、模型、天空、雾和透明效果在线性 HDR 中合成，最终通过单个 Three.js OutputPass 执行 ACES、曝光和 sRGB 显示转换。RawShaderMaterial 与标准材质均不能预先转换或截断 HDR 亮度；世界内 `toneMapped=false` 不绕过整场景最终输出。地面投影仍是线性颜色/覆盖率图，在地表着色中合成。当前没有辉光、接触遮蔽或历史缓冲。

环境照明与天空雾由同一个材质注册表绑定：每帧只遍历一次可见世界，共享相机/光照 uniforms，不逐物体克隆材质。材质释放及宿主销毁均恢复原有编译回调、缓存键与 Raw defines，避免多个独立包装层在销毁时重新挂回旧回调。

场景目标为 RGBA16F、深度渲染缓冲，按实际绘制像素尺寸分配；`antialias` 开启时使用目标内 4× MSAA，关闭时无多重采样，默认帧缓冲不重复抗锯齿。目标随尺寸变化重建，GPU 计时覆盖投影、场景与输出。HDR 颜色附件能力缺失直接拒绝创建，不切回旧管线。天空参数和资产输入归[环境资产](game/environment-assets.md#地表数据和着色)。

宿主独占 `renderer-host` 资源账户，天空、环境图、烘焙临时目标、天空几何与场景目标均登记；固定目标是必要工作集，超额通过账本报告。场景目标估算为每像素 12 字节，加每个 MSAA 样本 12 字节，含颜色、深度及 resolve 目标，不等于驱动实际显存。4× MSAA 原生 1440p 约 211 MiB，需与纹理、几何一起评估预算。尺寸变更替换同一项预留，重复尺寸不重新分配。

WebGL 丢失事件中释放宿主的旧 GPU 句柄并保留逻辑预算；不能等上下文恢复后才删除旧 framebuffer/renderbuffer。恢复重新烘焙天空/环境图、重建场景目标并重新绑定材质；失败进入 `failed` 并报告错误，不能继续发布 ready。宿主销毁撤销材质钩子、释放目标及账户。切图只替换世界资源，宿主目标继续复用，不能随世界世代累积。

## 渲染层与表现资源

自定义层通过宿主挂载，登记已添加对象和资源所有权；mount 失败回滚已添加对象，unmount/unload/dispose 即使部分失败也继续清理，最后聚合报告。显式挂载状态支持部分成功后的幂等释放。

地面投影由单一层拥有，在世界绘制前合成并纳入 GPU 计时；执行失败也要恢复渲染目标与状态。地表在真实片元位置接收，未探索区域不泄露印记。分辨率是独立预算，不能随角色数量无界扩张。

动态单位、标记和印记读取当前地表与已有帧循环；不自行创建常驻 RAF 或计时器。共享资源按租约释放，世界切换时重新绑定接收者，层关闭释放私有目标。

## 总览与小地图

总览是 WorldSource 的只读数据能力，小地图为 Canvas 消费者；采样不能调用 loadChunk、占用渲染驻留或创建远方游戏实体。外部传入的源由调用者拥有。

基础栅格与动态叠层分开缓存。栅格按逻辑范围、分辨率和世界身份复用，叠层变化不使地形全部重算。缓存有界，固定可见页；独立请求世代拒绝迟到结果，绘制合并到宿主帧。

可见页按稳定位置顺序合成，不依赖异步完成顺序。已有高分辨率结果可以复用，逐步细化期间保留粗图，避免加载时反复空白。河流与地貌使用同一世界解析器及采样足迹，不能另画一套不对应真实地格的河。

世界加载开始时取消旧任务并暂停刷新，新世界就绪后恢复；保留窗口展示状态但钳制新范围、清理旧导航目标。关闭时终止请求，迟到结果不再绘制。

普通 refresh 更新展示，强制 refresh 同时使对应缓存失效；刷新任务要经过容量准入。页面隐藏/可见性由宿主提供，不能让小地图私自建立另一套页面生命周期。非交互模式不注册输入处理器；导航只通知应用，传送等玩法由应用校验。

## 迷雾、单位与诊断

迷雾按稀疏逻辑状态维护，卸载显示块不丢已探索结果；未物化孔洞是传播边界，不能透过未加载区域无界扫描。远处单位可以降低动画刷新频率，不能改变模拟时间。

只有一个宿主绘制循环。CPU 计时是任务耗时，GPU 时间异步到达；队列忙、线程等待和实际计算成本须区分，不能把排队直接当作 CPU 瓶颈。自适应决策需对应测量来源，具体门槛由实现和[优化门禁](optimization-gates.md)维护。

## 验证

流送/缓存改动覆盖取消、迟到发布、世界替换、租约共享、容量和销毁；LOD/材质改动覆盖共享边界、编辑后贴地、full/fast、远坐标、环绕和恢复；总览改动覆盖采样无驻留副作用、缓存失效、稳定合成和交互。

执行命令与必跑组合见[测试策略](testing.md)，资源长期稳定性同时检查 soak 和浏览器场景。截图不能替代资源释放与协议测试，CPU 基准不能替代 GPU/浏览器帧时。已有取舍与数据见[测量入口](README.md#evidence)。
