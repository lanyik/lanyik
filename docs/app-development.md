## 应用边界

应用是模块化单体：纯数据战斗核心、地图适配器、批量表现层、React HUD、组合入口。
核心不导入 React、Three.js、DOM、Worker 或地图内部模块；地形流送不拥有战斗事实。

新增角色存档由 `core/CharacterCheckpoint.ts` 定义和校验，`SkillSystem`/`DeterministicRandom` 导出与恢复自身状态，Worker 批次在前序操作后生成角色记录。
`app/CharacterRepository.ts` 负责固定 IndexedDB 槽与世界版本；`StartScreen`/`SessionMenu` 负责种子预览和存读档操作，`WorldPreview.worker.ts` 执行一次性地图栅格生成。
`ShareSnapshot.ts` 在 Worker 克隆快照到达时复用未变化的物品、属性、装备等只读分支，避免每个 10 Hz 快照重新计算全部装备比较。
`VirtualItemGrid.tsx` 将背包和打造限制为可见行加少量缓冲，离屏格子没有 DOM/动画；格子内品质流光只在悬停/聚焦时播放，稀有度静态底色、描边和星级保持。
UI 是浏览器 DOM/CSS，由浏览器布局、绘制和合成，不存在应用侧“全部 UI 一个 draw call”的合同。性能检查用 `node scripts/benchmark-survivor-ui.mjs <预览地址>` 的满背包实测。
实测方法、对比值和适用范围见 [UI 开销](./game/ui-performance.md)。

## 权威状态与时钟

每局只有一个位于专用 Worker 的 `CombatSimulation`，独占位置、血蓝、等级、经验、金币、属性点、装备、背包、宝珠、
物品对象表、人口消费位、宝箱消费状态、战斗冷却和随机状态的写入；自动清理设置与累计件数也由核心拥有。
实体事实由它持有的唯一 `CombatWorld` 存储，玩家和怪物共享位置与生命组件；主线程只读取转移过来的表现缓冲。
`CombatSession` 管理加载状态、暂停/隐藏和通知显示期限，命令由异步端口提交，Worker 完成后发布快照。
React 只读取冻结的低频快照和提交命令，不直接修改战斗；每 12 tick（10Hz）发布常规 UI 快照，命令、通知和暂停屏障立即带回快照。
灵境作为显式初始输入注入纯核心。Worker 使用 `SpiritRepository` 端口加载/保存，生产为 IndexedDB 严格事务与 Web Lock 单写者。
灵境 revision 改变的批次先完成一次保存，再发布状态；保存失败明确停止会话。单位测试注入内存仓库，浏览器测试使用真实存储。
开始新游戏和死亡后重开重置局内状态；读取角色存档恢复金币、粉尘与角色进度，灵境独立永久保留，详见[角色存档](game/character-saves.md)。
左上 Worker 负载由已有帧循环每秒取样并发布，暂停时仍刷新；原始记录与计算口径见[线程观测](./game/simulation-and-ai.md#逐-worker-负载观测)。
界面窗口开关、筛选、选中物品 ID 和目标宝珠槽属于本地 UI 状态，不进入模拟。
会话快照公开加载世代 `generation`，React 按世代重挂载交互区；新局清空窗口、选择、浮窗和目标槽，避免局内物品 ID 重用后继承上一局的操作对象。
每次开始或重开都先调用 `CombatView.reset()`，在加载世界或创建新 Worker 前清空实例池、效果与投影，并隐藏旧局角色和雾；首个新状态恢复显示。加载期间不继续绘制上一局实体。

固定逻辑 120Hz，每 tick 为 1000/120ms；渲染跟随浏览器 RAF，显示器高刷新不会增加逻辑执行频率。
时钟累计整数微秒×Hz，避免将周期舍入成 8333 微秒造成漂移；单帧最多接受 250ms 墙钟时间，后台时间不追赶。
最多一个在途批次，另有至多 30 个待执行 tick 和 64 条待提交命令；慢 Worker 下移动输入合并为最新值，
超过 tick 上限的积压计入 diagnostics 并丢弃；时钟另外累计帧间隔超过 250ms 追赶上限而裁掉的时间，命令溢出明确失败。
表现持续绘制最近收到的完整帧，按前后 tick 插值。
碰撞查询 Worker 默认关闭，当前实测的密集查询不优于模拟线程本地执行。显式启用并满足硬件预算时，弹道查询达到实际候选门槛才使用两个查询 Worker；其余系统都在模拟 Worker，见[线程职责与协议](./game/simulation-and-ai.md#多-worker-职责与执行协议)。
`HexMap` 独占 RAF：`beforeframe` 驱动输入、角色与镜头更新，然后更新地图并绘制；`afterframe` 采集当前帧并发布诊断。
`bootstrap` 先建立展示宿主，再创建图形资源、会话和监听器；同步 WebGL 创建失败也展示原因和重试入口。
失败尝试先完整释放才可重试，清理异常会保留错误并要求刷新页面，不在半清理对象上重新初始化。
公开 `bootstrap({ collisionQueries?: boolean })`；默认入口读取宿主在模块执行前设置的 `window.survivorOptions`，仅接受该可选布尔字段，无 URL 开关。
默认值来自 `GAME_CONFIG.workers.parallelCollisionEnabled`，显式启用仍受硬件核心数预算约束。
`application.session` 在成功建立会话后可访问，启动失败时由启动宿主负责展示和重试。计算隔离与任务提交边界见[渲染隔离与扩展边界](./game/simulation-and-ai.md#渲染隔离与扩展边界)。
单 tick 顺序：

1. 保存前一位置，推进受击保护、被动盾、药剂及状态期限，清理到期表现，执行疾行或普通移动；
2. 同步区块窗口，跨区块时释放失效实体、初始化新人口，独立判断六边形地域边界；
3. 自动索敌并创建弹道，扫掠取最早交点，收集命中后批量结算；玩家死亡则结束 tick；
4. 每 12 tick 按装配槽顺序尝试自动技能，逐技能结算，死亡怪物退出后续行为更新；
5. 按圈层感知与运行行为树，执行移动和攻击时序，再批量结算伤害与反伤；
6. 若玩家仍存活，推进经验吸附、升级、物品拾取与附近宝箱，每 60 tick 回复血蓝，失效快照。

近处行为决策 30Hz、远处巡逻/归位和祭司同伴搜索 5Hz、自动技能判断 10Hz；所有醒着的怪物位置/弹道和攻击释放保持 120Hz。地形和碰撞 Worker 按需求处理任务，
不创建空转时钟；具体频率与理论吞吐口径见[模拟设计](./game/simulation-and-ai.md#固定频率配置与吞吐估算)。

手动施法与药剂由会话命令在批次开始、上一批次所有 tick 提交完毕后执行，只在 ready 且未暂停/隐藏/死亡时接受。
暂停立即停止提交新 tick，等待在途工作后发送零 tick 屏障，收到最终快照才向 UI 确认暂停。
暂停仍可加点、整理装备、嵌珠、装配/升级技能和切换自动施法；恢复后按新状态继续。相同种子、逐 tick 输入和命令提交位置可重放。

## 数据布局与地域驻留

高频实体统一使用固定槽的预分配组件数组，总容量 1601；各类查询用活跃槽列表和 swap-remove。
删除只交换查询游标，不搬动存活实体的组件；跨 tick 目标使用带代数的安全整数句柄，避免回收后误伤新实体。
不逐怪创建组件对象、行为树、事件、计时器或 React 对象。

| 实体查询 / 表现 | 上限 | 满载行为 |
|---|---:|---|
| 怪物 | 640 | 49 区块最多 539 槽，超过为明确配置错误 |
| 弹道 | 128（敌方最多 64） | 玩家等待可用槽；敌方本次施法跳过发射并进入后摇，齐射预检完整容量 |
| 经验球 | 768 | 新经验合并到首个活跃球，容量溢出不丢价值 |
| 地面物品 | 64 | 不创建额外物品，现有物品保留 |
| 宝箱表现 | 49 | 驻留未开箱，按距离淡出 |

怪物组件包含真实等级、类型、精英/Boss、出生归属、移动意图、目标、运行叶节点与攻击时序；
位置、生命与弹道归属等由独立组件数组保存。地面物品实体的物品 ID 与冻结物品表一并增删。
自动索敌、范围技能、治疗感知与拾取使用边长 4 的固定容量哈希网格，弹道先做扫掠包围盒初筛，再对候选求交；
网格生命周期、确定性顺序与实际候选调度见[模拟设计](game/simulation-and-ai.md#空间查询与生命周期)。
行为树决定巡逻、短停、脱战归位、绕行、后退、攻击和追击；动作系统负责前摇、单次命中/发射和后摇，表现读取同一动作进度。

方形玩法区块为 12×12，常驻窗口固定 9+16+24=49 块，只决定驻留与卸载。
行为按实际距离独立分层：18 内 30Hz、32 内 5Hz，退出阈值分别为 20/34；低频只降低决策频率，不冻结可见远处的移动。
12 内获取玩家，追击至 19 或玩家距出生点超过 22 后脱战；归位完成才能重新获取目标，闲置怪物在出生点附近巡逻。
只在跨区块时重建窗口。每个出生槽在本次驻留只生成一次，死亡不补充；离开至卸载后重入重建。
宝箱和 Boss 同样按驻留消费，不维护定时轮次、死亡补充冷却或无限探索历史。
实体的出生区块失效时移除，清空引用；地面物品/经验按当前位置离开外圈时清理。

六边形地域是独立内容分区，半径 24，环数决定总体等级带，每环增加 5 级；三难度在等级带内分布。
边界出生点必须按自身坐标确定类型、等级与掉落，不直接继承区块中心的地域。
领主出现在恐怖六边形中心，中心所属的唯一方形区块拥有其出生槽。

## RPG 与界面

装备基础值、显式词条、聚合值分别存储且冻结。等级/星级/品质独立；`sumEquipment()` 是装备聚合入口。
基础属性只有力量、体魄、敏捷、精神，不影响概率或攻速。概率构筑来自装备词条，寻宝分布仅来自宝珠。
`sumOrbs()` 聚合六槽有效 rating，`lootProfile()` 同时提供掉落抽样和 UI 展示，防止说明与实际概率分叉。
宝珠只有宝箱/领主来源，开局两个槽，其余 50/100/150/200 级解锁；没有宝珠反向提高自身掉率的递归奖励。

背包物品统一为 `type/value/size`，所有操作校验真实背包 ID。装备/宝珠/药剂/词条分别限 80/48/32/80 格，药剂与精粹同规格最多 99 份一格。
穿戴/嵌入先移出新物品，再原子返回旧物品，同分类满包可一换一；卸下需要该分类空间。
宝箱按各类容量及实际可合并数量预检全部奖励，失败不改变已有堆叠、不消费随机数、物品 ID 或箱子。
`EquipmentEvaluation.ts` 统一计算最终属性战力及同部位换装差值；总战力和装备贡献进入玩家快照。
各分类自动回收默认关闭，由当前页签品质下拉框设置包含本档的上限；装备售出额外要求未锁定、同部位有装备且换装战力降低。
药剂和词条售出换金币，宝珠分解换粉尘；共享 `Recycling.ts` 收益与 `quoteCraft` 手动回收预检，删除无偿丢弃命令。
设置、加点、升级、换装、打造、解锁与入包边界执行；曾穿戴的装备自动锁定，空部位升级、持平/更高战力装备保留，其余分类按独立品质设置处理。
`storeInventoryItem()` 复用规则，返包装备相对新穿戴状态比较，直接卸下完整保留并检查空格。
宝箱通过克隆 PRNG 生成实际奖励后检查容量，成功后提交，满包拒绝不推进随机序列和 ID。
累计自动处理件数进入玩家快照，不用逐件通知刷屏。整理先合并兼容堆叠，再按品质、装备等级降序，同类非装备按配方、最后 ID 升序排序。
生命/法力最大值变化保持比例；升级额外回血仅按一次经验结算治疗一次。
药剂拾取自动合并同规格堆叠，药剂分类提供显式合并；每次只减一瓶，堆叠 ID 保持到数量归零。
药剂与宝珠没有物品等级；药剂固定四种配方、四档品质，金药附加另一资源 15% 上限恢复。至少一个可恢复资源未满时可使用，共用冷却；HUD 与模拟共用最小足量选药规则。物品数据和图标规范见[通用物品](./game/items.md)。

角色窗口是两列：左装备/宝珠和详情、右攻击/防御/生命摘要、基础加点和按进攻、生存、探索分组的属性。
装备体位和宽高由固定网格控制，空槽与已装备槽有明确区别；选中装备只保存 ID，详情从当前穿戴快照解析，
避免背包替换后继续显示旧物品。详细属性使用原生可折叠分组，保留完整属性及单位。
背包采用自适应列数的紧凑物品格，直接展示评分、换装战力差、保护标记与操作。
工具栏有装备/宝珠/药剂/词条分类，默认装备；打开时合并堆叠并整理一次，各分类有独立自动回收品质与计数，标题显示当前分类容量条与满包状态，
底栏显示格数、总数量和金币；宝珠页顶部直接显示六槽，用共享指针/键盘拖拽嵌入和交换。品质色由 GameConfig 同时驱动 UI 与地面物品。
卡片使用稳定物品 ID 作为 React key 和选择值，排序保持选择；分类变化清空选择，避免快捷键误操作隐藏物品。
卡片本身可聚焦，内部操作和感叹号使用独立按钮，避免嵌套按钮；复选框焦点不阻断菜单或移动快捷键。
感叹号支持悬停/聚焦，portal 提示避免被窗口滚动区域裁切。
`ItemTooltip` 只包裹通用图标按钮；卡片文字、留白、评分和操作按钮不触发详情。离开图标立即关闭；底部提示 Alt 固定。
固定后可移入浮窗操作，Alt/Esc、关闭按钮或外部点击关闭。Provider 保证全局只有一个物品浮窗；触屏触碰图标时固定。
`CombatSession` 只从成功拾取事件维护提升装备 ID 集合；每次发布重新比较，移除失效候选，重开局清空。
`UpgradePrompt` 在主界面右下显示最高战力提升候选，一键穿戴复用正式装备命令，忽略不丢弃物品。
宽度不小于 1180px 时角色与背包在共享工作区并排；更窄时提供窗口切换，隐藏非前台窗口，
关闭其中一个后另一个恢复显示。宽度不大于 700px 时角色内容改为纵向滚动，装备排列不变。
地图右上，战斗记录左上；血蓝/经验/技能/状态下中，血蓝同时显示标签和数值，生命不超过 25% 时标识危急。
桌面功能名与快捷键在右下，窄屏改为底部横向导航；界面使用实色面板隔离地形噪声，SVG 图标不引入额外资源。
视口高度不大于 600px 时工作区利用完整高度并允许内容滚动；尊重系统减少动态效果设置。
菜单快捷键集中在 App 的目录，与按钮共用行为；Esc 按窗口优先级关闭，按钮 Enter 保持原生语义。

## 世界、表现与生命周期

出生搜索使用与 ProceduralWorldSource 相同水体配置的同步 resolver，在最多 14 圈内寻找 5×5 干燥地面。
找不到则明确失败。`HexMap.loadWorld()` 调用开始即拥有 source；调用前未发布的 source 由适配器清理。
逻辑战斗坐标单位为 tileSize=1，表现层根节点按实际 tileSize 缩放，镜头跟随插值位置和地表高度。
角色、掉落、宝箱和效果事实保留双精度逻辑坐标；写实例矩阵前减去插值玩家位置，根节点以双精度放回逻辑世界。
角色出生锚、距离淡出与技能投影源使用同一局部原点，避免地图浮动原点已移动而实例缓冲仍保存巨大 Float32 坐标。
高度缓存每格六顶角及中心，共最多 4096 项；角色、弹道与掉落物按所在三角扇面插值高度，再留出有界微位移偏移。
六角顶点三角函数只初始化一次。区块挂载/卸载、世界卸载、surface 改变或达到上限时清空，避免采样未驻留地块后长期沿用零高度。

主角使用 Quaternius 游侠；地精、小恶魔、程序化蛛兽和岩石守卫通过定义的模型索引组成五个敌人模型池，六种行为角色共享这些池，细节见资产合同。
动作在构建时烘焙，怪物共享八帧循环移动与八帧非循环攻击 morph 数据；攻击方向与进度由模拟决定。
怪物提交与 AI 圈层解耦，在 24–30 逻辑单位内平滑淡出，远处实例在写矩阵和动画前剔除。
实例矩阵、颜色和出生锚只上传可见前缀。morphTexture 使用 RedFormat，按 Three 支持的整张权重纹理更新；空池不上传。
宝箱和地面物品共用距离淡出。弹道、经验和物品采用实例池，战利品使用 Kenney CC0 模型、宝珠多面体与饰品环，八类掉落和一类宝箱复用实例池；品质光环与光柱另有两个固定实例批次，GPU 流光和独立彩色特效，资源与分级见[通用物品](./game/items.md#地面物品和品质表现)；不进行逐怪骨骼求值。
静止宝箱按模型底面的 5×5 地形采样拟合朝向，旋转后重新求接触高度；放置矩阵缓存最多 49 项，随表面缓存一起失效，上传前减去插值玩家坐标。
地面效果通过一个有界俯视投影目标由地形片元接收，覆盖坡面、山脊与水面；立体效果仍按各自深度绘制。
投影范围/分辨率统一来自 `GAME_CONFIG.presentation.groundProjection`；资源费用读取实际 render target 尺寸，不另写固定分辨率。
近战前摇显示实际判定范围的扇形，施法/震荡前摇显示圆环，冲锋显示最大路径矩形；治疗预警绿色，敌方攻击红色。
玩家技能、治疗与震荡使用 128 项效果事实，表现展开为最多 4096 个实例；持续结界另用一个球壳，跟随玩家直到护盾耗尽。
脉冲/霜环包含冲击环、符文与粒子，闪电为分段双层电弧，疾行保留路径残影；共用图集与实例材质，预警和效果统一预分配、计入资源预算并释放。
远景雾使用灰蓝色 `0x849b9f`，相机深度 620 开始、1100 完全遮蔽，早于 1500 的地形裁剪距离；
应用关闭独立天空穹顶，让完全入雾的地形与场景底色衔接。`BoundaryMist` 用一份实例材质绘制三个高度的世界空间噪声雾环，
14 内不覆盖战斗区域，14–26 渐浓、26–44 保持浓雾，44–52 收尾，随模拟时间推进；避免原先 36 开始退雾过早暴露外围。
雾、特效池和结界资源由 CombatLayer 统一持有与释放，距离参数统一归入 `GameConfig.presentation`。
雾片实例也使用局部坐标；各噪声层的世界相位在 CPU 按哈希周期取模后上传，保持世界锚定而不向 GPU 传巨大绝对位置。

右上小地图复用地图包的 `WorldMinimap` 与现有地形 Worker 概览分页：96×96 地形格范围，基础采样 192，64 页 LRU 上限。
山川、水域、地貌直接来自当前世界同种子与同水体参数的采样；难度色晕只在缓存底图上合成，不触发远处区块驻留或新增 Worker。
`RegionMapBinding` 是 UI 装载端口，`HexRegionMap` 在适配层持有采样控件；React 只挂载 Canvas、传递只读战斗快照和展开状态。
玩家与地域中心按 even-column 格心的逆映射对齐采样像素；困难为琥珀色、恐怖为玫瑰色的低透明渐变，去掉六边形边框和逐格数字。
折叠态仅标记恐怖地域与玩家，展开再显示困难/恐怖等级；上方保留当前地域精确难度和等级带，色晕仅表达邻近危险程度。
控件关闭自身导航输入，M/Esc 统一由 App 管理；两种尺寸都跟随角色，不提供地图传送。移动仅重绘叠层与拼接缓存页，静止快照不重复重绘。
世界替换中止旧采样并清缓存；React 严格模式重挂载、面板卸载及适配器关闭都释放小地图消费者，先于世界 Worker 和资源预算账户释放。
固定池禁用自身视锥剔除，由玩法窗口控制实例数量；地形仍由地图区块和 LOD 控制。
角色资源首次初始化异步加载，成功预算申请后才挂载；已释放层或过期世界不接收加载结果。
角色的六个 GLB 与二十四张贴图按 `GAME_CONFIG.presentation.assetLoadConcurrency`（默认 4）有界并发，技能图集是独立单项任务。
`fetch` 使用当前初始化的取消信号；世界替换、关闭或任一资产失败会取消同一初始化其余请求并释放已经加载的半成品。
GLTF/ImageBitmap 解码不可中断，因此取消立即结束等待并释放其余资源，晚到解码结果单独释放；贴图持有的 ImageBitmap 在 dispose 时关闭。
原始源模型、生成网格/法线、PNG atlas、实例 morphTexture 和所有材质均有明确释放路径。

`CombatSession.start()` 用加载世代拒绝过期结果，加载时停止时钟、清输入并终止旧战斗 Workers。
主线程直接拥有模拟 Worker 与查询 Workers，以 MessageChannel 连接它们；没有嵌套创建的子 Worker。
重开复用地图与角色资源，重建整组战斗 Workers；关闭、加载失败或任何战斗 Worker 错误都终止整组并释放等待请求。
请求乱序、解码失败和 15 秒无回复明确失败；恢复必须重新启动会话，不在主线程继续旧局。
隐藏、失焦、暂停、死亡与关闭按合同停止/清理输入；恢复可见性不会覆盖用户主动暂停。
pagehide 非往返缓存场景停止应用帧并等待异步释放，重复关闭返回同一 Promise。
地图或资源失败进入 failed 并显示原因，可重新加载同一种子；没有静默替换模型或伪造地图的降级路径。

Windows 一键入口为根目录 `run.bat`，工作目录固定为脚本所在目录，检查 Node.js `^20.19.0 || >=22.12.0` 与 npm。

批处理使用 CRLF 行尾，控制台文字使用 ASCII，避免 Windows 代码页影响执行或错误展示。
地形生成器 v21 衔接平原、丘陵与山脉，压低谷地山口、平滑限制峰顶；生产 Worker 使用与渲染同种子的 `ProceduralCombatTerrain`。玩家采用接触切线滑行，树林局部虚影和镜头净空在渲染端处理，规则和性能见[地形通行](game/terrain-navigation.md)。
构建脚本先校验 realpath 与父目录，只替换 `apps/survivor/.assets`；不下载网络资产或删除源文件。
Vite 保持 React、Three.js、世界运行时的明确分组，生成文件不入 Git。

### 本地运行诊断

`app/RuntimeLog.ts` 由 `bootstrap` 创建并在应用生命周期内持有；`CombatSession` 接收该记录器，独立测试和模拟基准不依赖浏览器存储。
日志存于当前来源的 `localStorage["survivor.runtime-log.v1"]`，跨刷新保留；开发端口 5173 与预览端口 4174 各自保存。
最多保留最近 64 条、128,000 个序列化字符，每条详情最多 2,048 字符，超限淘汰最早记录。每页有独立 UUID，每条附时间戳。
记录页面启动/可见性/退出、会话启动、背包整理/锁定/自动清理/穿戴/打造命令，以及 React、未捕获脚本、未处理 Promise、会话/Worker、WebGL 上下文丢失、启动/存档/清理错误。
物品命令带种子、tick 与操作参数，表示发出了操作，不等同于操作已经提交。可获得的错误栈随错误详情保留。
写入只发生在这些低频边界，模拟 tick、每帧渲染、移动按键和完整角色存档不写入该日志；游戏运行不上传日志。
主界面、O 存档界面和失败界面共用 `RuntimeLogExport`，下载 `rift-diagnostics-*.json`；React 根界面异常退出后，可刷新回主界面导出。
存储被禁用、空间不足或已有日志损坏时停止写入并在导出区域显示原因，导出的报告也包含 `storageError`；不会清除损坏的原记录或影响游戏命令。
全局异常及 WebGL 监听由 bootstrap 显式注册、销毁时移除；恢复页面缓存的 pagehide 只记录和暂停，不销毁监听。

日志只能记录浏览器仍能执行脚本时的事件，浏览器进程被终止、系统/GPU 崩溃可能没有最后一条；缺失 pagehide 不能直接判定为崩溃，pagehide 也不能区分刷新和手动关闭。
本功能接入前的退出无法追溯。2026-09-13 用户报告的整个窗口关闭与 Ctrl 解锁期间叠加 W 移动吻合，但没有当时的异常栈可以认定程序崩溃。
因此背包/工坊改用 Shift 快速锁定，避开浏览器保留的 Ctrl+W；规则见[界面合同](game/interface-design.md)。

`RuntimeLog.test.ts` 验证跨页保留、条数/字符预算、存储拒绝/配额/损坏；`Bootstrap.test.ts` 验证异常接线及监听清理。
`inventory-shortcuts.spec.ts` 在真实 Worker 页面检查 Shift+W、连续锁定、Shift+空格长按、解锁自动售出时的浮窗卸载，并通过真实未捕获错误、刷新、下载验证日志保留。
2026-09-13 验证：应用 193 项单测、类型检查和生产构建通过；装备/快捷键/存档/启动失败与中途关闭共六项浏览器回归通过，500 次世界替换检查通过。

交付正在运行的开发地址前，执行 `npm run check:app:dev`，检查 5173 的实际页面、地形小地图采样完成、五技能 type/value 图标、拖拽装配、着色器错误与窄屏滚动后的关闭按钮，以及未打包模拟 Worker 中三类物品的生成与入包。
该检查复用正在运行的服务，不替换 Worker 或预先重建服务，能够发现开发服务返回旧模块而磁盘源码已更新的情况。
检查样本中只有装备传入物品等级；宝珠生成使用默认最低品质，药剂以品质、配方和堆叠数量创建，与无等级物品合同保持一致。
物品公共字段或跨 Worker 合同重构后，重启开发服务并刷新页面，再通过该检查；生产构建通过或 HTTP 200 不能替代开发地址验收。

`test:app` 覆盖确定性、圈层、真实战斗/拾取、等级节奏、装备三轴、概率归一化、宝珠、药剂、加点隔离、
排序优先级、最终战力与穿戴结果一致、安全清理保护、满包奖励随机状态、拾取推荐失效，以及跨 AI 边界的模型显示。
另覆盖代际身份、树抢占、前摇躲避、圈层取消攻击、弹道来源失效、齐射容量和一次死亡结算。
`test:app:e2e` 覆盖真实 Worker/WebGL、五个模型、血蓝地图位置、窗口分离、固定体位、穿脱装备、tooltip、
快捷键、响应式窗口切换与失败资源恢复，以及真实攻击姿势、预警、敌方弹道颜色和暂停。
`benchmark:app` 测量真实直行战斗与 640 怪物/128 弹道满载的纯模拟 CPU；阈值和测量范围见 ECS 设计。
`benchmark:app:workers` 测量真实查询线程的拷贝、转移和等待成本；测试额外覆盖并行一致性、缓冲所有权、背压和暂停边界。
浏览器检查满载并行查询、20 次重开、查询线程崩溃与恢复，以及最终所有 Worker 退出。
图形验收同时采集 console error 与 WebGL/GL/Three warning，覆盖真实纹理上传失败；重开逐次检查旧怪物池和投影已清空。
各用例共用消息分类，仅排除 Chromium 截图/录像读回时明确报告的 `GL Driver Message (OpenGL, Performance, ...): GPU stall due to ReadPixels` 警告；该提示仍保留在 trace。其他图形 warning、全部 console error 和 pageerror 均失败。
专门的 Worker 浏览器用例显式启用查询线程；另覆盖 WebGL 创建失败后重试、挂起贴图时关闭，以及新局物品 ID 重用和宝珠拖拽状态重置。
应用类型、核心测试、两种基准与浏览器测试进入 CI。遵守仓库标准 gate，生命周期与驻留相关修改增加 500 次世界替换 soak。
`region-map.spec.ts` 检查地形像素、难度叠层、展开/收起的分页复用、静止无重复请求/重绘、快捷键归属、窄屏边界以及最终缓存和请求释放；坐标单测覆盖正负列格心与跨列连续性。
